    第8回　ポインタ1¶

    到達目標¶

    • アドレスと間接参照を用いて変数を操作できる．
    • 関数から呼び出し元の値を変更できる．
    • 配列・文字列とポインタの関係，寿命の制約を説明できる．

    1　場所を値として持つ¶

    前回までとのつながりと準備¶

    第2回では&でアドレスを表示し，第5回では関数へ配列を渡し，第7回ではscanfへ変数のアドレスを渡す意味に触れました．今回はそれらをポインタという仕組みで説明します．変数の値・変数の場所・場所を保存する変数を区別することが出発点です．

    作業場所はPL1の下のweek08です．Visual Studioで空のプロジェクトを作り，.cファイルを追加します．第1回と同じC17・Cとしてコンパイル・警告レベル4を使います．短いコード片はmain内へ，関数の定義はmainの外へ置きます．ポインタの初期化を省略せず，指す先を図にしてから実行してください．

    この回では，すでに存在する変数・配列だけを指します．自分でメモリを確保する処理は第13回です．アドレスの具体値は環境や実行ごとに変わるので，見本の数値をソースへ書き込む必要はありません．

    第2回で使った &x はxのアドレスです．ポインタは対象を指すための値で，ポインタ変数に保存できます．

    int x = 10;
int *p = &x;
*p = 20;
    式 意味
    x xに保存された整数20
    &x xのアドレス
    p pに保存された，xを指すポインタ
    *p pが指す先のint．この例ではx
    &p ポインタ変数p自身のアドレス

    宣言の int *p は型を表し，式の *p は間接参照を表します．*p = 20; はp自体ではなく，指す先を書き換えます．p = &y; はpの指す先を切り替えます．

    p（xを指す値を保存） ──→ x（20を保存）

    ポインタの型は指す対象の型と合わせます．intへのポインタでdoubleを書き換えるようなことはしません．アドレス表示は printf("%p\n", (void *)p); です．

    ポインタ自身にも保存場所がある¶

    変数pの領域                         変数xの領域
┌───────────────────┐              ┌─────────────┐
│ xを指すアドレス値  │ ───────────→ │ 整数20      │
└───────────────────┘              └─────────────┘
 この箱の場所は&p                    この箱の場所は&x
 箱の中身を読む式はp                 箱の中身を読む式はxまたは*p

    printf("p=%p &x=%p &p=%p\n", (void *)p, (void *)&x, (void *)&p);
printf("x=%d *p=%d\n", x, *p);
printf("pointer=%zu object=%zu\n", sizeof p, sizeof x);

    pと&xは同じ対象を指す値ですが，&pはポインタ変数自身の場所です．sizeof pはポインタのサイズ，sizeof xはintのサイズです．MSVCのx64向けビルドでは通常8バイトと4バイトですが，32ビット向けなどでは異なります．サイズだけから型を判定することはできません．宣言を読んで確認してください．

    宣言の*と，式の*を区別する¶

    int *p = &x;は，intを指すポインタpを宣言し，&xで初期化する文です．「*pへ&xを代入する」という処理ではありません．int *p;の後にp = &x;と書いても同じ対象を指せますが，間に未初期化のpを使わないようにします．

    int* pという空白の置き方でも同じ意味です．ただしint *p, q;ではpだけがポインタで，qはintです．両方をポインタにするならint *p, *q;と書きます．この講義では混同を避けるため，基本的に1行ずつ宣言します．

    double d = 3.0;を指すならdouble *dp = &d;です．型が合わないときに，キャストで診断を消して無理にアクセスしてはいけません．ポインタの型は，指す値の読み書きや，後で学ぶ「次の要素」への移動単位に関係します．

    ポインタのコピーと値のコピー¶

    int a = 10;
int b = 3;
int *p = &a;
int *q = p;
*p = 13;
printf("%d %d %d\n", a, *p, *q);
q = &b;
printf("%d %d %d\n", a, *p, *q);

    最初は13 13 13です．q = pではaそのものを複製せず，aを指す値をコピーするので，pとqは同じaを指します．次にq = &bとすると，qだけがbを指し，13 13 3となります．pはaを指したままです．

    次の表は，毎回a=10，b=3，p=&a，q=&bから独立に実行した場合です．

    操作 a b pの指す先 qの指す先
    p = q; 10 3 b b
    *p = *q; 3 3 a b

    p = qは矢印の変更，*p = *qは矢印の先の値の変更です．この2つを図で説明できるようにしてください．

    &と*を組み合わせる¶

    int a = 10;，int *p = &a;の場合，*&aはa，*&pはpを表します．&*pはpと同じポインタ値です．一方，&*aは整数aへ間接参照を適用しようとするため正しい式ではありません．

    *&pはpという変数を表すので，*&p = &b;と代入すればpの指す先を変えられます．&*pはアドレス値であり，&*p = &b;とは代入できません．同じアドレスとして表示されても，代入先にできる式かどうかは別です．通常はp = &b;のように簡潔に書きます．

    値を増やすのか，ポインタを進めるのか¶

    有効なintを指すpに対して++*pと(*p)++は，どちらも指す先の値を1増やします．式の値を使う場合の前置・後置の違いは第3回と同じです．

    一方，*p++は*(p++)と解釈され，p自体を次の要素へ進めます．移動前の要素を表す式になります．安全に進めるには配列内などの範囲条件を守る必要があります．単独の変数で先へ進めて値を読む実験はせず，後の配列の節で扱います．

    2　関数で呼び出し元を書き換える¶

    int引数の値を変更しても呼び出し元に影響しなかったのは，値のコピーだったからです．ポインタを渡す場合もポインタの値のコピーですが，コピーしたポインタが同じ対象を指すので，対象を変更できます．

    swap(&x, &y) では，swap内のaがxを，bがyを指します．一時変数を使って *a と *b を交換します．一時変数なしに上書きすると元の値を失います．

    関数の契約

    この回のswapは，aとbが有効なintを指していることを呼び出し側の責任とします．NULLや寿命の終わった変数のアドレスは渡しません．ポインタ引数なら何でも渡せるわけではありません．

    swapの3つの代入¶

    void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

    呼び出し元のxが5，yが8なら，tempへ5を退避し，xへ8を書き，最後にyへ5を書きます．tempは局所変数ですが，aとbが指す対象は呼び出し元のxとyです．a = b;と書いても局所的なポインタ値が変わるだけで，交換にはなりません．

    複数の出力をポインタで受け取る¶

    void decompose(double x, long *whole, double *fraction)
{
    *whole = (long)x;
    *fraction = x - *whole;
}

    mainでlong n;，double f;を用意してdecompose(3.14, &n, &f);と呼ぶと，nは3，fは約0.14になります．戻り値はvoidですが，2つの出力先へ値を書き込めます．この例のxは有限で−100〜100とし，longへの変換が範囲内になるようにします．出力先は有効なlongとdoubleを指す必要があります．

    負の−3.14なら整数部は−3，小数部は約−0.14です．キャストは0方向へ小数部を切り捨てるので，床関数のように−4へ変わるわけではありません．

    引数をlong whole，double fractionへ変えると，変更できるのはコピーだけです．比較するときも，呼び出し元のnとfを先に0へ初期化し，未初期化の値を渡してはいけません．関数から複数情報を返す方法はこれだけではなく，第11回では構造体にまとめる方法も扱います．

    ポインタを戻り値にする¶

    int *min_pointer(int *a, int *b)
{
    if (*a < *b) {
        return a;
    }
    return b;
}

    int x = 9, y = 3;としてint *result = min_pointer(&x, &y);と呼ぶと，resultはyを指します．返しているのは値3ではなく，その値がある場所です．*result = 0;と書けばyが0になります．等しい場合はこの実装ではb側を返します．返した対象が呼び出し後も生きていることが必要です．

    ポインタ引数そのものを関数内で別の場所へ変更しても，呼び出し元のポインタ変数は変わりません．その変数を変更する方法は，次回の二重ポインタで学びます．

    3　配列とポインタ¶

    多くの式で配列名は先頭要素へのポインタに変換されます．int *p = values; は &values[0] を保存します．p + 1 は「1バイト先」ではなく「次のint要素」を指します．values[i] と *(values + i) は同じ要素を表します．

    配列自体とポインタ変数は同じものではありません．配列そのもののsizeofは全要素分ですが，ポインタのsizeofはポインタ自身のサイズです．関数引数の int a[] は int *a として扱われ，長さは保持しません．

    ポインタ演算は同じ配列内，または最後の要素の1つ先までに限ります．1つ先のポインタはループの終了判定に使えますが，間接参照はできません．別々の変数へのポインタを引き算して距離を調べることもしません．

    次の要素へ進む単位¶

    int values[5] = {10, 20, 30, 40, 50};
int *p = values;
int *q = p + 2;

    添字       0       1       2       3       4        1つ先
        ┌───────┬───────┬───────┬───────┬───────┐
        │ 10    │ 20    │ 30    │ 40    │ 50    │
        └───────┴───────┴───────┴───────┴───────┘
          ↑               ↑                       ↑
          p               q = p + 2                values + 5

    intが4バイトなら，qはpから2要素，つまり8バイト先を指します．p + 2という式だけではp自身は変わりません．p += 2;や++pはpを更新します．doubleならdoubleのサイズ，charなら1バイトが1要素分です．同じ配列内なら--pや整数の減算で戻ることもできますが，先頭より前へ進んではいけません．

    差と比較は同じ配列で行う¶

    q - pはバイト数ではなく，要素数の差2です．ポインタの差の型はstddef.hで宣言されるptrdiff_tで，表示には%tdを使います．例えばprintf("distance=%td\n", q - p);と書けます．

    同じ配列内ではp < qは真，p == qは偽です．同じ配列の1つ先のポインタも，終了判定や差の計算に使えます．無関係な配列や変数の間で大小比較・引き算をして並びを推測してはいけません．また，ポインタ同士を足す演算や，ポインタを2倍する演算はありません．

    添字による走査とポインタによる走査¶

    enum { COUNT = 5 };
int a[COUNT] = {2, 6, 1, 4, 7};
int sum_index = 0;
int sum_pointer = 0;
for (int i = 0; i < COUNT; ++i) {
    sum_index += a[i];
}
for (const int *p = a; p != a + COUNT; ++p) {
    sum_pointer += *p;
}
printf("%d %d\n", sum_index, sum_pointer);

    どちらも20になります．前者は添字を，後者は指す場所を更新します．最後の要素を読んだ後，pがa + COUNTに到達すると条件が偽になり，本体では読まれません．&a[COUNT]も1つ先を表せますが，a[COUNT]の値を読むことはできません．1つ先よりさらに先のポインタを作ることも避けます．

    要素数を名前でまとめる方法には#define COUNT 5もあります．これはコンパイルに先立つ前処理で，COUNTというトークンを5へ置き換える指定で，変数を作る宣言ではありません．この講義では既習のenumによる整数定数を基本にします．どちらもサイズとループの上限に同じ名前を使い，修正漏れを防ぎます．

    配列とポインタは同一ではない¶

    操作 配列a ポインタ変数p
    要素にアクセス a[i] 有効な範囲ならp[i]
    指す先を変更 a = pやa++は不可 p = a，++pなどが可能
    sizeof 配列全体のサイズ ポインタ自身のサイズ
    宣言 要素の領域を確保する ポインタ値を保存する領域を確保する

    p[i]も*(p + i)と同じです．pが配列の途中を指しているなら，p[0]はその途中の要素になります．また，a[2]は*(a + 2)，*(2 + a)，2[a]とも同じ意味になりますが，後ろの2つは読みにくいため通常のコードでは使いません．

    配列名が先頭要素へのポインタへ変換されるのは，多くの式での規則です．sizeof aや&aなどは例外です．&aは配列全体を指すポインタで，先頭要素を指す&a[0]とは型が異なります．詳しい扱いは第9回で整理します．

    関数に渡すときの配列表記¶

    仮引数のint a[]とint *aは，どちらもintへのポインタとして扱われます．配列全体の複製ではなく先頭を指す値を渡すため，大きな配列でも引数として全要素をコピーする必要はありません．ただし，関数が全要素を走査する時間までなくなるわけではありません．

    void set_one(int *a, int n)
{
    for (int i = 0; i < n; ++i) {
        a[i] = 1;
    }
}

    mainのint a[] = {2, 3, 4};へset_one(a, 3);を実行すると，元の要素が{1, 1, 1}へ変わります．仮引数をint a[]へ書き換えても同じです．読み取り専用ならconst int *aを使います．どちらの仮引数表記でもsizeof aはポインタのサイズなので，長さは別に渡します．

    4　文字列とconst¶

    char buffer[] = "cat";
const char *word = "cat";

    bufferは書き換え可能な配列です．wordは文字列リテラルを指します．リテラルを書き換えてはいけないため，const char * を使います．

    const int *p はpを通して対象を書き換えない，int *const p はpの指す先を変更しない，という違いがあります．読み取り専用の配列を受ける関数では前者を使います．

    配列の初期化とリテラルへのポインタ¶

    bufferという配列： [ 'c' ][ 'a' ][ 't' ][ '\0' ]  ← 要素を変更できる
wordという変数：  [ ポインタ値 ] ──→ "cat"のリテラル ← 変更不可

    buffer[0] = 'C';は可能です．word = "dog";も可能で，wordが別のリテラルを指すようになります．しかしbuffer = "dog";という配列への代入はできず，word[0]の書き換えもできません．word = NULL;はポインタ値の変更として可能ですが，その後%sへ渡すことはできません．

    同じ内容の文字列リテラルが，処理系によって同じ領域を共有する場合もあります．別々になる場合もあるため，ポインタの==で内容の一致を判定してはいけません．リテラルが共有されるかどうかにかかわらず，リテラルの変更は未定義動作です．読み取り専用領域にあるから必ず同じエラーが出る，という保証もありません．

    宣言 pの指す先の変更 pを通した要素の変更
    int *p 可能 可能
    const int *p 可能 不可
    int *const p 不可 可能
    const int *const p 不可 不可

    const int *pは，対象が他の経路からも絶対に変わらないという意味ではありません．変更可能なint xを指しているなら，x = 20;による更新は可能です．このポインタを通して書かない，という制約です．

    ポインタで文字列長を求める¶

    size_t pointer_length(const char *s)
{
    const char *start = s;
    while (*s != '\0') {
        ++s;
    }
    return (size_t)(s - start);
}

    const char *なので*sを書き換えることはできませんが，sを進めることはできます．"abc"ならsは3回進み，終端を指して止まります．差は3です．終端が読み取り可能な同じ配列内にあり，差がptrdiff_tで表せる長さであることを前提にします．授業では短い文字列だけを使います．

    *s != '\0'は*sとも書けます．終端の値は0だからです．カウンタを増やすforの版，whileで進めた回数を数える版，ポインタの差を使う版は，同じ終端までの走査を別の形で書いたものです．

    コピーの代入式を読む¶

    コピー先に十分な容量があり，コピー元が終端を持ち，両者が重ならないとき，次のループで終端も含めてコピーできます．dstとsrcは，それぞれ書き込み先・読み取り元を指す有効なポインタとします．

    while ((*dst = *src) != '\0') {
    ++dst;
    ++src;
}

    まず1文字を代入し，その代入した値が終端かどうかを調べます．終端もコピーしてから条件が偽になるため，最後の0はコピー先へ入ります．単にwhile (*src)の本体で非0の文字だけをコピーする形では，別途終端を書き込む処理が必要です．

    短くwhile ((*dst++ = *src++) != '\0') { }とも書けます．*dst++は*(dst++)なので，移動前の要素に代入して両ポインタを進めます．この形では終端をコピーした後にも1つ進みます．今回は読めることを目標にし，実装は容量検査を先に行う明確なループを基本にします．コピーで上書きするのは終端までなので，その後ろに古い文字が残っていても，表示は新しい終端で止まります．

    5　NULLと寿命¶

    NULLは「対象を指していない」ことを表すヌルポインタ定数です．int *p = NULL; と初期化できますが，そのまま *p を読んだり書いたりしてはいけません．文字列の終端'\0'とは役割が違います．

    関数内の通常の局所変数のアドレスを返すと，関数終了後には対象の寿命が終わっています．そのポインタを使ってはいけません．「アドレスが表示できる」「前の値が残って見える」は有効な領域である証拠ではありません．

    NULLはstdio.hやstddef.hなどで利用できます．p == NULLは!pとも書けますが，非NULLなら必ず有効なポインタ，ということではありません．NULLの表示形式や内部表現がすべての環境で同じとは限らず，通常の整数のアドレス計算に置き換えてはいけません．

    問題 なぜ危険か この回での対処
    未初期化のint *pを使う 有効な対象が定まっていない 宣言時に有効なアドレスかNULLを入れる
    NULLを間接参照する 指す対象がない NULLかどうかを判定し，参照しない
    局所変数のアドレスを返す 関数終了後に寿命が終わる 呼び出し元の変数へ書くか，値を返す
    配列の外を読む 対象の範囲を超える 長さと境界を確認する
    リテラルを書き換える 言語仕様で変更不可 変更するならchar配列へコピー

    不正アクセスが必ず停止や特定のエラーになるとは限りません．危険な例を実行して結果を覚えるのではなく，「何を指すか・型は合うか・寿命は続いているか・範囲内か・書き込めるか」を確認します．

    #include <stdio.h>
void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}
int sum_array(const int *a, int n)
{
    int total = 0;
    for (int i = 0; i < n; ++i) {
        total += *(a + i);
    }
    return total;
}
int main(void)
{
    int x = 3, y = 8;
    int *p = &x;
    *p = 5;
    swap(&x, &y);
    printf("x=%d y=%d\n", x, y);
    int values[] = {10, 20, 30};
    printf("sum=%d\n", sum_array(values, 3));
    const char *word = "cat";
    printf("%c %s\n", *word, word + 1);
    return 0;
}

    pointers.c

    x=8 y=5
sum=60

    最後のword + 1は，元の文字列の2文字目を指します．そこから終端まで表示するのでatになります．

    例題の前半ではpの値は変わらず，指す先のxが3→5→8へ変わります．交換の一時変数tempが保持するのはアドレスではなく，元の整数5です．中盤のsum_arrayは配列のコピーを作らず，3要素を読み取って60を返します．constなのでこの関数を通して値を変えることはありません．

    最後の*wordは1文字なので%c，word + 1は終端まで続く文字列の開始位置なので%sに渡します．同じポインタに関係する式でも，式が文字の値なのか，文字列を指すポインタなのかで書式が異なります．

    演習では，まず紙に変数の箱とポインタの矢印を書き，代入ごとに箱の中身と矢印のどちらが変わるか記録してください．Visual Studioのデバッガでpと*pを確認する場合も，有効な対象を指していることを先に確かめます．
