    第8回　ポインタ1¶

    到達目標¶

    • アドレスと間接参照を用いて変数を操作できる．
    • 関数から呼び出し元の値を変更できる．
    • 配列・文字列とポインタの関係，寿命の制約を説明できる．

    1　場所を値として持つ¶

    前回までとのつながりと準備¶

    第2回では&でアドレスを表示し，第5回では関数へ配列を渡し，第7回ではscanfへ変数のアドレスを渡す意味に触れました．今回はそれらをポインタという仕組みで説明します．変数の値・変数の場所・場所を保存する変数を区別することが出発点です．

    作業場所はPL1の下のweek08です．Visual Studioで空のプロジェクトを作り，.cファイルを追加します．第1回と同じC17・Cとしてコンパイル・警告レベル4を使います．短いコード片はmain内へ，関数の定義はmainの外へ置きます．ポインタの初期化を省略せず，指す先を図にしてから実行してください．

    この回では，すでに存在する変数・配列を指すポインタを扱います．自分でメモリを確保する処理は第13回です．

    ポインタとアドレス¶

    ポインタは変数や配列を指すための値で，ポインタ変数に保存されます． 実質的には，ポインタは変数や配列などがメモリ上でもつアドレスです． 他の変数とは異なる型をもち，int型へのポインタやchar型へのポインタとして宣言されます． ポインタを表す演算子は * です． int *p; という形で int 型の変数を指す（つまり，アドレスを保管する）ポインタ変数 p が宣言されます． また，ポインタ変数が指す実体を参照する演算子にも，同じ * を使います． これを間接参照といいます． 第2回で使った & はその逆で，変数などのアドレスを求める演算子です．

    式 意味
    x 変数 x
    &x 変数 x のアドレス
    int *p int 型変数へのポインタ p の宣言
    p = &x pが変数 x を指すように参照を設定
    *p pが指す変数への間接参照 
    int x = 10;
int *p = &x;
printf("%d\n", *p); // 10

*p = 20;
printf("%d\n", x); // 20

int y = 30;
p = &y;
printf("%d\n", *p); // 30

    宣言の int *p はint型へのポインタという型を表し，その後の式での *p は間接参照を表します． *p = 20; はp自体ではなく，指す先を書き換えます． つまり p が指す変数は x のままで，指す先である x の値が 20 に書き換わります． p = &y; はpの指す先を切り替えます． p が y を指すようになるため，*p は y の値である 30 となります．

    ポインタ自身の保存場所¶

    ポインタも変数と同様にメモリ上にありますので，アドレスがあります． p に保存されたアドレスの値を表示するには，書式 %p を用いて printf("%p\n", (void *)p); とします．

    変数pの領域                         変数xの領域
┌───────────────────┐              ┌─────────────┐
│ xを指すアドレス値  │ ───────────→ │ 整数20      │
└───────────────────┘              └─────────────┘
 この箱の場所は&p                    この箱の場所は&x
 箱の中身を読む式はp                 箱の中身を読む式はxまたは*p

    int x = 20;
int *p = &x;
printf("p=%p &x=%p &p=%p\n", (void *)p, (void *)&x, (void *)&p);
printf("x=%d *p=%d\n", x, *p);
printf("pointer=%zu object=%zu\n", sizeof p, sizeof x);

    pと&xは同じ対象を指す値ですが，&pはポインタ変数自身の場所です．sizeof pはポインタのサイズ，sizeof xはintのサイズです．MSVCのx64向けビルドでは通常8バイトと4バイトですが，32ビット向けなどでは異なります．サイズだけから型を判定することはできません．宣言を読んで確認してください．

    宣言の*と式の*を区別する¶

    これまでの例のint *p = &x;は，int *p;という宣言とp = &x;という代入を一文にまとめたものです． int *p = &x;は，intを指すポインタpを宣言し，&xで初期化する文です．「*pへ&xを代入する」という処理ではありません．

    空白の場所を変えて int* p としても，同じ意味になります． この書き方の方が，「int*（＝int型へのポインタ）として p を宣言する」という意図が伝わりやすいかもしれませんが，注意する点もあります． 複数のポインタを宣言しようとして int* p, q;と書いた場合，pだけがポインタで，qはint型の変数となります． 両方をポインタにするならint *p, *q;と書く必要があります． この講義では混同を避けるため，基本的にポインタは1行ずつ分けて宣言します．

    double d = 3.0;を指すならdouble *dp = &d;です．型が合わないときに，キャストで診断を消して無理にアクセスしてはいけません．ポインタの型は，指す値の読み書きや，後で学ぶ「次の要素」への移動単位に関係します．

    ポインタのコピーと値のコピー¶

    int a = 10;
int b = 3;
int c = 1;
int *p = &a;
int *q = &b;
int *r = &c;
q = p;
*r = *p;

*p = 13;
printf("%d %d %d %d %d %d\n", a, b, c, *p, *q, *r); // 13 3 10 13 13 10

    q = pは a そのものではなく a へのポインタをコピーするので，pとqは同じaを指すようになります． *r = *pは p が指す a の値をコピーするので，r の指す c へ a のもつ値10が代入されます． その後，*p = 13により，aの値が13となります． この時，pとqはaを，rはcを指しているため，出力結果は 13 3 10 13 13 10 となります．

    p = qはポインタのコピーで，*p = *qはポインタが指す値のコピーです．

    &と*を組み合わせて使う¶

    &は変数や関数などの実体からアドレスを求める演算，*はポインタ，すなわちアドレスから実体を参照するための演算です． int a = 10;，int b = 20;，int *p = &a;の場合を考えましょう． このとき，*&aはa，*&pはpを表します． &*pはpと同じアドレスとなります． 一方で，&*aは整数aをアドレスとして間接参照を適用しようとしており，正しい式ではありません．

    *&pはpというポインタ変数を表すので，*&p = &b;という代入でpの指す先を変えることができます． ただし，&*pはアドレス値でありポインタ変数ではないため，&*p = &b;という代入はできません． 同じアドレス値を表していても，代入先にできる式かどうかは場合によります．

    ポインタへのインクリメント¶

    int a = 10;，int *p = &a;の場合，++*pは変数 a の値を1増やします． ここで後置の ++ 演算子は * 演算子より優先順位が高いため，*p++ は *(p++) と解釈され，ポインタ p へのインクリメントとなります． p が配列の要素を指すポインタだった場合は，次の要素を指すポインタへと更新されます． 単独の変数を指すポインタは1つ先まで進めることはできますが，進めた先を間接参照することはできません．配列の要素を指す場合以外は，ポインタをインクリメントしないようにしましょう． ポインタではなく a の値をインクリメントしたい場合は，(*p)++ と書く必要があります．

    2　関数で呼び出し元を書き換える¶

    関数内で引数の値を変更しても呼び出し元に影響しなかったのは，値のコピーを渡していたからです． 引数がポインタの場合はポインタの値のコピーが渡されますが，コピーされたポインタも同じ対象を指すので，間接参照を用いて呼び出し元の値を変更できます．

    void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

    関数 swap は，int型変数へのポインタ a と b を引数として，それらが指す変数の値を入れ替えます． ポインタを引数とすることで，呼び出し元の変数の値を変更しています．

    int x = 1;
int y = 2;
swap(&x, &y);
printf("x = %d, y = %d\n", x, y); // x = 2, y = 1

    swap(&x, &y) では，変数 x と y を指すポインタが引数として渡されます． 関数 swap 内では，a は x を，b は y を指します． temp = *a で tempへ1を退避し，*a = *b で xへ2を代入し，最後に*b = temp で yへ1を代入します． aとbはポインタなので，a = bと書いても局所的なポインタ値が変わるだけで，値の交換にはなりません．

    関数にポインタを渡すときの条件

    この回のswapは，aとbが有効なintを指していることを呼び出し側の責任とします．NULLや寿命の終わった変数のアドレスは渡しません．ポインタ引数なら何でも渡せるわけではありません．

    関数に複数の戻り値を持たせる¶

    通常，関数の戻り値は return で返す一つの値ですが，ポインタを用いることで複数の値を返すことができます．

    void decompose(double x, long *whole, double *fraction)
{
    *whole = (long)x;
    *fraction = x - *whole;
}

    関数 decompose は小数を受け取り，整数部分と小数部分に分けて返します． ただし，実際の引数は double x，long *whole，double *fraction の3つで，戻り値は void です． ポインタを引数として渡し，関数内でその指す先へ値を書き込めるようにして，戻り値のように扱っています．

    long n と double f をあらかじめ宣言してから decompose(3.14, &n, &f) と呼ぶと，n は3，f は約0.14になります． −3.14なら整数部は−3，小数部は約−0.14です． キャストは0方向へ小数部を切り捨てるので，床関数のように−4へ変わるわけではありません． なお，整数部分を取り出すのに long 型へのキャストを用いているので，longへの変換が範囲内に収まるよう，この例のxは有限で−100〜100とする必要があります． また，whole と fraction は有効な long と double を指している必要があります．

    関数から複数の情報を返す方法はこれだけではなく，第11回では構造体にまとめる方法も扱います．

    ポインタを戻り値として返す¶

    int *min_pointer(int *a, int *b)
{
    if (*a < *b) {
        return a;
    }
    return b;
}

    関数 min_pointer は2つのint型変数へのポインタを受け取り，参照先の値が小さい方のポインタを返します． 戻り値がint型変数へのポインタなので，関数の宣言も int *min_pointer となっています．

    int x = 9, y = 3;
int *result = min_pointer(&x, &y);

printf("%d\n", *result); // 3

    result = min_pointer(&x, &y);と呼ぶと，resultはyを指します． 返しているのは y の値3ではなく，その値がある場所です． *result = 0;と書けばyが0になります． 値が等しい場合，この実装ではb側を返します． 返した対象の寿命が呼び出し後も続いていることが必要です．

    ポインタが引数のとき，関数にはポインタの値のコピーが渡されるので，関数内でポインタそのものを別の場所を指すように変更しても，呼び出し元のポインタ変数は変わりません． 呼び出し元で引数に渡したポインタ変数を変更するには，次回扱う二重ポインタを用います．

    3　配列とポインタ¶

    C 言語において，配列とポインタは非常に関わりが深い概念です． 多くの場合，配列名は先頭要素へのポインタとして扱われます．

    int values[5] = {10, 11, 12, 13, 14};
int *p = values;
printf("%d %d %d\n", *p, *values, values[0]); // 10 10 10
printf("%d %d %d\n", *(p + 1), *(values + 1), values[1]); // 11 11 11

    int *p = values とすることで，ポインタ p に &values[0] が保存されます． ポインタ変数に1加算した p + 1 は「1バイト先」ではなく「次のint要素」を指します． values[i] と *(values + i) は同じ要素を表します．

    配列自体とポインタ変数は同じものではありません． 配列に対する sizeof は配列の全要素分の大きさを返しますが，ポインタに対する sizeof はポインタ自身のサイズを返します． 関数引数の int a[] は関数内では int *a として扱われ，配列の長さは保持しません．

    ポインタ演算は同じ配列内，または最後の要素の1つ先までに限ります． 1つ先のポインタはループの終了判定に使えますが，間接参照はできません． 別々の変数へのポインタを引き算して距離を調べることもしません．

    次の要素への移動量¶

    int values[5] = {10, 20, 30, 40, 50};
int *p = values; // *p = values[0]
int *q = p + 2; // *q = values[2]

    添字       0       1       2       3       4        1つ先
        ┌───────┬───────┬───────┬───────┬───────┐
        │ 10    │ 20    │ 30    │ 40    │ 50    │
        └───────┴───────┴───────┴───────┴───────┘
          ↑               ↑                       ↑
          p               q = p + 2                values + 5

    intが4バイトのとき，qはpから2要素，つまり8バイト先を指します． doubleならdoubleのサイズ，charなら1バイトが1要素分です． 同じ配列内なら--pや整数の減算で戻ることもできますが，先頭より前へ戻ることはできません．

    ポインタの差の計算や比較¶

    同じ配列の要素を指すポインタ同士であれば，差の計算や比較が可能です． q - pはアドレスの差ではなく，配列内での添え字の差です． 上記の例では2となります．

    ポインタの差の型はstddef.hで宣言されるptrdiff_tで，表示には%tdを使います． 例えばprintf("distance=%td\n", q - p);と書けます．

    比較も同様に，添え字の比較となります． 上記の例ではp < qは真，p == qは偽です． 配列の最後の要素の1つ先のポインタも，終了判定や差の計算に使えます．

    異なる配列の要素を指すポインタ間や変数との間で大小比較・引き算をすることはできません． また，ポインタ同士を足す演算や，ポインタを2倍する演算はありません．

    添字による走査とポインタによる走査¶

    配列の全ての要素を処理することを走査といいます． 配列の走査は添え字を使うこともできますし，ポインタを使うこともできます．

    以下は，配列aの全ての要素の和を，添え字による走査とポインタによる走査でそれぞれ求める例です．

    int a[5] = {2, 6, 1, 4, 7};

int sum_index = 0;
for (int i = 0; i < 5; ++i) { // 添え字による走査
    sum_index += a[i];
}

int sum_pointer = 0;
for (int *p = a; p != a + 5; ++p) { // ポインタによる走査
    sum_pointer += *p;
}
printf("%d %d\n", sum_index, sum_pointer);

    結果はどちらも20になります． 添え字による走査では，添え字iが5に到達するとfor文の繰り返し条件が偽となりループが終了します． ポインタによる走査では，pがa + 5に到達すると条件が偽になりループが終了します． この条件では配列の最後の要素の1つ先のポインタa + 5を用いていますが，上述の通りこの比較は認められます． ただし，*(a + 5) のように値を参照することはできません．

    配列とポインタの違い¶

    配列とポインタは同じように扱える場面も多いですが，そうでない場合もあります． 例えば配列 a について int *p = a とポインタpが宣言されていた場合を考えます．

    操作 配列a ポインタ変数p
    添え字によるアクセス a[i] は可能 p[i] は可能
    ++による次の要素の参照 a++，++a は不可 p++，++p は可能
    ポインタint *qの代入 a = q は不可 p = q は可能
    sizeof 配列全体のサイズ ポインタ自身のサイズ
    宣言時 配列全体の領域を確保 ポインタ値の領域を確保

    添え字によるアクセスについて，p[i] は *(p + i) と同じように解釈されます． pがa[0]を指していれば，p[i]はa[i]と同じです． なお，a[2]は*(a + 2)，*(2 + a)，2[a]とも同じ意味になりますが，後ろの2つは読みにくいため通常は使いません．

    多くの式で配列名は先頭要素へのポインタへと変換されますが，sizeof aや&aなどの例外もあります． &aは配列全体を指すポインタで，先頭要素を指す&a[0]とは型が異なります． 詳しい扱いは第9回で整理します．

    配列が関数の引数となるときの表記¶

    配列を関数の引数とするとき，int a[]と書いてもint *aと書いても，どちらもintへのポインタとして扱われます． 配列全体の複製ではなく先頭を指すポインタのみを渡すため，大きな配列でも引数として全要素をコピーする必要はありません．

    void set_one(int *a, int n)
{
    for (int i = 0; i < n; ++i) {
        a[i] = 1;
    }
}

    int a[] = {2, 3, 4} であるときに set_one(a, 3)を実行すると，aの要素が{1, 1, 1}へ変わります． 仮引数をint a[]と書いたときも同じです．

    関数内での意図しない値の変化を避けるため，仮引数をconst int *aとすれば，配列を読み込み専用にできます． どちらの仮引数表記でも配列の長さは別に渡す必要があります．

    4　文字列とconst¶

    宣言時に const をつけることで，変更不能な変数や配列を定義できます．

    char buffer[] = "cat";
const char *word = "cat";

    bufferは書き換え可能な配列です． wordは文字列リテラルを指しています． リテラルを書き換えてはいけないため，const char * を使います．

    const int *p はpを通して対象を書き換えない（*pを変えない），int *const p はpの指す先を変更しない（pを変えない），という違いがあります． 読み取り専用の配列を受ける関数では前者を使います． まとめると，以下の通りとなります．

    宣言 pの指す先の変更 pを通した要素の変更
    int *p 可能 可能
    const int *p 可能 不可
    int *const p 不可 可能
    const int *const p 不可 不可

    const int *pは，pの参照先が絶対に変わらないという意味ではありません． あくまでもこのポインタを通して書き換えない，という制約です． p が指しているint xが変更可能なら，x = 20といった代入は可能です．

    int x = 10;
const int *p = &x;

*p = 20; // NG
x = 20; // OK

    配列の初期化とリテラルへのポインタ¶

    先の例では，buffer はchar型の配列であり，wordは文字列リテラルへのポインタです． そのため，buffer[0] = 'C'は可能ですが，buffer = "dog"という配列全体への直接代入はできません． word = "dog"は可能で，wordが別の文字列リテラルを指すようになります． しかし，word[0] = 'C'という書き換えはできません． word = NULL;はポインタ値の変更として可能ですが，その後%sへ渡すことはできません．

    char buffer[] = "cat";
const char *word = "cat";

buffer[0] = 'C'; // OK
buffer = "dog"; // NG
printf("%s\n", buffer); // Cat

word[0] = 'C'; // NG
word = "dog"; // OK
printf("%s\n", word); // dog

    同じ内容の文字列リテラルは，処理系によっては同じ領域を共有する場合もありますが，別々になる場合もあるため，ポインタの==で内容の一致を判定してはいけません． リテラルが共有されるかどうかにかかわらず，リテラルの変更は未定義動作です． 読み取り専用領域にあるから必ず同じエラーが出る，という保証もありません．

    ポインタで文字列長を求める¶

    関数 pointer_length は文字列の先頭へのポインタを受け取り，その文字列の長さを返します．

    size_t pointer_length(const char *s)
{
    const char *start = s;
    while (*s != '\0') {
        ++s;
    }
    return (size_t)(s - start);
}

    まず s の位置を start に保存します． その後，s が指す要素が終端文字 \0 になるまで s を進め，そのときの s と start の差を返します． const char *なので*sを書き換えることはできませんが，ポインタsを進めることはできます． この関数は，終端が読み取り可能な同じ配列内にあり，差がptrdiff_tで表せる長さであることを前提にしています．

    なお，*s != '\0'は*sとも書けます． 終端文字 \0 の値は0なので，*s が \0 となったとき*sは偽となります．

    コピーの代入式を読む¶

    コピー先に十分な容量があり，コピー元が終端を持ち，両者が重ならないとき，次のループで終端も含めてコピーできます． dstとsrcは，それぞれ書き込み先・読み取り元を指す有効なポインタとします．

    while ((*dst = *src) != '\0') {
    ++dst;
    ++src;
}

    まず1文字を代入し，その代入した値が終端かどうかを調べます． 終端もコピーしてから条件が偽になるため，最後の0はコピー先へ入ります． 単にwhile (*src)の本体で非0の文字だけをコピーする形では，別途終端を書き込む処理が必要です．

    このwhileループはさらに短くwhile ((*dst++ = *src++) != '\0') { }とも書けます． *dst++は*(dst++)なので，移動前の要素に代入して両ポインタを進めます． この形では終端をコピーした後にも1つ進みます． 今回は読めることを目標にし，実装は容量検査を先に行う明確なループを基本にします． コピーで上書きするのは終端までなので，その後ろに古い文字が残っていても，表示は新しい終端で止まります．

    5　NULLと寿命¶

    NULLは「対象を指していない」ことを表すポインタ定数です． int *p = NULL; と初期化できますが，そのまま *p を読んだり書いたりしてはいけません． 文字列の終端'\0'とは役割が違います．

    関数内の通常の局所変数のアドレスを返すと，関数終了後には対象の寿命が終わっています． そのポインタを使ってはいけません． 「アドレスが表示できる」「前の値が残って見える」は有効な領域である証拠ではありません．

    NULLはstdio.hやstddef.hなどで利用できます． p == NULLは!pとも書けますが，非NULLなら必ず有効なポインタ，ということではありません． NULLの表示形式や内部表現がすべての環境で同じとは限らず，通常の整数のアドレス計算に置き換えてはいけません．

    問題 なぜ危険か この回での対処
    未初期化のint *pを使う 有効な対象が定まっていない 宣言時に有効なアドレスかNULLを入れる
    NULLを間接参照する 指す対象がない NULLかどうかを判定し，参照しない
    局所変数のアドレスを返す 関数終了後に寿命が終わる 呼び出し元の変数へ書くか，値を返す
    配列の外を読む 対象の範囲を超える 長さと境界を確認する
    リテラルを書き換える 言語仕様で変更不可 変更するならchar配列へコピー

    不正アクセスが必ず停止や特定のエラーになるとは限りません．危険な例を実行して結果を覚えるのではなく，「何を指すか・型は合うか・寿命は続いているか・範囲内か・書き込めるか」を確認します．

int sum_array(const int *a, int n)
{
    int total = 0;

        total += *(a + i);
    }
    return total;
}
int main(void)
{
    int x = 3, y = 8;
    int *p = &x;
    *p = 5;
    swap(&x, &y);
    printf("x=%d y=%d\n", x, y);
    int values[] = {10, 20, 30};
    printf("sum=%d\n", sum_array(values, 3));
    const char *word = "cat";
    printf("%c %s\n", *word, word + 1);
    return 0;
}

    pointers.c

    最後のword + 1は，元の文字列の2文字目を指します．そこから終端まで表示するのでatになります．

    例題の前半ではpの値は変わらず，指す先のxが3→5→8へ変わります．交換の一時変数tempが保持するのはアドレスではなく，元の整数5です．中盤のsum_arrayは配列のコピーを作らず，3要素を読み取って60を返します．constなのでこの関数を通して値を変えることはありません．

    最後の*wordは1文字なので%c，word + 1は終端まで続く文字列の開始位置なので%sに渡します．同じポインタに関係する式でも，式が文字の値なのか，文字列を指すポインタなのかで書式が異なります．

    ポインタの動きがよく分からない場合，まず紙に変数の箱とポインタの矢印を書き，代入ごとに箱の中身と矢印のどちらが変わるかを記録するといいでしょう． Visual Studioのデバッガでpと*pを確認する場合も，pが有効な対象を指していることを先に確かめます．
