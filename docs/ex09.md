## 課題1　最大要素の場所を返す

`FindMax`プロジェクトに`find_max.c`を作ります．この課題では，次の3つの小問を順に行い，同じファイルへ書き足します．

1. 課題1-1：二重ポインタを通して，整数とポインタを書き換える．
2. 課題1-2：講義の`find_max`で，最大要素の場所を出力引数に受け取る．
3. 課題1-3：最大値を値で返す関数と，場所で返す関数を比べる．

### 課題1-1　二重ポインタの代入を追う

二重ポインタを通して整数とポインタ変数を書き換えるプログラムを作成し，各代入の後で変わった変数と，`p`が指している変数を確認してください．

プログラムが満たすこと（仕様）は次のとおりです．

- 講義の`void redirect(int **destination, int *target)`を`main`の前に定義する．
- 関数`void trace(void)`を作る．`trace`では，`int x = 10;`，`int y = 30;`，`int *p = &x;`，`int **pp = &p;`と宣言する．
- `trace`では，次の5つの代入・呼び出しを順に行い，それぞれの直後に`printf("x=%d y=%d p_is_x=%d p_is_y=%d\n", x, y, p == &x, p == &y);`を実行する．
    1. `**pp = 20;`
    2. `*pp = &y;`
    3. `**pp = 40;`
    4. `redirect(&p, &x);`
    5. `*p = 50;`
- `main`では`trace();`を呼ぶ．

表示は次のようになります．

~~~text
x=20 y=30 p_is_x=1 p_is_y=0
x=20 y=30 p_is_x=0 p_is_y=1
x=20 y=40 p_is_x=0 p_is_y=1
x=20 y=40 p_is_x=1 p_is_y=0
x=50 y=40 p_is_x=1 p_is_y=0
~~~

`**pp`への代入は2段先の整数を変え，`*pp`への代入は1段先のポインタ変数`p`を変えます．2行目で`x`と`y`がどちらも変わらないのは，整数ではなく`p`に保存されたアドレスを変えたからです．`pp`自身は最初から最後まで`p`を指しています．

`redirect`の`destination`は値渡しで作られたコピーですが，`&p`のコピーなので同じ`p`を指します．そのため`*destination = target;`で呼び出し元の`p`が変わります．

### 課題1-2　見つからない場合と同点の場合

講義の`find_max`で最大要素の場所を受け取るプログラムを作成し，検索範囲が異なる場合，検索に失敗する場合，最大値が2つある場合の結果を確認してください．

プログラムが満たすこと（仕様）は次のとおりです．

- 講義の`int find_max(int a[], int n, int **out)`を`main`の前に定義する．
- 関数`void try_find(int x0, int x1, int x2, int n)`を作る．`try_find`は次の処理を行う．
    - `int a[] = {x0, x1, x2};`と，`int *answer = &a[1];`を宣言する．`answer`に前の結果が残っている状態を表すため，わざと`NULL`以外で初期化している．
    - `int ok = find_max(a, n, &answer);`を実行し，`printf("n=%d ok=%d null=%d\n", n, ok, answer == NULL);`で表示する．
    - `ok`が1のときだけ，`printf("max=%d index=%td\n", *answer, answer - a);`で表示し，`*answer = 99;`を実行する．
    - 最後に`printf("a=%d %d %d\n", a[0], a[1], a[2]);`で配列を表示する．
- `n`は3以下とする．
- `main`では，課題1-1の`trace();`に続けて，次の表の順に`try_find`を呼ぶ．

| `x0`，`x1`，`x2` | `n` |
| --- | ---: |
| 7，12，4 | 3 |
| 7，12，4 | 1 |
| 7，12，4 | 0 |
| 7，12，4 | −1 |
| 12，12，4 | 3 |

課題1-1の5行に続けて，次の13行が表示されます．

~~~text
n=3 ok=1 null=0
max=12 index=1
a=7 99 4
n=1 ok=1 null=0
max=7 index=0
a=99 12 4
n=0 ok=0 null=1
a=7 12 4
n=-1 ok=0 null=1
a=7 12 4
n=3 ok=1 null=0
max=12 index=0
a=99 12 4
~~~

??? tip "ヒント"

    `*answer`を読むのは，戻り値が1のときだけです．`answer - a`はポインタの差なので`%td`で表示します．

`n=1`では先頭の要素だけが検索に使われるので，`a[1]`の12は候補になりません．`n`が0以下なら要素を読まずに失敗します．`find_max`は最初に`*out = NULL;`を実行するので，失敗したときに`answer`へ前のアドレスが残りません．失敗した関数が出力先をどう扱うかは関数ごとの仕様で，この関数では`NULL`にすると決めています．

最大値が2つあるときは，`a[i] > *best`という比較なので最初の要素（添字0）が選ばれます．`>=`にすると最後の要素が選ばれます．

`find_max`は，`n`が実際の要素数以下かどうかを判定できません．負の`n`を失敗として扱えることと，大きすぎる`n`が安全であることは別です．`n`に4以上を渡す呼び出しは書きません．また，`out`には有効なポインタ変数のアドレスを渡します．出力結果として`NULL`を受け取ることと，`out`自体へ`NULL`を渡すことは違います．

### 課題1-3　値を返す版と場所を返す版

最大値を値で返す関数と場所で返す関数を使うプログラムを作成し，返された場所を通して配列を書き換えたときに，保存した値と配列がどう変わるかを確認してください．

プログラムが満たすこと（仕様）は次のとおりです．

- 講義の`int max_value(const int a[], int n)`と`int *max_pointer(int a[], int n)`を`main`の前に定義する．`max_value`は`n`が1以上のときだけ使い，`max_pointer`は`n`が0以下なら`NULL`を返す．
- 関数`void try_return(int x0, int x1, int x2)`を作る．`try_return`は次の処理を行う．
    - `int a[] = {x0, x1, x2};`を宣言し，`int saved = max_value(a, 3);`と`int *found = max_pointer(a, 3);`を実行する．
    - `found`が`NULL`でなければ，`printf("before=%d %d\n", saved, *found);`，`*found = 99;`，`printf("after=%d %d\n", saved, *found);`を順に実行する．
    - 最後に`printf("a=%d %d %d\n", a[0], a[1], a[2]);`で配列を表示する．
- `main`では，課題1-2の呼び出しに続けて`try_return(7, 12, 4);`と`try_return(-7, -12, -4);`を呼ぶ．
- 続けて`main`で`int a[] = {7, 12, 4};`を宣言し，`printf("empty=%d\n", max_pointer(a, 0) == NULL);`を実行する．

課題1-2の表示に続けて，次の7行が表示されます．

~~~text
before=12 12
after=12 99
a=7 99 4
before=-4 -4
after=-4 99
a=-7 -12 99
empty=1
~~~

`saved`は最大値を求めた時点の整数のコピーなので，`*found = 99;`の後も12のままです．一方，`found`は元の配列の要素を指しているので，`*found`への代入は`a`へ反映されます．`max_pointer`が返すのは関数内の変数`best`自身のアドレスではなく，`best`に保存されていた，呼び出し元の配列の要素のアドレスです．

全部が負の配列でも正しく求まるのは，最大候補を0ではなく先頭の要素から始めているからです．空の入力に対して，`max_value`には意味のある戻り値がないので`n=0`を渡しません．`max_pointer`は`NULL`で失敗を表せます．

課題1全体の表示は次のようになります．

~~~text
x=20 y=30 p_is_x=1 p_is_y=0
x=20 y=30 p_is_x=0 p_is_y=1
x=20 y=40 p_is_x=0 p_is_y=1
~~~

## 課題2　表示順を変更する

`Names`プロジェクトに`names.c`を作ります．この課題では，次の2つの小問を順に行い，同じファイルへ書き足します．

1. 課題2-1：ポインタ配列の要素を交換して，文字列の表示順を変える．
2. 課題2-2：変更可能な文字配列をポインタ配列から書き換える．

### 課題2-1　ポインタを交換する

ポインタ配列の2つの要素を交換して文字列の表示順を変えるプログラムを作成し，3通りの交換と，表示に文字を付け足しても文字列本体が変わらないことを確認してください．

プログラムが満たすこと（仕様）は次のとおりです．

- 講義の`void swap_names(const char *names[], int i, int j)`と`void print_each(const char *prefectures[], int n)`を`main`の前に定義する．`i`と`j`は有効な添字とする．
- 関数`void try_swap(int i, int j, int times)`を作る．`try_swap`は次の処理を行う．
    - `const char *names[] = {"Tokyo", "Osaka", "Nagoya"};`を宣言する．
    - `swap_names(names, i, j);`を`times`回くり返す．
    - `printf("swap(%d, %d) x%d:", i, j, times);`の後，3つの文字列をそれぞれ`printf(" %s", names[k]);`で表示し，最後に改行する．
- `main`では，`try_swap(0, 2, 1);`，`try_swap(1, 1, 1);`，`try_swap(0, 2, 2);`の順に呼ぶ．
- 続けて`main`で`const char *names[] = {"Tokyo", "Osaka", "Nagoya"};`を宣言し，`print_each(names, 3);`を呼んでから，`printf("%s length=%zu\n", names[2], strlen(names[2]));`を実行する．

表示は次のようになります．

~~~text
swap(0, 2) x1: Nagoya Osaka Tokyo
swap(1, 1) x1: Tokyo Osaka Nagoya
swap(0, 2) x2: Tokyo Osaka Nagoya
Tokyo-ken
Osaka-ken
Nagoya-ken
Nagoya length=6
~~~

`try_swap`は呼ばれるたびに`names`を初期値から作るので，3つの場合はそれぞれ初期状態から試したことになります．同じ添字の交換では何も変わらず，同じ交換を2回行うと元の順に戻ります．

各文字列の長さが違っても交換できるのは，文字を移動せず，大きさが一定のポインタ値を交換しているからです．`print_each`は表示のときに`-ken`を付けるだけで，文字列の末尾へ書き足していません．そのため`strlen(names[2])`は6のままです．

### 課題2-2　指す先の文字を書き換える

ポインタ配列を通して，変更可能な文字配列の先頭の文字を大文字に書き換えるプログラムを作成し，元の配列の内容が変わることを確認してください．

プログラムが満たすこと（仕様）は次のとおりです．

- 関数`void capitalize(char *words[], int n)`を作る．`words[0]`〜`words[n - 1]`が指す文字列の先頭の文字を，`toupper`で大文字に書き換える．`toupper`の戻り値は`int`なので，`char`へキャストして代入する．
- `main`では，課題2-1の表示に続けて，`char city0[] = "tokyo";`，`char city1[] = "osaka";`，`char *editable[] = {city0, city1};`を宣言し，`capitalize(editable, 2);`を呼ぶ．
- 続けて，`printf("%s %s\n", city0, city1);`と`printf("same=%d\n", editable[0] == city0);`を実行する．

課題2-1の7行に続けて，次の2行が表示されます．

~~~text
Tokyo Osaka
same=1
~~~

??? tip "ヒント"

    `toupper`を使うには`ctype.h`をインクルードします．引数は`(unsigned char)words[i][0]`のように変換して渡します．

`capitalize`は`editable`のポインタ値を変えていません．各ポインタが指している`city0`や`city1`の文字を変えています．そのため，`city0`と`city1`を直接表示しても先頭が大文字になっています．

`names`の要素は文字列リテラルを指す`const char *`なので，`names[0][0]`のように文字を書き換えることはできません．`const`を外したりキャストしたりして書き換えることもしません．文字を変えたいときは，この課題のように変更可能な配列を用意します．なお，`char *`の配列`editable`を，そのまま`const char **`の引数（`swap_names`など）へ渡すことはできません．関数と配列の要素型をそろえます．

課題2全体の表示は次のようになります．

~~~text
swap(0, 2) x1: Nagoya Osaka Tokyo
swap(1, 1) x1: Tokyo Osaka Nagoya
swap(0, 2) x2: Tokyo Osaka Nagoya
Tokyo-ken
Osaka-ken
Nagoya-ken
Nagoya length=6
Tokyo Osaka
same=1
~~~

## 課題3　行ごとの平均

`MatrixMean`プロジェクトに`matrix_mean.c`を作ります．この課題では，次の2つの小問を順に行い，同じファイルへ書き足します．

1. 課題3-1：2行3列の配列の行ごとの平均を表示する．
2. 課題3-2：配列へのポインタで受け取り，全体の平均を求める．

列数は`enum { COLS = 3 };`で定めます．要素の値は0〜100とします．

### 課題3-1　行ごとの平均を表示する

二次元配列の行ごとの平均を表示するプログラムを作成し，3通りの配列と，行数を変えた場合の結果を確認してください．

プログラムが満たすこと（仕様）は次のとおりです．

- 関数`void print_means(int a[][COLS], int rows)`を作る．先頭から`rows`行について，各行の合計を`int`で求め，`(double)total / COLS`を`printf(" %.1f", ...)`で表示する．改行はしない．
- 関数`void show(int a[][COLS], int rows)`を作る．`show`は`printf("rows=%d:", rows);`で表示し，`print_means(a, rows);`を呼んでから改行する．
- `rows`は0〜2とする．
- `main`では，次の3つの配列を宣言する．

    ~~~c
    int a[2][COLS] = {{1, 2, 3}, {4, 5, 6}};
    int b[2][COLS] = {{0, 0, 0}, {100, 100, 100}};
    int c[2][COLS] = {{1, 1, 2}, {2, 2, 3}};
    ~~~

- `main`では，`show(a, 2);`，`show(a, 1);`，`show(a, 0);`，`show(b, 2);`，`show(c, 2);`の順に呼ぶ．

表示は次のようになります．

~~~text
rows=2: 2.0 5.0
rows=1: 2.0
rows=0:
rows=2: 0.0 100.0
rows=2: 1.3 2.3
~~~

`rows=0`では行を1つも処理しないので，平均は表示されません．`rows`に3を渡すと存在しない3行目へ進むので，そのような呼び出しは書きません．

`(double)total`の変換をせずに`total / COLS`とすると整数除算になり，小数部分が失われます．表示桁数を増やしても，除算で失った情報は戻りません．

### 課題3-2　配列へのポインタで受け取る

配列へのポインタで二次元配列を受け取り，行ごとの平均と全体の平均を求めるプログラムを作成し，課題3-1と同じ平均が求まることと，全体の平均が求められない場合の戻り値を確認してください．

プログラムが満たすこと（仕様）は次のとおりです．

- 関数`void print_means_pointer(int (*a)[COLS], int rows)`を作る．処理と表示は`print_means`と同じで，仮引数の書き方だけが違う．
- 関数`int overall_mean(int (*a)[COLS], int rows, double *mean)`を作る．`rows`が0以下なら`*mean`を変更せずに0を返す．そうでなければ，全要素の合計を要素数`(double)rows * COLS`で割った値を`*mean`へ書き込み，1を返す．
- 関数`void show_overall(int (*a)[COLS], int rows)`を作る．`show_overall`は`double mean = 0.0;`を宣言して`int ok = overall_mean(a, rows, &mean);`を実行し，`printf("rows=%d: ok=%d overall=%.2f\n", rows, ok, mean);`で表示する．
- `main`では，課題3-1の表示に続けて，`printf("pointer:");`，`print_means_pointer(a, 2);`，改行の表示を順に行う．
- 続けて，`show_overall(a, 2);`，`show_overall(a, 1);`，`show_overall(a, 0);`，`show_overall(c, 2);`の順に呼ぶ．

課題3-1の5行に続けて，次の5行が表示されます．

~~~text
pointer: 2.0 5.0
rows=2: ok=1 overall=3.50
rows=1: ok=1 overall=2.00
rows=0: ok=0 overall=0.00
rows=2: ok=1 overall=1.83
~~~

仮引数の`int a[][COLS]`は`int (*a)[COLS]`と同じ型なので，結果は変わりません．括弧を落として`int *a[COLS]`と書くと，仮引数は`int **`になり，別の型です．列数は，次の行までの大きさを決めるために必要です．行数は型に残らないので`rows`として別に渡します．

`rows=0`では要素の個数が0なので，割り算をせずに失敗を返します．`ok=0`の行の`overall=0.00`は，`show_overall`が初期化した値がそのまま表示されたもので，平均ではありません．行平均を表示する関数が`rows=0`で何も表示しないことと，平均値を返す関数が空の入力を失敗として扱うことは，別の仕様です．

`a`の全体の平均3.5は，行平均2.0と5.0の平均と一致します．これはどの行も要素数が同じだからです．行の長さが異なる場合は，発展1で確かめます．

課題3全体の表示は次のようになります．

~~~text
rows=2: 2.0 5.0
rows=1: 2.0
rows=0:
rows=2: 0.0 100.0
rows=2: 1.3 2.3
pointer: 2.0 5.0
rows=2: ok=1 overall=3.50
rows=1: ok=1 overall=2.00
rows=0: ok=0 overall=0.00
rows=2: ok=1 overall=1.83
~~~

## 課題4　二次元配列の行を交換する

3行9列の文字配列の2つの行を，終端を含む9個の`char`ずつ交換するプログラムを作成し，交換の前後で各行の9要素がどう変わるかを確認してください．

`SwapRows`プロジェクトに`swap_rows.c`を作ります．プログラムが満たすこと（仕様）は次のとおりです．

- 列数を`enum { WIDTH = 9 };`で定める．
- 関数`void swap_rows(char names[][WIDTH], int i, int j)`を作る．`i`行と`j`行の`WIDTH`個の要素を，1個ずつ一時変数を使って交換する．`i`と`j`は有効な添字とする．
- 関数`void show(const char *label, char names[][WIDTH], int n)`を作る．`show`は`printf("%s:", label);`で表示した後，`n`行それぞれについて空白を1つ表示し，その行の`WIDTH`個の要素を順に表示する．値が0の要素は`.`，それ以外は`%c`で表示する．最後に改行する．
- `main`では`char names[][WIDTH] = {"toyama", "ishikawa", "fukui"};`を宣言し，次の順に処理する．
    1. `show("start", names, 3);`
    2. `swap_rows(names, 1, 2);`の後に`show("swap 1 2", names, 3);`を呼び，さらに`printf("%s %s %s\n", names[0], names[1], names[2]);`を実行する．
    3. `swap_rows(names, 1, 2);`の後に`show("swap 1 2", names, 3);`
    4. `swap_rows(names, 1, 1);`の後に`show("swap 1 1", names, 3);`
- 続けて`main`で`char empty[][WIDTH] = {"toyama", "ishikawa", ""};`を宣言し，`swap_rows(empty, 1, 2);`の後に`show("empty", empty, 3);`を呼ぶ．

表示は次のようになります．

~~~text
start: toyama... ishikawa. fukui....
swap 1 2: toyama... fukui.... ishikawa.
toyama fukui ishikawa
swap 1 2: toyama... ishikawa. fukui....
swap 1 1: toyama... ishikawa. fukui....
empty: toyama... ......... ishikawa.
~~~

??? tip "ヒント"

    行は配列なので，`names[i] = names[j];`とは書けません．列`c`を0〜`WIDTH`−1まで進め，各文字を一時変数で交換します．終端や初期化で0になった残りの要素も含めて交換します．

`WIDTH`は，最長の`ishikawa`の8文字と終端の1個を合わせた9です．短い行も9個分が確保され，初期化で余った要素は0になります．`.`の位置が，その0の要素です．

交換の後も，各行の開始位置は変わっていません．その位置に保存されている内容が変わっています．課題2では文字列本体を動かさず，配列中のポインタを変えました．ポインタの交換は文字列の長さに関係なく一定回数の代入で済みますが，行の交換は`WIDTH`回の反復が必要です．一方，二次元配列は本体を連続した固定幅の領域として確保できます．

短い`fukui`の5文字だけを`ishikawa`の先頭へ上書きすると，終端を書かない限り`fukuiawa`のように余分な文字が残ります．固定幅全体を交換すれば，長さが違う場合や空文字列の場合も正しく入れ替わります．

## 発展1　長さが異なる行を扱う

長さが異なる2つの行をポインタ配列と長さの配列で管理し，行と長さを組にして交換するプログラムを作成し，交換の前後の各行の合計と平均，全要素の平均，交換後に書き換わる元の配列を確認してください．

`RaggedRows`プロジェクトに`ragged_rows.c`を作ります．プログラムが満たすこと（仕様）は次のとおりです．

- 関数`int row_sum(const int *row, int length)`を作る．`row`から`length`個の要素の合計を返す．
- 関数`void print_rows(int **rows, const int lengths[], int n)`を作る．各行`r`について，合計`sum`を`row_sum`で求め，`printf("row%d sum=%d mean=%.2f\n", r, sum, (double)sum / lengths[r]);`で表示する．
- 関数`double total_mean(int **rows, const int lengths[], int n)`を作る．全行の合計を，全行の要素数の合計で割った値を返す．
- 関数`void swap_ragged(int *rows[], int lengths[], int i, int j)`を作る．`rows[i]`と`rows[j]`を交換し，`lengths[i]`と`lengths[j]`も交換する．
- `main`では，講義と同じ次の宣言をする．

    ~~~c
    int row0[] = {1, 2, 3};
    int row1[] = {4, 5};
    int *rows[] = {row0, row1};
    int lengths[] = {3, 2};
    int **p = rows;
    ~~~

- `main`では，次の順に処理する．
    1. `print_rows(p, lengths, 2);`
    2. `printf("total mean=%.2f\n", total_mean(p, lengths, 2));`
    3. `swap_ragged(rows, lengths, 0, 1);`の後に`print_rows(p, lengths, 2);`
    4. `p[1][0] = 10;`の後に`printf("row0[0]=%d row1[0]=%d\n", row0[0], row1[0]);`

表示は次のようになります．

~~~text
row0 sum=6 mean=2.00
row1 sum=9 mean=4.50
total mean=3.00
row0 sum=9 mean=4.50
row1 sum=6 mean=2.00
row0[0]=10 row1[0]=4
~~~

全要素の平均は`15 / 5 = 3.0`です．行平均2.0と4.5を単純に平均した3.25とは一致しません．要素数が異なる場合は，各行の合計と個数を集計してから割ります．

ポインタ配列`rows`は`int **`で指せます．`p[1]`の場所には実際に`int *`が保存されているからです．ポインタ配列を用意しても`row0`や`row1`の内容はコピーされません．交換後の`p[1]`は`row0`を指しているので，`p[1][0] = 10;`で変わるのは変数`row0`の先頭です．表示の`row0`，`row1`は「現在の0行目，1行目」であり，変数名の`row0`，`row1`とは別です．

ポインタだけを交換して長さを交換しないと，2要素の行を長さ3として読み，範囲外にアクセスします．行のポインタと有効な要素数は，必ず組で扱います．

## 発展2　配列とポインタの型を確かめる

二次元配列，ポインタ配列，配列へのポインタ，一次元配列について，要素の個数と，ポインタを1つ進めたときの単位を表示するプログラムを作成し，それぞれの型が何を数えるかを確認してください．

`ArrayTypes`プロジェクトに`array_types.c`を作ります．プログラムが満たすこと（仕様）は次のとおりです．

- 列数を`enum { COLS = 3 };`で定める．
- 関数`int flat_at(const int flat[], int r, int c)`を作る．幅`COLS`の行列として，行`r`・列`c`の要素`flat[r * COLS + c]`を返す．
- `main`では，次の宣言をする．

    ~~~c
    int a[2][COLS] = {{1, 2, 3}, {4, 5, 6}};
    int *rows[2] = {a[0], a[1]};
    int (*q)[COLS] = a;
    int flat[] = {1, 2, 3, 4, 5, 6};
    ~~~

- `main`では，次の7つの`printf`を順に実行する．

    ~~~c
    printf("ints_a=%zu ints_row=%zu pointers_rows=%zu\n",
           sizeof a / sizeof(int), sizeof a[0] / sizeof(int), sizeof rows / sizeof(int *));
    printf("row_count=%zu col_count=%zu\n", sizeof a / sizeof a[0], sizeof a[0] / sizeof a[0][0]);
    printf("step_row=%td step_int=%td\n", (a + 1) - a, (a[0] + 1) - a[0]);
    printf("q=%d same_row=%d\n", q[1][2], q + 1 == &a[1]);
    printf("rows=%d same_row=%d\n", rows[1][2], rows[1] == a[1]);
    printf("same_place=%d\n", (void *)&a == (void *)&a[0][0]);
    printf("flat=%d a=%d\n", flat_at(flat, 1, 2), a[1][2]);
    ~~~

表示は次のようになります．

~~~text
ints_a=6 ints_row=3 pointers_rows=2
row_count=2 col_count=3
step_row=1 step_int=1
q=6 same_row=1
rows=6 same_row=1
same_place=1
flat=6 a=6
~~~

`sizeof a`は`6 * sizeof(int)`，`sizeof a[0]`は`3 * sizeof(int)`，`sizeof rows`は`2 * sizeof(int *)`です．バイト数そのものは環境によって異なるので，ここでは`sizeof(int)`や`sizeof(int *)`で割って個数として表示しています．`rows`にはポインタしか含まれず，指す先の`int`の大きさは`sizeof rows`に入りません．`sizeof a / sizeof a[0]`で行数を求められるのは，`main`で宣言した配列そのものに対してだけです．関数の仮引数はポインタなので，この式では行数を求められません．

`a + 0`の型は`int (*)[3]`で，1つ進むと次の行（`int`3個分）へ進みます．`a[0] + 0`の型は`int *`で，1つ進むと次の`int`へ進みます．どちらも差は1です．ポインタの差は，バイト数ではなく，指す型の要素数で表されます．

`&a`（型は`int (*)[2][3]`），`&a[0]`（`int (*)[3]`），`&a[0][0]`（`int *`）は，どれも格納領域の先頭に対応します．`same_place=1`はそれを`void *`に変換して比べた結果です．しかし型は違うので，関数の引数として自由に取り替えられるわけではありません．特に，`a`も`&a`も`int **`ではありません．なお，`int (*q)[3]`に対する`&q`の型は`int (**)[3]`で，`q`というポインタ変数自身を指します．

`int *p = &a[0][0];`として`p[0]`〜`p[5]`を走査する書き方は使いません．最初の行の範囲を越えるためです．二次元配列は`a[r][c]`で走査します．一次元として扱いたいなら，`flat`のように最初から一次元配列を用意し，`r * COLS + c`で添字を計算します．
