# 第5回　配列と関数


## 到達目標

- 配列と二次元配列を範囲内で操作できる．
- 関数を定義し，引数と戻り値を使える．
- 変数のスコープと引数の値渡しを説明できる．


## 1　同じ型の値をまとめる

### 前回とのつながりと準備 { #environment }

第4回ではカウンタを変えながら同じ処理を繰り返しました．今回は，カウンタを「何番目のデータを扱うか」に利用します．さらに，繰り返し使う処理を関数にまとめ，`main`から呼び出します．**データのまとまりが配列，処理のまとまりが関数**と考えると役割を整理できます．

作業場所は`PL1`の下の`week05`です．[第1回](lec01.md#hello)と同じく，Visual Studioの空のプロジェクトへ`.c`ファイルを追加し，Cとしてコンパイル，C17，警告レベル4を確認します．短いコード片は指定された関数内に置き，完全なプログラムは別のプロジェクトで扱います．`main`は1プロジェクトに1つです．

今回の関数は1つのソースファイルに書きます．`main`の中へ別の関数の定義を書かず，`main`と並ぶ位置へ置いてください．複数のファイルへ分割する方法は第12回で学びます．

### 要素を番号で指定する

5人分の点数を別々の変数にする代わりに，配列を使います．配列は同じ型の要素が連続した領域に並ぶものです．

~~~c
int scores[5] = {72, 85, 60, 93, 80};
~~~

要素は `scores[0]` から `scores[4]` です．添字は0から始まります．`scores[2] = 65;` で3番目の要素を変更できます．`int a[5] = {0};` なら全要素を0で初期化します．初期化しない関数内の配列の要素は，値を入れてから読みます．

| 添字 | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 初期値 | 72 | 85 | 60 | 93 | 80 |
| `scores[2] = 65`の後 | 72 | 85 | 65 | 93 | 80 |

宣言の`scores[5]`は「5個用意する」という意味ですが，式の`scores[2]`は「添字2の1個を選ぶ」という意味です．同じ角括弧でも，宣言と要素へのアクセスを区別します．Cは0始まりです．他の言語には1始まりのものもあるため，数学の「第1要素」とCの「添字0」を対応させましょう．

~~~c
for (int i = 0; i < 5; ++i) {
    printf("scores[%d]=%d\n", i, scores[i]);
}
~~~

添字には定数だけでなく`i`のような整数の式も使えます．この例では`i`が0から4へ変わり，すべての要素を順に読みます．要素数5の配列では，最後の添字は4です．

### 初期化の方法

~~~c
int a[3] = {12, 3, 5};
int b[] = {12, 3, 5};
int c[5] = {1, 1};
int d[5] = {0};
~~~

`a`と`b`はどちらも3要素です．初期化子がある場合，`b`のように要素数を省略すると，値の個数から決まります．`c`は{1, 1, 0, 0, 0}，`d`はすべて0になります．**初期化子を書いたうえで省略した要素は0**ですが，通常の局所配列を`int a[3];`と宣言するだけでは0になりません．

後から値を入れるなら，`a[0] = 12;`のように各要素へ代入します．まだ値を入れていない`a[0]`に対する`a[0]++`も，最初に値を読むので使用できません．「よく分からない値が出るだけ」と考えず，未初期化の値は読まないことを守ってください．

!!! warning "要素数と最後の添字は違う"

    `scores[5]`は範囲外です．Cは通常，実行時に添字の範囲を自動検査しません．ビルドが成功しても正しいとは限りません．ループ条件は`i < 5`とします．

`sizeof scores / sizeof scores[0]` は，配列そのものが見える場所で要素数を計算する式です．配列を `a = b;` のように丸ごと代入することはできません．コピーには要素ごとの代入などを使います．

同様に，2つの配列を`a == b`と比較しても，全要素の値の一致を調べることにはなりません．同じ長さの配列の内容を比較するなら，各添字の要素を順に比較します．配列名が式の中で先頭の要素を指す情報として扱われる仕組みは第8回で学びます．

### メモリ上では連続して並ぶ

`int`が4バイトの場合，`int a[3] = {12, 3, 5};`は合計12バイトを占めます．次は架空のアドレスによる概念図です．

~~~text
先頭アドレス    0x1000         0x1004         0x1008
              ┌────────────┬────────────┬────────────┐
要素          │ a[0] = 12  │ a[1] = 3   │ a[2] = 5   │
              └────────────┴────────────┴────────────┘
サイズ           4バイト        4バイト        4バイト
~~~

第2回の別々の変数とは異なり，**配列の要素は添字の順に連続して並ぶ**ことが保証されます．次のコードで先頭アドレスを表示できます．具体的な値は実行ごとに変わり得ます．`%p`に合わせる`(void *)`の詳細は第8回で扱います．

~~~c
int a[3] = {12, 3, 5};
for (int i = 0; i < 3; ++i) {
    printf("a[%d]=%d address=%p\n", i, a[i], (void *)&a[i]);
}
printf("array=%zu element=%zu count=%zu\n",
       sizeof a, sizeof a[0], sizeof a / sizeof a[0]);
~~~

`int`が4バイトなら最後の行は`array=12 element=4 count=3`です．アドレスの差を目で確認する際は16進数の繰り上がりに注意します．アドレスの具体値をプログラムに書き込む必要はありません．`sizeof`の結果は`size_t`型なので，表示書式は`%zu`です．

### 範囲外のアクセスは実行して確かめない

`float a[3] = {0.5f, 0.3f, 0.8f};`に対して`a[3]`を読むのは範囲外アクセスです．正しい添字は0，1，2だけです．結果は未定義動作であり，「必ずエラーが出る」「ランダムな値が1つ出る」とも決められません．負の添字も使用しません．配列の外へアクセスする例は，原因を説明して正しい添字へ直す読解問題として扱います．

## 2　二次元配列

~~~c
int table[2][3] = {{1, 2, 3}, {4, 5, 6}};
~~~

「3要素の配列が2つ」と考えます．`table[1][2]` は6です．行を選び，その行の列を選びます．要素は行単位に連続して並びます．二重ループでは，それぞれの添字に対応する上限を使います．

### 表の見方とメモリの並び

| 行＼列 | 0 | 1 | 2 |
| --- | ---: | ---: | ---: |
| 0 | 1 | 2 | 3 |
| 1 | 4 | 5 | 6 |

~~~text
メモリの順：table[0][0] [0][1] [0][2] │ [1][0] [1][1] [1][2]
値：             1       2      3   │    4      5      6
                 └─── 0行目 ───┘        └─── 1行目 ───┘
~~~

最後の添字（列）が変わる方向に要素が連続します．全体の要素数は2×3＝6ですが，`table[0][3]`は0行目の範囲外です．メモリ上で次の行が続いていても，正しく`table[1][0]`と書く必要があります．

~~~c
for (int row = 0; row < 2; ++row) {
    for (int col = 0; col < 3; ++col) {
        printf("%d ", table[row][col]);
    }
    printf("\n");
}
~~~

外側を列，内側を行に変えると，訪問順が変わります．ただし`table[row][col]`の第1添字は常に行，第2添字は列です．ループの順を変えたからといって添字を逆にするわけではありません．

### 三次元配列へ広げる

`int data[2][3][4] = {0};`は，「3行4列のまとまりが2つ」と考えられる24要素の配列です．添字の範囲は順に0〜1，0〜2，0〜3です．例えば`data[1][2][3]`が最後の要素です．

~~~c
int data[2][3][4] = {0};
data[1][2][3] = 7;
printf("last=%d count=%zu\n", data[1][2][3],
       sizeof data / sizeof data[0][0][0]);
~~~

表示は`last=7 count=24`です．すべてを訪問するなら3つのループを入れ子にします．次元が増えても「各添字の範囲を守る」「最後の添字の方向に連続する」という考え方は同じです．

!!! note "Visual Studioで使う配列の大きさ"

    この講義ではリテラルか`enum`の定数で大きさを指定します．例えば`enum { COUNT = 5 };`と`int a[COUNT];`です．MSVCのCでは可変長配列（`VLA`）を使えません．Cの`const int n = 5;`を配列の固定長定数として使う方法にも頼りません．実行時に大きさを決める方法は第13回で学びます．

    MSVCの対応については[定義済みマクロの説明（__STDC_NO_VLA__）](https://learn.microsoft.com/en-us/cpp/preprocessor/predefined-macros?view=msvc-170)でも確認できます．

## 3　処理に名前を付ける

### 定義・呼び出し・戻り値

~~~c
int square(int x)
{
    return x * x;
}
~~~

関数は引数を受け取り，処理した結果を戻り値として返します．`int y = square(4);` なら`y`は16です．`x`は**仮引数**，4は**実引数**です．この例は，`x*x`が`int`の範囲に収まる値に限定します．

呼び出すと，実引数の値を仮引数へ渡して関数本体を実行し，`return`で呼び出し元へ戻ります．呼び出し元では，`square(4)`という式の値が16になり，それが`y`へ代入されます．関数の定義を書いただけでは，本体をその場で実行するわけではありません．

| 部分 | `square`の例 | 役割 |
| --- | --- | --- |
| 戻り値の型 | 最初の`int` | 呼び出し元へ返す値の型 |
| 関数名 | `square` | 呼び出すときの名前 |
| 仮引数 | `int x` | 呼び出し時の値を受け取る変数 |
| 本体 | 波括弧の中 | 実行する処理 |
| `return` | `return x * x;` | 計算した値を返し，呼び出しを終える |

### 小数の絶対値を求める

~~~c
double absolute(double src)
{
    double dst;
    if (src < 0.0) {
        dst = -src;
    } else {
        dst = src;
    }
    return dst;
}
~~~

`main`内で`double v = -0.4;`，`double result = absolute(v);`と書くと，`result`は0.4になります．仮引数`src`と呼び出し元の`v`は同じ名前でなくてかまいません．`absolute(0.5)`のようにリテラルも渡せ，`printf("%.1f\n", absolute(0.5));`のように返された値をそのまま表示にも使えます．この例では有限の小さな値を扱います．

### 引数が複数の場合

~~~c
double volume(double width, double height, double depth)
{
    return width * height * depth;
}
~~~

`volume(2.0, 3.0, 4.0)`は24.0です．引数はコンマで区切り，個数・型・順序を対応させます．戻り値用の変数を作らず，式を直接`return`してもかまいません．ここでは引数は0〜100の範囲とします．関数は通常1つの値を返します．複数の情報をまとめて扱う方法は，ポインタや構造体の回で学びます．

`return` は呼び出し元へ値を返す操作で，画面に表示する操作ではありません．表示は`printf`の仕事です．値を返さない関数の戻り値型は`void`です．引数のない関数は `void show(void)` のように書きます．

~~~c
void display(int value)
{
    printf("value=%d\n", value);
    return;
}

void hello(void)
{
    printf("hello!\n");
}
~~~

`void`関数では値を付けない`return;`を使えます．末尾の`return;`は省略もできます．`return`の後ろへ文を書いても，その呼び出しでは実行されません．`void`でない関数は，必要なすべての経路で値を返すようにします．

C17では引数なしを明確にするため`(void)`と書きます．宣言の`void hello();`は引数の型・個数を指定するプロトタイプにはならないため，この講義では使いません．戻り値が`void`なら，`int x = hello();`のように値として受け取ることはできません．

### 宣言を先に知らせる

関数を定義より前に呼ぶときは，`int square(int x);` のように**プロトタイプ宣言**を置きます．引数と戻り値の型をコンパイラが確認できるようにします．

~~~text
stdio.hのインクルード
squareのプロトタイプ宣言（末尾に;）
mainの定義 → squareを呼ぶ
squareの定義（本体を書く）
~~~

`int square(int);`のように宣言では仮引数名を省略できます．定義と宣言の型を一致させてください．呼び出す場所で宣言が必要なのは，コンパイル時に呼び出し方を確認するためです．「`main`より後ろの関数は実行時にまだ存在しない」という意味ではありません．

`main`も関数であり，この授業では`int main(void)`を使います．`return 0;`はプログラムの正常終了を表します．コマンドライン引数を受け取る`int main(int argc, char *argv[])`という形は第10回で扱います．関数一般の`return`は呼び出し元へ戻りますが，`main`からの`return`はプログラムの終了につながります．

## 4　値渡しと配列の引数

通常の`int`引数は値のコピーです．関数内で仮引数`x`を変更しても，呼び出し元の変数は変わりません．

~~~c
int plus_one(int value)
{
    value += 1;
    return value;
}
~~~

`main`で`int b = 10;`として`plus_one(b);`だけを実行すると，戻り値11は使われず，`b`は10のままです．`int c = plus_one(b);`なら`c`が11になり，`b = plus_one(b);`なら戻り値を代入することで`b`も11になります．関数呼び出しと代入を分けて考えましょう．

一方，配列の引数は全要素がコピーされるのではありません．関数は元の要素にアクセスできます．長さは自動では伝わらないため，`sum_array(scores, COUNT)` のように別の引数で渡します．詳しい仕組みは第8回のポインタで学びます．

`const int a[]` は，その関数が`a`を通して要素を書き換えないことを表します．配列引数`a`に`sizeof`を使っても，元の配列全体のサイズは得られません．

### 配列の引数と長さの約束

~~~c
int sum_array(const int a[], int n)
{
    int sum = 0;
    for (int i = 0; i < n; ++i) {
        sum += a[i];
    }
    return sum;
}
~~~

配列を渡すと，先頭の要素を指す情報（ポインタ）が値として渡されます．Cの値渡しが例外になるのではなく，コピーされるのが要素全体ではないということです．関数の仮引数の`a[]`はポインタとして扱われ，配列を作る宣言の`a[]`とは意味が違います．

`sizeof a`自体は書けますが，この関数の中ではポインタのサイズになり，呼び出し元の配列全体のサイズではありません．そのため`n`を別に渡します．3要素の配列に`n=5`を指定しても，5要素へ拡張されるわけではなく，範囲外アクセスの原因になります．

`const`を付けない配列引数なら，要素を書き換えることもできます．要素の変更は呼び出し元にも残るため，読むだけの関数には`const`を付け，関数の役割を明確にします．今回の`sum_array`や`max_score`は配列を書き換えません．

## 5　スコープと寿命

**スコープ**は名前が使える範囲です．ブロック内で宣言した名前は原則そのブロックの終わりまで使えます．`for`の初期化で宣言した`i`は`for`の外から使えません．別のブロックで同じ名前を使っても別の変数です．意図しない隠蔽を避けるため，名前の使い回しは控えます．

**寿命**は変数の領域が有効な期間です．通常の局所変数は，ブロックへの実行の進入に伴って用意され，抜けると寿命を終えます．名前の見える範囲と領域の有効期間は同じ概念ではありません．`static`を使う場合などの違いは第13回で扱います．

### 関数ごとの局所変数

`absolute`の`dst`はその関数内だけで使える**局所変数（ローカル変数）**です．`main`から`dst`という名前でアクセスすることはできません．同様に，`main`の変数を別の関数からその名前で直接読むこともできません．必要な情報は引数として渡し，計算結果は戻り値として受け取ります．

同じブロックで`int a`を2回宣言すると重複しますが，独立したブロックなら同名の別の変数を宣言できます．

~~~c
{
    int a = 123;
    printf("%d\n", a);
}
{
    int a = 345;
    printf("%d\n", a);
}
~~~

表示は123，345です．後半は前半の変数への代入ではなく，新しい局所変数です．字下げではなく波括弧が範囲を決めます．

### グローバル変数と名前の隠蔽

関数の外で宣言した変数は，**グローバル変数**と呼ばれます．この回の1ファイルの例では，宣言以降の各関数から同じ変数へアクセスできます．他ファイルからの利用には宣言などの規則があり，第12回で扱います．

~~~c
int count = 0;

void tick(void)
{
    ++count;
}
~~~

`main`で`count`を表示してから`tick();`を呼び，再び表示すると0から1へ変わります．一方，`tick`内に`int count = 3;`を追加すると，その関数では局所変数の`count`が優先されます．`++count`は局所変数を4にするだけで，グローバル変数は0のままです．このように内側の名前が外側を見えなくすることを**隠蔽（シャドーイング）**と呼びます．

グローバル変数は実行開始から終了まで領域が存在し，明示的に初期化しない場合にも0で初期化されます．通常の未初期化の局所変数と区別してください．ただし，あらゆる関数で値を変える設計は原因を追いにくくなります．この回の課題では引数・戻り値・局所変数を基本とし，グローバル変数は挙動を読む補足例として扱います．

## 6　例：点数と行の合計

~~~c title="arrays.c" linenums="1"
--8<-- "sample/05/arrays.c"
~~~

[`arrays.c`](sample/05/arrays.c){ download }

~~~text
total=390 mean=78.0
row 0: 6
row 1: 15
~~~

`sum_array`の契約は「`n`は0以上で，`a`から少なくとも`n`個の有効な`int`要素を読めること」です．ここでは点数が0〜100，個数が5なので合計も`int`の範囲に収まります．

### 例題を分解して読む

`enum { COUNT = 5 };`は整数定数`COUNT`に5という名前を付けています．`main`では5要素の`scores`を作り，その配列と要素数を`sum_array`へ渡します．関数内では`sum`が0→72→157→217→310→390と変化し，390を`main`へ返します．その値を`main`の`total`へ保存して表示します．

平均の計算を`total / 5.0`としているのは，整数除算を避けるためです．続く二次元配列の処理では，行が変わるたびに`sum`を0へ戻します．配列全体の合計と，行ごとの合計では初期化の位置が異なることに注目しましょう．

### よくある間違い

| 症状 | 確認すること |
| --- | --- |
| 最後に余分な値を読む | `i <= COUNT`ではなく`i < COUNT`か |
| 合計が毎回変わる | 配列や合計変数を読む前に初期化したか |
| 関数呼び出しの診断が出る | 呼び出し前に宣言があり，引数の型・個数が合うか |
| 戻り値が使われない | 呼び出し後に代入・表示しているか |
| 配列の長さが関数内で分からない | 長さを別引数で渡したか |
| 呼び出し元の整数が変わらない | 値渡しを理解し，必要な戻り値を代入したか |
| 同じ名前なのに値が違う | 別のスコープの変数で隠蔽していないか |

まず要素数，添字の範囲，関数の引数・戻り値の型を紙上で対応させます．次に小さい既知のデータで確認します．大きなデータに変える前に，1要素やすべて同じ値の場合でも説明できるようにしましょう．
