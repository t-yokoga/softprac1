## 課題1　値のコピーとポインタのコピー

ポインタを使って変数の値を変え，配列の2つの要素を交換するプログラムを作成し，値のコピーとポインタのコピーの違いと，`&a[1]`と`a + 1`が同じ場所を指すことを確認してください．

`PointerTrace`プロジェクトに`pointer_trace.c`を作ります．プログラムが満たすこと（仕様）は次のとおりです．

- 講義の`void swap(int *a, int *b)`を`main`の前に定義する．
- `int`の配列を空白区切りで1行に表示する関数`void print_array(const int a[], int n)`を`main`の前に定義する．
- `main`では，`int x = 3;`，`int y = 8;`，`int *p = &x;`，`int *q = &y;`と宣言する．
- 次の5つの時点で，`printf("x=%d y=%d *p=%d p_is_x=%d\n", x, y, *p, p == &x);`を実行する．`p_is_x`は，`p`が`x`を指していれば1，そうでなければ0になる．
    1. 宣言・初期化の後
    2. `*p = *q;`の後
    3. `p = q;`の後
    4. `*p = 5;`の後
    5. `swap(&x, &y);`の後
- 続けて配列`int a[] = {1, 5, 3, 4, 2, 6};`を宣言し，`printf("same=%d\n", &a[1] == a + 1);`を実行する．
- `swap(&a[1], &a[4]);`で添字1と4の要素を交換して`print_array`で表示し，次に`swap(a + 1, a + 4);`で同じ2つの要素をもう一度交換して表示する．

表示は次のようになります．

~~~text
x=3 y=8 *p=3 p_is_x=1
x=8 y=8 *p=8 p_is_x=1
x=8 y=8 *p=8 p_is_x=0
x=8 y=5 *p=5 p_is_x=0
x=5 y=8 *p=8 p_is_x=0
same=1
1 2 3 4 5 6
1 5 3 4 2 6
~~~

`*p = *q`は`q`が指す値を`p`が指す変数へコピーするので，`x`が変わり，`p`は`x`を指したままです．`p = q`はポインタの値をコピーするので，`x`も`y`も変わらず，`p`が`y`を指すようになります．そのため，その後の`*p = 5`で変わるのは`y`で，`swap`の後の`*p`も`y`の値です．

`swap(&a[1], &a[4])`で昇順になり，`swap(a + 1, a + 4)`で元の並びに戻ります．2回目の呼び出しも同じ2つの要素を交換していることが，この表示から分かります．

## 課題2　最小値と最大値を返す

配列の最小値と最大値を，2つのポインタ引数を通して呼び出し元へ返すプログラムを作成し，5通りの配列で最小値と最大値を確認してください．

`MinMax`プロジェクトに`minmax.c`を作ります．プログラムが満たすこと（仕様）は次のとおりです．

- 関数の形は`void minmax(const int a[], int n, int *low, int *high)`とする．戻り値は使わず，最小値を`*low`へ，最大値を`*high`へ書き込む．
- `n`は1以上で，`a`から少なくとも`n`要素を読めるものとする．
- `low`と`high`は互いに異なる有効な`int`を指し，入力配列の要素とも重ならないものとする．
- 関数`void show(const int a[], int n)`を作る．`show`は`int low, high;`を宣言して`minmax(a, n, &low, &high)`を呼び，`printf("%d %d\n", low, high);`で表示する．
- `main`では，次の5つの配列について，表の順に`show`を呼ぶ．

| 配列 | `n` |
| --- | ---: |
| {7, −2, 9, 0} | 4 |
| {5} | 1 |
| {3, 3, 3} | 3 |
| {−8, −2, −5} | 3 |
| {7, 2, 10, 3, 5} | 5 |

表示は次のようになります．

~~~text
-2 9
5 5
3 3
-8 -2
2 10
~~~

??? tip "ヒント"

    最初の要素で両候補を初期化します．全部が負の配列でも正しく求まるように，最大値を0から始めず`a[0]`から始めます．

`show`の`low`，`high`は，`minmax`が書き込んだ後に初めて読みます．関数へ渡すのは未初期化の値そのものではなく，`&low`と`&high`です．`n=0`では最初の`a[0]`を読めるという約束を満たせないので，この関数には渡しません．

## 課題3　安全な文字列コピー

`CopyText`プロジェクトに`copy_text.c`を作ります．この課題では，次の3つの小問を順に行い，3つのコピー関数を同じファイルに並べます．

1. 課題3-1：容量を確かめてから文字列をコピーする関数を，添字を使って作る．
2. 課題3-2：同じ処理を，添字を使わずポインタを進める形で作る．
3. 課題3-3：同じ処理を，さらに短い書き方で作り，コピー後の配列の全要素を表示する．

3つの関数は，どれも次の約束を満たします．

- 関数の形は`int 関数名(char *dst, size_t capacity, const char *src)`とする．必要な標準ヘッダをインクルードする．
- `src`は終端のある文字列，`dst`は`capacity`要素の書き込み可能な配列とし，両者の領域は重ならないものとする．
- 終端まで`dst`に入るなら，終端も含めてコピーして1を返す．
- 容量が足りなければ，`dst`を変更せずに0を返す．

### 課題3-1　添字版を作る

添字を使って文字列をコピーする関数`copy_text`を使うプログラムを作成し，4通りの容量と文字列で，戻り値とコピー後の配列を確認してください．

確認のために，関数`void check(int version, size_t capacity, const char *src)`を作ります．`check`は次の処理を行います．

- `char out[8] = "old";`を宣言する．
- `version`が1なら`ok = copy_text(out, capacity, src);`とする．課題3-2と3-3で，2と3の場合を書き足す．
- `printf("%d: %d [%s]\n", version, ok, out);`で，`version`，戻り値`ok`，呼び出し後の`out`を表示する．角かっこは，`out`が空文字列のときにも分かるように付けている．

`main`では，次の4通りの順に`check(1, 容量, 文字列)`を呼びます．`out`の要素数は8ですが，関数には表の容量を渡すので，関数から見た配列の大きさは表の容量になります．

| 容量 | `src` |
| ---: | --- |
| 4 | `"cat"` |
| 3 | `"cat"` |
| 1 | `""` |
| 4 | `"cats"` |

表示は次のようになります．容量が足りないときは，`out`が`"old"`のまま残ります．

~~~text
1: 1 [cat]
1: 0 [old]
1: 1 []
1: 0 [old]
~~~

??? tip "ヒント"

    `strlen(src)`を先に求めます．長さが容量以上なら終端が入りません．

容量が足りない場合は，書き込みを始める前に`return 0;`で戻ります．途中まで上書きしてから失敗する設計ではありません．容量4の配列へ`"cat"`をコピーする場合，書く添字は0，1，2，3の4つで，最後の3には終端が入ります．

### 課題3-2　添字なしのポインタ版を作る

添字を使わずポインタを進める`while`ループでコピーする関数`copy_text_pointer`を加えたプログラムを作成し，課題3-1と同じ4通りで同じ結果になることを確認してください．

`strlen`による容量の検査は課題3-1と同じです．終端文字のコピーも必要です．`check`に`version`が2の場合を加え，`main`では`version`を1から2まで変えながら，それぞれ課題3-1と同じ4通りで`check`を呼びます．

表示は，課題3-1の4行に続けて次の4行が出ます．

~~~text
2: 1 [cat]
2: 0 [old]
2: 1 []
2: 0 [old]
~~~

### 課題3-3　さらに短い表記で作る

容量の検査の後のコピーを次の形で書いた関数`copy_text_short`を加えたプログラムを作成し，課題3-1と同じ4通りの結果と，コピー後の配列に残る文字を確認してください．

`check`に`version`が3の場合を加え，`main`では`version`を1から3まで変えて`check`を呼びます．続けて，`main`で次の処理を行います．

- `char buffer[] = "aaaaaaaaaa";`を宣言し，`copy_text_short(buffer, sizeof buffer, "hoge")`を呼ぶ．
- `buffer`の全要素（`sizeof buffer`個）の文字コードを，`%d`で空白区切りに1行で表示する．

課題3全体の表示は次の13行になります．

~~~text

1: 0 [old]
1: 1 []
1: 0 [old]
2: 1 [cat]
2: 0 [old]
2: 1 []
2: 0 [old]
~~~

`"hoge"`の終端（0）の後ろに，コピー前の`'a'`（97）が残っています．`%s`で表示すると終端までの`hoge`だけが表示されますが，配列の中身は全部が置き換わったわけではありません．

## 課題4　ポインタで配列・文字列を走査する

`PointerWalk`プロジェクトに`pointer_walk.c`を作ります．この課題では，次の4つの小問を順に行い，同じファイルへ書き足します．

1. 課題4-1：配列の合計と文字列長を，ポインタを使って求める．
2. 課題4-2：ポインタの差と比較を表示する．
3. 課題4-3：別の配列と文字列でも合計と長さを表示する．
4. 課題4-4：関数から配列を書き換え，`sizeof`の違いを表示する．

### 課題4-1　合計と文字列長を求める

配列の合計を添字とポインタの両方で求め，文字列の長さをポインタで求めるプログラムを作成してください．

プログラムが満たすこと（仕様）は次のとおりです．

- 要素数を`enum { COUNT = 5 };`で定める．
- 添字で合計を求める`int sum_index(const int a[], int n)`と，ポインタで合計を求める`int sum_pointer(const int *a, int n)`を作る．`sum_pointer`では，`a[i]`や`*(a + i)`を使わず，ポインタを`a`から`a + n`の手前まで進める．
- 文字列長は，講義と同じ`size_t pointer_length(const char *s)`で求める．
- `main`では`int a[COUNT] = {2, 4, 6, 3, 5};`を宣言し，`printf("sum=%d %d\n", sum_index(a, COUNT), sum_pointer(a, COUNT));`と`printf("length=%zu\n", pointer_length("cat"));`を実行する．

表示は次のようになります．

~~~text
sum=20 20
length=3
~~~

`sum_pointer`で本体が実行されるとき，ポインタは`a[0]`〜`a[4]`のどれかを指しています．`a + n`へ進むと条件が偽になるため，1つ先を読むことはありません．条件を`p <= a + n`にすると範囲外を読むので，そのようには書きません．

### 課題4-2　差と比較を表示する

2つのポインタの差と比較を表示する関数を加えたプログラムを作成し，指す要素の位置が異なる場合と同じ場合で，差と比較の結果を確認してください．

- 関数`void compare(const int *p, const int *q)`を作り，`printf("distance=%td reverse=%td before=%d equal=%d\n", q - p, p - q, p < q, p == q);`で表示する．
- `main`で，課題4-1の表示の後に`compare(a + 1, a + 3);`と`compare(a + 1, a + 1);`を呼ぶ．

表示は次の2行です．

~~~text
distance=2 reverse=-2 before=1 equal=0
distance=0 reverse=0 before=0 equal=1
~~~

ポインタの差の単位はバイトではなく要素数です．差の型は`ptrdiff_t`なので，`%td`で表示します．

### 課題4-3　別の値で確認する

課題4-1の関数を別の配列と文字列で呼ぶ処理を加えたプログラムを作成し，合計と長さを確認してください．

- `int zeros[COUNT] = {0, 0, 0, 0, 0};`と`int numbers[COUNT] = {1, 2, 3, 4, 5};`を宣言し，それぞれの合計を課題4-1と同じ形式で表示する．
- `pointer_length`へ`""`，`"A"`，`"Hello"`を渡し，それぞれの長さを課題4-1と同じ形式で表示する．

表示は次の5行です．

~~~text
sum=0 0
sum=15 15
length=0
length=1
length=5
~~~

`pointer_length`の仮引数は`const char *s`ですが，`++s`は書けます．講義の`const`の表のとおり，`s`が指す文字の変更は許されませんが，`s`というポインタの移動は禁止されていません．

### 課題4-4　関数から配列を書き換える

関数で配列の全要素を1に書き換える処理を加えたプログラムを作成し，呼び出し元の配列が変わることと，配列とポインタの`sizeof`の違いを確認してください．

- 講義の`void set_one(int *a, int n)`を`main`の前に定義する．
- `main`の最後で`set_one(a, COUNT);`を呼び，`a`の合計を課題4-1と同じ形式で表示する．
- `int *p = a;`を宣言し，`printf("size_a=%zu size_p=%zu\n", sizeof a, sizeof p);`で表示する．

表示は次の2行です．

~~~text
sum=5 5
size_a=20 size_p=8
~~~

`size_a`は配列全体の大きさ（`int`5個分）で，`size_p`はポインタ1個の大きさです．`size_p`は環境によって異なり，64ビット（x64）の実行環境では8，32ビット（x86）では4になります．

`set_one`へコピーされたのは配列そのものではなく先頭を指す値なので，変更が呼び出し元に残ります．関数の中では配列の大きさが分からないので，要素数を`n`として別に渡します．

課題4全体の表示は次のようになります．

~~~text
sum=20 20
length=3
distance=2 reverse=-2 before=1 equal=0
distance=0 reverse=0 before=0 equal=1
sum=0 0
sum=15 15
length=0
length=1
length=5
sum=5 5
size_a=20 size_p=8
~~~

## 発展1　整数部と小数部を分ける

実数を整数部と小数部に分けるプログラムを作成し，4つの入力で整数部と小数部を確認してください．

`Decompose`プロジェクトに`decompose.c`を作ります．プログラムが満たすこと（仕様）は次のとおりです．

- 講義の`void decompose(double x, long *whole, double *fraction)`を`main`の前に定義する．入力`x`は−100〜100の有限な値とする．
- 関数`void show(double x)`を作る．`show`は`long whole = 0;`と`double fraction = 0.0;`を宣言して`decompose(x, &whole, &fraction)`を呼び，`printf("x=%.2f whole=%ld fraction=%.2f\n", x, whole, fraction);`で表示する．
- `main`では，3.14，−3.14，0.0，5.0の順に`show`を呼ぶ．

表示は次のようになります．

~~~text
x=3.14 whole=3 fraction=0.14
x=-3.14 whole=-3 fraction=-0.14
x=0.00 whole=0 fraction=0.00
x=5.00 whole=5 fraction=0.00
~~~

整数部への変換は四捨五入ではなく，0の方向への切り捨てです．小数部は浮動小数点数の近似なので，小数点以下2桁に整えて表示しています．

## 発展2　小さい値の場所を返す

2つの変数のうち値が小さいほうの場所を返す関数を使うプログラムを作成し，3通りの初期値で，返された場所と，その場所へ書き込んだときに変わる変数を確認してください．

`MinPointer`プロジェクトに`min_pointer.c`を作ります．プログラムが満たすこと（仕様）は次のとおりです．

- 講義の`int *min_pointer(int *a, int *b)`を`main`の前に定義する．
- 関数`void try_min(int x, int y)`を作る．`try_min`は次の4行を順に実行する．

    ~~~c
    int *result = min_pointer(&x, &y);
    printf("minimum=%d points_to_y=%d\n", *result, result == &y);
    *result = 0;
    printf("x=%d y=%d\n", x, y);
    ~~~

- `main`では，`try_min(9, 3);`，`try_min(3, 9);`，`try_min(5, 5);`の順に呼ぶ．

表示は次のようになります．値が等しいときは，講義の実装では`b`側（`y`）を返します．

~~~text
minimum=3 points_to_y=1
x=9 y=0
minimum=3 points_to_y=0
x=0 y=9
minimum=5 points_to_y=1
x=5 y=0
~~~

`result`が指す`x`や`y`は`try_min`の仮引数で，`try_min`から戻るまで寿命が続きます．そのため，`try_min`の中で`*result`を使えます．これに対して，関数内の`int local = 10;`のアドレスを返す関数は，戻った時点で`local`の寿命が終わっているので書きません．

## 確認問題

この節は自習用で，成績には含めません．

1. `int *p, q;`でポインタはどちらか．
2. `p = q`と`*p = *q`はそれぞれ何をコピーするか．
3. `int a = 10;`，`int *p = &a;`で，`*&a`，`*&p`，`&*p`は何を表すか．`&*a`は正しいか．
4. `(*p)++`と`*p++`は何が違うか．
5. 5要素の配列`a`について，`a + 5`を作ることと`*(a + 5)`を読むことは同じか．
6. `const int *p`と`int *const p`は何を禁止するか．
7. `p`が非`NULL`なら，常に安全に`*p`を読めるか．
8. `char buffer[] = "cat";`と`const char *word = "cat";`は何を保存するか．

## チェックリスト

- 各課題のソースが1つのファイルにまとまり，警告なしでビルドできる．
- 1回の実行で，課題に示したすべての場合の結果が表示される．
- 表示が，課題に示した出力と一致する．
- 関数の名前，引数，戻り値の型が課題の指定どおりである．
- 小問のある課題で，前の小問の関数や表示を残している．
- 未初期化ポインタ，範囲外アクセス，寿命が終わった変数へのアクセスを書いていない．
