# 第6回　演習：文字列

解答・解説は授業で別途提示します．このページには問題とヒントを掲載しています．

[講義](lec06.md)を読んでから取り組んでください．出力と処理の流れを予測しましょう．

## 準備と進め方

作業場所は `PL1\week06` です．[第1回](lec01.md#hello)と同じ設定（Cとしてコンパイル，C17，警告レベル4）で，課題ごとに別の空のプロジェクトを作ります．特に指定がなければ，`main`を持つソースは1プロジェクトに1つです．保存後にCtrl+Shift+Bでビルドし，Ctrl+F5で実行します．

各課題で，ソース，試した値，予測，実行結果，結果の説明を残してください．提出先や締切は，授業時に案内します．

### 今回の進め方

| 課題 | 内容 | 確認すること |
| --- | --- | --- |
| 1 | 長さと空白の数 | 最初の終端で止まる走査 |
| 2 | ASCIIの文字変換 | 大文字だけを選んで変更 |
| 3 | 数値の型変換 | 計算する型と変換のタイミング |
| 4 | 文字列の比較・連結 | `strcmp`の符号，終端込みの容量 |
| 発展 | コピーの容量の境界 | 入る場合・入らない場合の分岐 |

実行前に，配列の全要素を終端も含めて書き出してください．次に「配列容量」「文字列長」「終端の添字」を記録します．これらを区別してからコードを追うと，範囲外アクセスを防ぎやすくなります．予測と実行結果を比較し，自分の実装を確認しましょう．

この回の文字列はソース内で用意し，キーボードからは読み込みません．変更するのは指定された初期値・容量・式です．容量検査を削除したり，終端のない配列を`%s`や`strlen`へ渡したりする実験は行いません．コピー元とコピー先は別の配列にします．

### ウォームアップ：文字と数値

`main`内で次を実行し，表示される文字と整数を対応させます．`stdio.h`が必要です．

~~~c
char c = '3';
printf("character=%c code=%d\n", c, c);
if (c >= '0' && c <= '9') {
    printf("digit=%d\n", c - '0');
}
printf("last=%c\n", "abcd"[3]);
~~~

ASCIIでは`character=3 code=51`，`digit=3`，`last=d`です．`c`を`'0'`，`'9'`，`'A'`へ変更し，`'A'`の場合には`digit`の行を表示しないことを確認します．`(int)c`というキャストだけでは数字の3にならない理由を説明してください．


## 課題1　長さを数える

`Length` プロジェクトで`strlen`を使わず，文字列の長さを数える関数`my_length`を作ります．引数は必ず終端を持つ文字列とします．空文字列，`A`，`Hello`で0，1，5を確認してください．

??? tip "ヒント"

    添字を0から増やし，`s[i]`が`'\0'`になるまで数えます．

### 終端へ到達するまでを追う

`"Hello"`について，`n`が0，1，2，3，4のときに読む値は`'H'`，`'e'`，`'l'`，`'l'`，`'o'`です．それぞれ終端ではないので`n`を増やします．`n=5`で終端を読み，そこで終了して5を返します．空文字列なら`n=0`の最初の判定で終端なので，本体は1回も実行しません．

| 文字列 | 配列に必要な最小容量 | `my_length`の結果 |
| --- | ---: | ---: |
| `""` | 1 | 0 |
| `"A"` | 2 | 1 |
| `"Hello"` | 6 | 5 |
| `"A B"` | 4 | 3 |

文字列中のスペースも1文字に数えます．この関数は`string.h`の`strlen`とは違う名前にし，標準関数を自分の関数で置き換えないようにしています．`size_t`の宣言には`stddef.h`を使っています．

### 配列容量と文字列長を比べる

次のコードを`main`内へ追加します．

~~~c
char text[10] = "abc";
printf("length=%zu capacity=%zu\n", my_length(text), sizeof text);
text[1] = '\0';
printf("text=%s length=%zu capacity=%zu\n",
       text, my_length(text), sizeof text);
~~~

`char text[] = {'a', 'b', 'c', '\0', 'd', 'e'};`の場合も`my_length`は3です．終端以降を読み進めないことを説明してください．この配列の最後の要素が終端でなくても，読み取り可能な領域内に最初の終端があるため，`abc`という文字列として扱えます．

### 空白を数える関数を追加する

講義の`count_spaces`を`my_length`と同じファイルで`main`より前へ定義し，`main`へ次を追加します．

~~~c
printf("spaces=%zu %zu %zu\n",
       count_spaces("abc def gh"),
       count_spaces("ijk lmn opq rst"), count_spaces(""));
~~~

実行前に結果を予測し，実行後に結果とその理由を記録してください．

**説明すること**：`my_length`の引数に配列容量を渡していないのに終わりを判断できる理由と，終端がない入力を許してはいけない理由を説明してください．

## 課題2　ASCIIの小文字へ変換

`Lower` プロジェクトで `char text[] = "Hello C17!";` の英大文字だけを小文字にします．結果はhello c17!です．ASCIIを前提とし，他の文字は変えません．

??? tip "ヒント"

    `'A'`以上かつ`'Z'`以下なら，`'a' - 'A'`を足します．

空文字列と`AZaz09`でも試します．これは任意の言語の大文字小文字を変換する処理ではありません．

### 変更する文字・しない文字を区別する

| 初期値 | 期待する表示 | 注目点 |
| --- | --- | --- |
| `"Hello C17!"` | 記入してください | 大文字だけ変わる |
| `""` | 記入してください | 本体を0回で終了 |
| `"AZaz09"` | 記入してください | `A`・`Z`の端と，小文字・数字 |
| `"@AZ["` | 記入してください | `A`の直前と`Z`の直後は変更しない |
| `"A B"` | 記入してください | スペースは保つ |

条件を使わずにすべての文字へ`'a' - 'A'`を足すと，数字や記号まで別の値になります．範囲を確認してから変更することが重要です．終端も変更しません．

### 1文字の変換を関数へ分ける

次の`lower`を`main`の前へ置き，ループ内の`if`全体を`text[i] = lower(text[i]);`に置き換えてください．表のすべての入力で，同じ結果になることを確認します．

~~~c
char lower(char c)
{
    if (c >= 'A' && c <= 'Z') {
        return (char)(c - 'A' + 'a');
    }
    return c;
}
~~~

`lower`の引数`c`はコピーです．関数内で計算するだけでは`text`の要素は変わりません．**返された文字を`text[i]`へ代入する**ことが必要です．第5回の値渡しと結び付けて説明してください．

### 補足：ASCIIの印字可能な範囲

ASCIIの表を確認したい場合は，次のループを`main`内で使えます．0〜31と127は制御用なので，この表示からは除いています．

~~~c
for (int code = 32; code <= 126; ++code) {
    printf("%3d : %c\n", code, code);
}
~~~

32はスペースなので，コロンの後ろには目に見える記号がありません．`'0'`が48，`'A'`が65，`'a'`が97であること，それぞれの並びが連続することを確認します．この例はASCIIを前提としており，日本語の文字一覧にはなりません．

## 課題3　変換する順序

`Average` プロジェクトで次を`main`内に書き，結果を予測します．

~~~c
int total = 7, count = 2;
printf("%.1f\n", (double)(total / count));
printf("%.1f\n", (double)total / count);
printf("%d\n", (int)-3.9);
~~~

### 同じ値で式だけを比べる

`total`を−7，`count`を2へ変更してください．最初の2行は−3.0，−3.5になります．整数除算は0方向へ小数部を切り捨てるため，−`7 / 2`は−3です．`count=0`の実験は行いません．

**説明すること**：`(double)(total / count)`の外側のキャストで，失われた小数部を戻せないのはなぜか．また，`double mean = total / count;`でも整数除算になるのはなぜか．右辺を計算する段階と，左辺へ代入する段階に分けて説明します．

### 計算する型を先に広げる

次の完全なプログラムへ置き換え，整数拡張，積の型，往復変換を確認します．

~~~c
#include <stdio.h>
int main(void)
{
    char c1 = 10, c2 = 100, c3 = 20;
    int promoted = c1 * c2 / c3;
    int i = 50000;
    long long square = (long long)i * i;
    char original = 'A';
    int saved = original;
    char restored = (char)saved;
    unsigned char small = (unsigned char)300;
    printf("promoted=%d\n", promoted);
    printf("square=%lld\n", square);
    printf("roundtrip=%d\n", original == restored);
    printf("unsigned=%u\n", (unsigned int)small);
    return 0;
}
~~~

~~~text
promoted=50
square=2500000000
roundtrip=1
unsigned=44
~~~

授業の8ビット`unsigned char`では300を256で割った余りの44になります．`unsigned int`へのキャストは`%u`に型を合わせるためです．この符号なしへの変換は，符号付きの計算のオーバーフローとは別の規則です．

`char`から`int`へ移した`saved`は元の値を保ち，`char`へ戻しても同じ文字になります．一方で`small`を`int`へ戻しても300には戻らず44です．失われた情報が復元されないことを説明してください．

### 範囲外の計算は読解だけにする

`long long square = i * i;`へキャストを外すと，MSVCの32ビット`int`では50000×50000が範囲を超えます．この形は実行しないでください．`(long long)(i * i)`も，計算後に変換するので解決しません．`i`を100へ変える場合は，どの形でも10000が範囲内ですが，それだけで大きな入力にも安全とは判断できません．

### 符号の異なる比較を読む

`int i = -10;`と`unsigned int u = 10u;`で`i < u`が偽になる理由を，講義の変換規則に従って説明してください．`u`が`INT_MAX`以下であると確認できる場合に限り，`i < (int)u`という比較が使えます．「警告が出たらとにかくキャストする」という直し方は避けます．

## 課題4　比較してから連結する

`CompareJoin` プロジェクトで，`"hoge"`と`"fuga"`を比較し，十分な容量がある場合だけ連結します．比較は`strcmp`の戻り値の符号だけを使い，連結は終端を含めたループで行います．

??? tip "ヒント"

    `strcpy`や`strcat`を実行する代わりに，自分で容量を確認します．現在の長さを`used`，追加分を`added`とし，残り容量に`added`と終端の1バイトが収まるか判定します．コピー先は最初から終端を持つ文字列です．

~~~text
after
text=hogefuga length=8 capacity=10
~~~

ASCIIでは最初の`h`が`f`より後なので`after`です．`strcmp`が返す具体的な正の数は出力条件に使いません．

### 容量の境界を確認する

`text`の容量だけを10から9，8へ変えます．文字列の初期値と容量検査は残します．

| 容量 | 連結できるか | 最後の文字列 | `strlen` |
| ---: | --- | --- | ---: |
| 10 | できる | `hogefuga` | 8 |
| 9 | できる（終端込みでぴったり） | `hogefuga` | 8 |
| 8 | できない | `hoge` | 4 |

容量8では`after`の次にnot enough spaceを表示します．書き込みを始める前に容量を確認しているので，元の`hoge`が保たれます．この演習では容量は5以上にし，初期文字列`hoge`の終端が必ず入るようにします．

### 比較の条件を変える

容量を10へ戻し，`suffix`を`"hoge"`へ変えると最初の行は`equal`，連結後は`hogehoge`です．`suffix`が`"z"`なら`before`，連結後は`hogez`です．空文字列`""`なら`after`ですが，連結しても`hoge`のままです．

**説明すること**：比較が文字列の長さでは決まらない理由，`i <= added`の等号が必要な理由，配列容量が連結後も変わらない理由を説明してください．

## 発展　容量の境界

講義の`strings.c`で`copy`の容量を4，3に変更し，`cat`をコピーできるか予測してください．条件式は残します．

`copy[4]`でも`word`の容量は16のままです．表示の`capacity`は`sizeof word`なので16です．どの配列の大きさを表示しているかも確認しましょう．`copy[3]`では最初の表示が`Cat`と，空の`copy`になります．`copy`へ部分的に`cat`を書いてから終端を書けなくなるのではなく，コピー自体を行わないため安全です．

3. `s[1] = '\0';`を実行すると，表示・長さ・容量はどうなるか．
4. `strcmp(a, b)`を−1と比較してはいけないのはなぜか．
5. `strcpy`で5文字の`hello`をコピーする場合，最小容量はいくつか．
