# 第1回　演習

解答・解説は授業で別途提示します．このページには問題とヒントを掲載しています．


[第1回の講義](lec01.md)を読み，Visual Studioで `hello.c` をビルド・実行できることを確認してから取り組んでください．
今回は変数や繰り返しを使わず，文字列を表示するプログラムの作成・ビルド・実行に関する課題に取り組みます．

## 演習の進め方

課題1〜4を順に進め，最後に確認問題に答えてください．課題5は発展課題です．
どの操作を使うか，どのような結果になるかを考えてみましょう．

!!! note "作業場所と記録"

    [講義で作成した](lec01.md#environment) `PL1\week01` を作業場所にします．作成したソースファイルと，実行結果を残してください．説明を書くための `memo.txt` をエディタで作っておくと便利です．

    提出先や締切は，授業時に案内します．

| 課題 | 内容 | プロジェクト名 | ソースファイル |
| --- | --- | --- | --- |
| 1 | 最初のプログラム | `Welcome` | `welcome.c` |
| 2 | 表示する内容の変更 | `Message` | `message.c` |
| 3 | エラーの修正 | `Broken` | `broken.c` |
| 4 | ソースと実行ファイルの区別 | `Version` | `version.c` |
| 5 | 発展：文字で図を描く | `House` | `house.c` |

### 各プログラムに共通の手順

各課題では，[講義の手順](lec01.md#hello)に従い，**課題ごとに別の「空のプロジェクト」**を作成します．
場所は `week01`，プロジェクト名は上の表の名前とし，新しいソリューションで作成してください．「ソリューションとプロジェクトを同じディレクトリに配置する」にチェックを入れます．

各プロジェクトで，次の手順を行います．

1. 表の名前の **`.c` ファイル**を「ソース ファイル」へ追加する．
2. プロジェクトのプロパティで **Cとしてコンパイル（/TC），C17，警告レベル4** を設定する．
3. コードを入力し，保存する．
4. **Ctrl+Shift+B** でビルドし，成功したことを確認する．
5. **Ctrl+F5** で実行し，プログラムが表示した内容を確認する．

!!! warning "mainを持つファイルをまとめて追加しない"

    この演習のプログラムには，それぞれ `main` があります．同じプロジェクトに全部を追加すると，`main` の重複でビルドできません．
    この回では，**1課題につき1プロジェクト，その中に1つのCソース**として管理してください．

## 課題1　最初のプログラム

!!! question "自分で保存し，ビルドして実行する"

    `Welcome` プロジェクトに `welcome.c` を作成し，次の2行を表示するプログラムを書いてください．

    ```text
    Welcome to Programming Languages 1.
    I can build and run a C program.
    ```

    `printf` を2回使う方法でも，1回で2行を表示する方法でもかまいません．

??? tip "ヒント"

    講義の `hello.c` を参考にします．行を分けるには，表示する文字列に `\n` を入れます．
    先に保存とビルドを行い，成功したことを確認してから実行します．

**確認すること**：`welcome.c` と，ビルドで生成した `Welcome.exe` が，それぞれどこに保存されているか確認してください．

## 課題2　改行と特殊な文字

!!! question "指定どおりの文字を表示する"

    `Message` プロジェクトに `message.c` を作成し，次の内容を表示してください．2行目は空行です．

    ```text
    My first C program

    She said, "Hello!"
    Backslash: \
    Progress: 100%
    ```

    最後の行の末尾にも改行を入れます．

??? tip "ヒント"

    `\n` は改行，`\"` は二重引用符，`\\` はバックスラッシュを表します．
    `printf` の書式文字列の中で `%` そのものを表示するには，`%%` と書きます．

**説明すること**：ソースコードに書いた `\n` は，画面にバックスラッシュと `n` の2文字として表示されるでしょうか．理由とともに答えてください．

## 課題3　エラーメッセージを読んで修正する

!!! question "誤りを含むプログラムを直す"

    `Broken` プロジェクトを作り，以下を `broken.c` として保存してください．このコードには意図的に誤りを入れてあります．

    ```c title="broken.c（修正前）" linenums="1"
    #include <stdio.h>

    int main(void)
    {
        printf("I fixed the error!\n")
        return 0;
    }
    ```

    1. Ctrl+Shift+Bでビルドする．
    2. 「エラー一覧」またはビルドの「出力」を読み，ファイル名・行番号・原因の説明を記録する．
    3. 原因を修正して保存し，もう一度ビルドする．
    4. ビルドが成功したことを確認してから実行する．

??? tip "ヒント"

    関数呼び出しの文の終わりに，何が必要だったかを確認してください．
    診断は，誤りのある行ではなく，次の `return` の行を指す場合もあります．

**記録すること**：修正前の診断と，修正した箇所を書いてください．診断の文面が他の人と同じである必要はありません．

## 課題4　ソースファイルと実行ファイル

!!! question "保存しただけで，実行結果は変わるか"

    1. `Version` プロジェクトに `version.c` を作成し，`Version A` と表示するプログラムを書く．
    2. ビルドし，実行して結果を確認する．実行後のコンソールは閉じておく．
    3. ソースの表示内容を `Version B` に変更し，保存する．
    4. **ここではまだビルド・実行せず**，既に作成されている `Version.exe` の内容が変わっているかを予測し，理由を記録する．
    5. Visual Studioで改めてビルドし，Ctrl+F5で実行する．

    最初と再ビルド後の表示結果，および保存とビルドの役割の違いを説明してください．

!!! note "予測してからビルドする"

    Visual Studioは，実行前にビルドを行う場合があります．手順4では実行操作をせず，保存したソースと，前回のビルドで作成した実行ファイルの関係を考えてください．

??? tip "最初のプログラム"

    ```c title="version.c（最初の内容）" linenums="1"
    #include <stdio.h>

    int main(void)
    {
        printf("Version A\n");
        return 0;
    }
    ```


## 課題5　発展：文字で図を描く

!!! question "家の形を表示する"

    `House` プロジェクトに `house.c` を作成し，次の図を表示してください．行の先頭の空白にも注意してください．変数や繰り返しは必要ありません．

    ```text
      /\
     /  \
    /____\
    | [] |
    |____|
    ```

??? tip "ヒント"

    画面に表示する1つの `\` に対して，ソースコードでは `\\` と書きます．`/` はそのまま文字列に書けます．

## 確認問題

次の問いに，自分の実行結果や記録をもとに答えてください．

1. Visual StudioのC++プロジェクトでC言語を使うには，ファイル名や設定のどこに注意するか．
2. ソースファイルを保存する操作と，プロジェクトをビルドする操作は，何が違うか．
3. `printf` の文末の `;` と，文字列中の `\n` は何が違うか．
4. `return 0;` は，画面に `0` を表示する文か．
5. プログラムを編集・保存した後，ビルドが失敗した．以前からあるexeが動けば，修正したプログラムが正しいといえるか．
6. ビルドが成功すれば，必ず課題で指定された表示になるか．

## チェックリスト

- Visual Studioでプロジェクトを作成し，Cのソースファイルを追加できる．
- 課題ごとのプロジェクトと，`welcome.c`，`message.c`，修正済みの `broken.c`，`version.c` を保存した．
- 警告やエラーを確認したうえで，それぞれのプログラムをビルド・実行できる．
- 課題2の空行・引用符・バックスラッシュ・パーセントを正しく表示できる．
- 課題3の診断と修正箇所，課題4の結果の違いを説明できる．

次回は **変数** を学びます．決まった文字列の表示から進み，値を保存し，計算して利用する方法を扱います．
