## この講義で学ぶこと

プログラミングとは，解きたい問題を整理し，コンピュータが実行できる手順として表すことです．
この講義では，C言語の基本文法だけでなく，データがメモリに置かれ，関数やポインタを通して扱われる仕組みを学びます．

講義を通して，次のことができるようになることを目指します．

- ソースコードを作成し，コンパイルして実行できる．
- 変数，条件分岐，繰り返し，配列を使って基本的な処理を記述できる．
- 処理を関数に分け，データの受け渡しを説明できる．
- ポインタ，構造体，動的メモリ確保を用いてデータを扱える．
- 入出力，ファイル，分割コンパイルを組み合わせてプログラムを構成できる．
- C言語で学んだ考え方をもとに，他のプログラミング言語との違いを説明できる．

## 資料の使い方

1. **講義**の到達目標と説明を読み，短い例の動作を確認する．
2. **演習**に取り組み，まず自分で結果を予測してから実行する．
3. 予測と結果が異なったら，コードやエラーメッセージを読み直す．
4. 各回のチェックリストで，操作だけでなく理由も説明できるか確認する．

!!! tip "ヒントと解答の提示"

    演習のヒントは，見出しをクリックすると開きます．解答・解説は授業で別途提示します．まず自分で予測し，実行結果とその理由を説明できるようにしましょう．

## 使用する環境

**WindowsのVisual Studio**を使用します．「C++によるデスクトップ開発」の機能で，C言語のソースファイルを作成・ビルド・実行します．Cの例はC17として扱います．

準備の確認方法は，[第1回「作業を始める前に」](lec01.md#environment)を参照してください．
