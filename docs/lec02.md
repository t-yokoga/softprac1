# 第2回　変数


第1回では，決まった文字列を画面に表示しました．今回は，数値や文字を変数に保存し，計算した結果を表示します．
例えば，長方形の縦と横の長さを保存しておけば，その値を使って面積を計算できます．

**名前・型・値**と，値が置かれる**メモリ上の場所**を区別し，コードを1行ずつ追いましょう．

!!! abstract "到達目標"

    - 変数を宣言・初期化し，代入によって値を変更できる．
    - 整数・小数・1文字に適した型を選べる．
    - printfの書式を型に合わせ，値を表示できる．
    - 変数の値・サイズ・アドレスを区別できる．
    - 実行前に値の変化を予測し，実行結果と比較できる．

## 1．前回の復習と作業の準備 { #environment }

### 表示するだけのプログラムから，値を使うプログラムへ

第1回では，mainの中に次の文を書きました．

~~~c
printf("Hello, world!\n");
~~~

今回はmain内に変数を用意し，その値をprintfへ渡します．mainや#includeの基本の形，保存・ビルド・実行の順序は前回と同じです．

### 第2回の作業場所

エクスプローラーで，前回のPL1フォルダの中に `week02` を作成してください．
第1回のファイルはそのまま残し，第2回のプログラムを別に管理します．

~~~text
PL1/
├── week01/
└── week02/
~~~

1. Visual StudioでC++／Windowsの「空のプロジェクト」を作成する．
2. プロジェクト名を `Variables`，場所をweek02にし，ソリューションとプロジェクトを同じディレクトリに配置する．
3. 「ソース ファイル」へ `variables.c` を追加する．
4. Cコードとしてコンパイル（/TC），C17，警告レベル4を設定する．

詳しい画面操作は[第1回のプロジェクト作成](lec01.md#hello)を参照してください．
以降の短いコードは，特に指定がなければmain内に書く**コードの一部**です．
同じ名前の変数を同じ場所で何度も宣言しないよう，確認する断片へ置き換えて試します．

!!! note "今回の入力はソースコードで指定する"

    キーボードから数値を入力する操作はまだ使いません．変数の初期値を書き換えて，保存 → ビルド → 実行を行います．条件分岐や繰り返しも不要です．

## 2．変数に値を保存する { #variables }

### 変数の名前・型・値

次の1行を見てください．

~~~c
int height = 10;
~~~

| 部分 | 役割 | この例での意味 |
| --- | --- | --- |
| int | 型 | 整数を扱う |
| height | 変数名 | 縦の長さを表す名前 |
| 10 | 初期値 | 最初に保存する値 |
| ; | 文法上の区切り | この宣言を終える |

**変数**は，値を保存する領域に名前を付けたものです．
よく「名前の付いた箱」と例えられますが，何でも入れられる箱ではありません．型によって扱う値の種類や範囲が決まります．

heightという名前だけで「縦の長さ」という意味がC言語に伝わるわけではありません．
その意味は人が読み取ります．`a` とだけ書くよりも `height` と書いた方が，計算の目的を理解しやすくなります．

### 宣言・初期化・代入を区別する

変数の型と名前を知らせることを**宣言**といいます．宣言と同時に最初の値を与えることが**初期化**です．
既にある変数に値を保存することを**代入**と呼びます．

~~~c
int height = 10;   // 宣言と初期化
height = 12;      // 既にある変数への代入
~~~

宣言と代入を分けて書くこともできます．

~~~c
int width;       // この段階では，まだ値を使わない
width = 5;       // 値を設定する
printf("%d\n", width);
~~~

この講義では，可能な限り宣言時に初期化します．使う直前まで値が決まらない場合も，読む前には必ず値を設定します．

!!! warning "宣言しただけで0になるとは限らない"

    main内の通常の局所変数は，初期化しなければ値が定まっていません．未初期化の値をprintfで表示して「どんな値か調べる」ことはしません．たまたま0に見えても，正しいコードにはなりません．

### 代入は右辺から左辺へ

`height = 12;` は「heightと12が等しい」という主張ではなく，「右辺の12を左辺のheightへ保存する」操作です．
`12 = height;` とは書けません．値を保存できる変数を左辺に置きます．

~~~c
int count = 3;
count = count + 1;
printf("%d\n", count);
~~~

2行目では，まず右辺のcountの現在値3に1を足して4を求め，その後で左辺のcountへ4を保存します．
数学の方程式として読むと不思議ですが，「計算してから上書きする」と読めば理解できます．
表示される値は4です．演算子の詳しい規則は次回学びます．

### コピーした値は独立している

~~~c
int a = 10;
int b = a;
a = 20;
printf("%d %d\n", a, b);
~~~

この結果は `20 10` です．bを初期化したときに保存したのは，その時点のaの値10です．
aとbが常に連動するように設定したわけではありません．この性質は，計算結果を保存する場合にも当てはまります．

## 3．計算の順番を追う { #calculation }

### 長方形の面積

縦10，横5の長方形の面積を，次のように計算します．Cでは掛け算に `*` を使います．

~~~c
int height = 10;
int width = 5;
int area = height * width;
printf("area=%d\n", area);
~~~

areaには50が保存され，画面には `area=50` と表示されます．
3行目では右辺を計算してからareaを初期化します．変数名を式に書くと，その変数に保存されている値を使います．

### 元の変数を変えたら，結果はどうなるか

続けて，heightだけを12へ変更したとします．

~~~c
height = 12;
printf("height=%d area=%d\n", height, area);
~~~

表示は `height=12 area=50` です．areaにはまだ50が残っています．
表計算ソフトの数式のように，縦の長さが変わったら面積も自動で再計算されるわけではありません．
新しい面積が必要なら，次の文を実行します．

~~~c
area = height * width;
printf("area=%d\n", area);
~~~

今度は60です．各段階の値を表にすると，変化を追いやすくなります．

| 実行した処理 | height | width | area |
| --- | --- | --- | --- |
| 3つの変数を初期化 | 10 | 5 | 50 |
| height = 12; | 12 | 5 | 50 |
| area = height * width; | 12 | 5 | 60 |

!!! tip "実行前に予測する"

    結果が違ったときは，最後のprintfだけでなく，値を設定した行から順に確認します．「その行の実行前に何が入っていて，実行後に何へ変わるか」を記録すると原因を探せます．

### 変数名のルール

この講義では，英字・数字・アンダースコアを組み合わせた名前を使います．先頭は数字にできません．
大文字と小文字は区別され，予約語（言語のために決められた語）は変数名にできません．

| 名前の例 | 使えるか | 理由・注意 |
| --- | --- | --- |
| height | 使える | 何を表すか分かりやすい |
| height2 | 使える | 先頭以外には数字を使える |
| total_price | 使える | アンダースコアを使える |
| Height | 使える | heightとは別の名前 |
| 2height | 使えない | 数字で始まっている |
| total-price | 1つの名前にはできない | -は減算の記号になる |
| int，return | 使えない | 予約語である |

自分で付ける名前では先頭のアンダースコアを避け，型やライブラリの名前と紛らわしい名前も避けましょう．

## 4．データ型を選ぶ { #types }

### 整数・小数・1文字

扱いたい値によって型を選びます．まずは整数ならint，小数を含む計算ならdouble，1文字ならcharを基本とします．

| 型 | 主な用途 | 初期化の例 | printfの書式 |
| --- | --- | --- | --- |
| int | 個数・点数などの整数 | int count = 3; | %d |
| unsigned int | 負の値を使わない整数 | unsigned int flags = 5u; | %u |
| long long | intより広い範囲を扱う整数 | long long n = 10000000000LL; | %lld |
| double | 小数を含む数の近似 | double price = 125.5; | %f |
| float | 通常はdoubleより少ない精度で表す数 | float rate = 0.5f; | %f |
| char | 1文字，小さな整数 | char grade = 'A'; | %c |

ソースに直接書いた10や125.5などの値を**リテラル**と呼びます．
小数のリテラル125.5はdouble型です．floatを表すには0.5fのようにfを付けます．uやLLも型を指定する接尾辞です．

unsignedは，負数を渡したら自動でエラーにしてくれる仕組みではありません．
符号付き・符号なしの変換規則があるため，単に「個数だからunsignedにすれば安全」と考えないようにします．今回は小さい個数にintを使います．

### 整数型の大きさと範囲

型は無限に大きな値を保存できるわけではありません．
整数型にはchar，short，int，long，long longなどがあり，実際のサイズは処理系によります．
**処理系**とは，コンパイラや実行環境など，プログラムを動かす仕組みのことです．

多くのWindows環境でintは4バイトですが，C言語がすべての環境で4バイトと定めているわけではありません．
また「64ビットPCだからlongも必ず8バイト」とは限りません．サイズは後述のsizeofで確かめられます．

`<limits.h>` をインクルードすると，intの下限 `INT_MIN` と上限 `INT_MAX` を表示できます．
これらは処理系が用意した範囲を表す名前です．自分で宣言する必要はありません．

~~~c
printf("int range: %d to %d\n", INT_MIN, INT_MAX);
~~~

!!! warning "範囲を超える計算を試さない"

    符号付き整数で上限を超える計算を行うと，Cでは動作が保証されません．上限に1を足して「必ず負になる」と考えるのは誤りです．範囲を確認する際は，上限・下限を表示するところまでにします．

### 型のサイズと範囲を比較する

次は**WindowsのMSVCでの基本的な整数型**の比較です（1バイト＝8ビット）．C17のすべての処理系で同じ値になるという意味ではありません．longは，MSVCでは64ビット用にビルドしても4バイトです．

| 型 | バイト数 | 値の範囲 |
| --- | ---: | --- |
| signed char | 1 | −128〜127 |
| unsigned char | 1 | 0〜255 |
| short | 2 | −32,768〜32,767 |
| unsigned short | 2 | 0〜65,535 |
| int / long | 4 | −2,147,483,648〜2,147,483,647 |
| unsigned int / unsigned long | 4 | 0〜4,294,967,295 |
| long long | 8 | −9,223,372,036,854,775,808〜9,223,372,036,854,775,807 |
| unsigned long long | 8 | 0〜18,446,744,073,709,551,615 |

charのサイズも1バイトですが，単にcharと書いたときの符号の有無は処理系・設定に依存します．上の2種類とは区別してください．
8ビットには2の8乗＝256通りの並びがあります．同じ8ビットでも，符号なしなら0〜255，2の補数による符号付きなら−128〜127と解釈します．負数の表現は第3回で学びます．

浮動小数点数では，**範囲（どれほど大きい・小さい数を表せるか）**と**精度（何桁程度を区別できるか）**を分けて考えます．次もMSVCでの値です．

| 型 | バイト数 | 十進の有効桁数の目安 | 最小の正の正規化数 | 最大の有限値 |
| --- | ---: | --- | --- | --- |
| float | 4 | 約6〜7桁 | 約1.175×10の−38乗 | 約3.403×10の38乗 |
| double | 8 | 約15〜16桁 | 約2.225×10の−308乗 | 約1.798×10の308乗 |

有効桁数は「小数点以下の桁数」ではなく，数全体の意味のある桁数です．正規化数よりも小さい正の値を表す**非正規化数**もありますが，その領域では精度が低下します．0や負数も表せるため，表の最小値は型全体の下限ではありません．

doubleはfloatより広い範囲と高い精度を持つ一方，1個の変数に使うメモリは2倍です．この講義の通常の小数計算にはdoubleを使い，大量の数値を保存するときには必要な精度と容量を考えて選びます．サイズはsizeof，範囲は整数ならlimits.h，浮動小数点数ならfloat.hのFLT_MAX・DBL_MAXなどで確認できます．

### 小数は近似として保存される

floatやdoubleは**浮動小数点数**を扱う型です．有限のビット数で表すため，すべての小数を厳密に保存できるわけではありません．
例えば0.1は，通常の実習環境では内部で近似値になります．

~~~c
double x = 0.1;
printf("%.1f\n", x);
printf("%.17f\n", x);
~~~

最初は0.1と表示されますが，桁数を増やすと近似の影響が見える場合があります．
表示する桁数を増やしても，変数に保存された値の精度が増えるわけではありません．
doubleを使えばすべての誤差がなくなる，というわけでもありません．

### charで1文字を扱う

`char grade = 'A';` のAは，**シングルクォート**で囲みます．
文字列を表す `"A"` とは異なります．文字列の扱いは第6回で学びます．

charの値は文字コードに対応する整数としても扱えます．また，単にcharと書いた場合に符号付きか符号なしかは処理系によります．
小さな整数として符号の有無を指定したい場合は，signed charまたはunsigned charを使います．
今回の文字の例は，基本的な英数字に限定します．日本語1文字がchar1個に必ず収まるわけではありません．

## 5．printfで値を表示する { #output }

### 書式と値を対応させる

`%d` は，文字列中のその位置にintの値を表示する指定です．
printfへ渡す値は，書式文字列の後ろへ，カンマで区切って並べます．

~~~c
printf("height=%d width=%d\n", height, width);
~~~

最初の%dにheight，次の%dにwidthが対応します．
引用符の内側のheight=という部分はそのまま表示される文字列です．外側のheightは変数の値を参照します．

~~~c
int height = 10;
printf("height\n");
printf("%d\n", height);
~~~

1行目のprintfはheightという6文字，次のprintfは10を表示します．
文字列の中に変数名を書くだけでは，値に置き換わりません．

### 小数の表示桁数

doubleを表示するときは%fを使い，小数点以下の桁数を指定するときは%.2fのように書きます．

~~~c
double price = 125.5;
printf("%f\n", price);
printf("%.2f\n", price);
~~~

表示は順に125.500000，125.50です．通常の%fでは小数点以下6桁を表示します．
%.2fで表示してもpriceに保存された値は変わりません．floatをprintfへ渡す場合はdoubleへ変換されるため，表示には同じ%fを使います．

!!! warning "書式は型変換の指示ではない"

    intを%f，doubleを%dで渡しても，型を変えて表示してくれるわけではありません．型の不一致は未定義動作の原因になります．警告を読んで修正し，誤った書式のまま実行しないでください．

書式と値の個数・順序も合わせます．heightとwidthを逆に渡すような間違いは，警告が出るとは限りません．期待する表示との比較も必要です．

## 6．メモリと変数 { #memory }

### 値はメモリ上に置かれる

**メモリ**は，実行中のプログラムがデータを保持する領域です．
ここでは，小さな区画が並び，各区画に場所を表す番号が付いているものとして考えます．
その場所を表すものが**アドレス**です．

通常のWindows環境では1バイトは8ビットです．ビットは0または1を表し，8ビットなら256通りの並びを作れます．
Cでの1バイトのビット数は `CHAR_BIT` で確認できます．
例えばintが4バイトの環境なら，int変数1つのために4バイト分の領域を使います．

| 観点 | 問い | heightの場合 |
| --- | --- | --- |
| 値 | 何が入っているか | height |
| サイズ | 何バイトを使うか | sizeof height |
| アドレス | どこにあるか | &height |

変数名heightは，ソースコードの中で対象を指定する名前です．
値10と，メモリ上の場所と，領域の大きさ4バイトは，すべて違う情報です．

### 複数バイトを占める変数の図解

次はintが4バイトの環境で，heightに10，widthに5を保存する**概念図**です．1行が1バイトを表し，アドレスは説明用の架空の値です．

~~~text
アドレス     1バイトの区画        変数の領域
0x1000       ┌────────────┐  ← &height（先頭）
             │            │  ┐
0x1001       ├────────────┤  │
             │            │  │ height：4バイトで値10を保存
0x1002       ├────────────┤  │
             │            │  │
0x1003       ├────────────┤  │
             │            │  ┘
0x1004       ├────────────┤  ← &width（先頭）
             │            │  ┐
0x1005       ├────────────┤  │
             │            │  │ width：4バイトで値5を保存
0x1006       ├────────────┤  │
             │            │  │
0x1007       ├────────────┤  │
             │            │  ┘
             └────────────┘
~~~

heightの値10は，各区画に10を1つずつ保存するのではなく，**4バイト全体で1つの値として表現**されます．&heightはその領域の先頭を指します．個々のバイトへの値の分かれ方は，この図では省略しています．

0xは**16進数**の表記です．各桁には0〜9とA〜F（小文字も可）を使い，Aは十進数の10，Fは15です．0x1009の次は0x100A，0x100Fの次は0x1010になります．図では1バイトごとにアドレスが1増えています．

!!! warning "配置は説明のための一例"

    実際に別々の変数が隣接したり，宣言順に並んだりする保証はありません．図の0x1000などを実際のアドレスとして使用しないでください．sizeofは変数自身の大きさであり，隣の変数までの距離を測るものではありません．

### sizeofでサイズを調べる

`sizeof(int)` は型intのサイズ，`sizeof height` はheightの型のサイズを求めます．
sizeofの結果は `size_t` 型なので，printfでは `%zu` を使います．

~~~c
printf("int: %zu bytes\n", sizeof(int));
printf("height: %zu bytes\n", sizeof height);
printf("double: %zu bytes\n", sizeof(double));
~~~

heightに10を保存しても100を保存しても，型がintのままならsizeof heightは変わりません．
表示に必要な十進数の桁数を数えているのではありません．
なお，Cではsizeof(char)は常に1です．

### &でアドレスを調べる

変数名の前に&を付けると，その変数のアドレスを得られます．表示には%pを使います．

~~~c
printf("height address=%p\n", (void *)&height);
~~~

`(void *)` は，%pに合わせて渡す値の型をそろえるために付けています．
詳しい意味は第8回のポインタで扱います．今回は，この形を使って値と場所を区別できれば十分です．

表示の具体的な値や形式は環境により異なります．別々の変数が宣言順に並ぶ保証もありません．
アドレス同士を計算して配置を決めつけたり，見本の数値をソースへ書き込んだりしないでください．

!!! tip "値が変わることと，場所が変わることは別"

    このmain内でheightへ別の整数を代入しても，同じheightの場所は変わりません．中身を上書きしています．ただし，プログラムを起動し直したときに前回と同じアドレスになる保証はありません．

## 7．例題をビルドして確かめる { #example }

ここまでの内容を，1つのプログラムで確認します．Variablesプロジェクトのvariables.cを，次の内容にしてください．
入力後はCtrl+Sで保存し，Ctrl+Shift+Bでビルドします．警告・エラーがないことを確認して，Ctrl+F5で実行します．

~~~c title="variables.c" linenums="1"
--8<-- "sample/02/variables.c"
~~~

[サンプルファイルをダウンロード](sample/02/variables.c){ download }

最初の3行は次のようになります．このコードではheightの変更後にareaを再計算していない点に注意してください．

~~~text
height=10 width=5 area=50
height=12 area=50
price=120.50 grade=A
~~~

続くサイズ・範囲・アドレスの行は，自分の環境で確認してください．
stdio.hはprintfのため，limits.hはCHAR_BITやINT_MIN・INT_MAXのために読み込んでいます．

### 値を1か所変えて確認する

1. 最初のwidthを5から7へ変え，areaがどうなるか予測する．
2. 保存・ビルド・実行し，最初のareaが70になることを確認する．
3. height = 12;の直後にareaの再計算を追加する．
4. 再び保存・ビルド・実行し，2行目のareaが84になることを確認する．

1か所ずつ変更し，予測と結果を記録しましょう．

## 8．よくある間違いと確認方法 { #errors }

| 状況 | 確認すること |
| --- | --- |
| 変数が宣言されていないといわれる | 使う前に宣言したか．heightとHeightなどの綴りが一致しているか． |
| 同じ名前を再定義したといわれる | 値を変えるだけなのに，int heightをもう一度書いていないか． |
| 値が初期化されていないと警告される | その変数を読む前に，初期化または代入したか． |
| printfの型について警告される | 書式と変数の型，値を渡す順序が一致しているか． |
| 面積が前の値のまま | 元の変数の変更後にareaを再計算したか． |
| 小数点以下の見え方が違う | %fと%.2fなどの指定を確認したか． |
| サイズやアドレスが他の人と違う | 環境に依存する情報を，同じ数値だと決めつけていないか． |

誤った書式や未初期化の値は，実行結果から正しさを判断しようとせず，コードと診断をもとに修正します．
ビルドに失敗した場合は，前回と同様に古い実行ファイルを起動しないでください．

## 9．まとめ

変数は，**型と名前を決め，値を保存して使う**ものです．
代入では右辺を計算してから左辺へ保存します．計算結果を変数に保存した後，元の値を変更しても結果は自動では更新されません．
また，値・サイズ・アドレスは別の情報なので，それぞれの意味に合った書式で表示します．

## 確認問題

次の問いに，自分の言葉で答えてみましょう．

- int height = 10;の型・名前・初期値はどの部分か．
- height = height + 1;では，どちらのheightを先に読むか．
- 面積を計算した後，縦の長さだけを変更するとareaはどうなるか．
- %d，%f，%c，%zu，%pは，それぞれ何を表示するために使うか．
- 同じ変数に別の値を代入すると，値・サイズ・場所のどれが変わるか．
