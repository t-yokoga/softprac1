### ソースの書き方

- 課題に示した場合は，すべて`main`から呼び出して表示します．値を書き換えて実行し直すのではなく，1回の実行ですべての結果が表示されるようにします．
- 小問のある課題は，同じプロジェクトのファイルへ小問の順に書き足します．前の小問で作った関数や表示は消さずに残します．
- 関数の名前，引数，戻り値の型は，課題の指定どおりにします．ヘッダは，課題に示した内容と同じにします．
- 表示は，課題に示した出力と同じにします．
- 各ヘッダには，ヘッダごとに異なる名前のインクルードガードを付けます．
- 各`.c`は，自分が使う宣言を持つヘッダだけをインクルードします．関数の本体はヘッダに書かず，`.c`に書きます．

今回のプログラムはどれも入力を待たず，コマンド引数も使いません．実行するとすぐに結果を表示して終了します．

!!! note "ビルドの失敗とその意味"

    講義の表のとおり，ビルドの失敗は段階で切り分けます．ヘッダが見つからなければ前処理の段階で，宣言と定義の型が食い違えばコンパイルの段階で止まります．ヘッダに宣言があっても，定義を持つ`.c`がプロジェクトに入っていない（またはビルドから除外されている）と，リンクの段階で「外部シンボルが未解決」になります．同じ関数の本体を2つの`.c`に書くと，リンクの段階で「シンボルが重複」になります．インクルードガードは同じ翻訳単位の中での重複を防ぐもので，この重複は防げません．

    ビルドに失敗したときは，前回の実行ファイルを実行せず，最初の原因に近い診断から直します．

??? tip "ファイルが見つからないとき"

    エクスプローラーで実際の拡張子を確認します．`calc.h.txt`や`main.c.cpp`になっていないか，同名の別ファイルを編集していないかを調べます．ソリューションエクスプローラーの表示だけで保存場所を判断せず，ファイルのプロパティで実際のパスを確認してください．

## 課題1　計算関数を別ファイルに分ける

`SplitCalc`プロジェクトに`main.c`，`calc.c`，`calc.h`を作ります．この課題では，次の3つの小問を順に行い，同じ3つのファイルへ書き足します．

1. 課題1-1：講義の3ファイルの形で，加算と乗算を別ファイルに分ける．
2. 課題1-2：引き算の関数を追加する．
3. 課題1-3：失敗を戻り値で返す割り算の関数を追加する．

関数を追加するときは，`calc.h`の宣言，`calc.c`の定義，`main.c`の呼び出しの3か所を対応させます．宣言だけでは計算はできず，定義だけでは呼び出し側に正しい型が伝わりません．

### 課題1-1　分割ビルド

加算と乗算の関数を`calc.c`に定義し，`main.c`から`calc.h`を通して呼び出すプログラムを作成し，3組の値で加算と乗算の結果を確認してください．

プログラムが満たすこと（仕様）は次のとおりです．

- `calc.h`と`calc.c`は，講義の[3ファイルの例](lec12.md)と同じ`add`と`multiply`を持つ．`calc.h`のインクルードガードは`PL1_CALC_H`とする．
- `calc.c`は`calc.h`をインクルードする．`main`は書かない．
- `main.c`は`stdio.h`と`calc.h`をインクルードし，関数`void show(double a, double b)`を定義する．`show`は`printf("a=%.1f b=%.1f add=%.1f multiply=%.1f\n", a, b, add(a, b), multiply(a, b));`で表示する．
- `main`では，`show(1.5, 2.0);`，`show(0.0, 3.0);`，`show(-2.0, 4.0);`の順に呼ぶ．

表示は次のようになります．

~~~text
a=1.5 b=2.0 add=3.5 multiply=3.0
a=0.0 b=3.0 add=3.0 multiply=0.0
a=-2.0 b=4.0 add=2.0 multiply=-8.0
~~~

`main.c`に`add`の本体がなくてもコンパイルできるのは，`calc.h`の宣言で引数と戻り値の型が分かるからです．本体はリンクの段階で`calc.c`から作ったオブジェクトと結び付けられます．`calc.h`をインクルードしただけでは`calc.c`はビルド対象にならないので，`calc.c`もプロジェクトに追加します．

### 課題1-2　引き算を追加する

`double`の引数2つの差を返す関数`subtract`を`calc.c`に追加して`main.c`から呼び出すプログラムを作成し，3組の値で差を確認してください．

- `calc.h`に`double subtract(double a, double b);`を宣言し，`calc.c`に定義する．`subtract`は`a - b`を返す．
- `main.c`に関数`void show_subtract(double a, double b)`を定義する．`show_subtract`は`printf("%.1f - %.1f = %.1f\n", a, b, subtract(a, b));`で表示する．
- `main`で，課題1-1の表示の後に`show_subtract(5.0, 2.0);`，`show_subtract(0.0, 0.0);`，`show_subtract(2.0, 5.0);`の順に呼ぶ．

表示は，課題1-1の3行に続けて次の3行が出ます．

~~~text
5.0 - 2.0 = 3.0
0.0 - 0.0 = 0.0
2.0 - 5.0 = -3.0
~~~

### 課題1-3　失敗を返す割り算を追加する

割る数が0.0なら失敗を戻り値で返し，成功したときだけ商をポインタの先へ保存する関数`calc_divide`を`calc.c`に追加して`main.c`から呼び出すプログラムを作成し，4組の値で戻り値と保存先の値を確認してください．

第8回の「戻り値で成功・失敗を返し，ポインタで結果を返す」を，別ファイルの関数にします．関数名は，標準ライブラリの`div`と衝突しないように`calc_divide`とします．

- 関数の形は`int calc_divide(double a, double b, double *out)`とする．`out`は有効な`double`を指すことを呼び出し側の条件とする．
- `b`が0.0なら，`*out`を変更せずに0を返す．それ以外は`a / b`を`*out`へ保存し，1を返す．
- 関数を使う側に引数の条件と戻り値の意味が伝わるように，`calc.h`の宣言の前にコメントを書く．
- `main.c`に関数`void show_divide(double a, double b)`を定義する．`show_divide`は`double result = 99.0;`を宣言して`int ok = calc_divide(a, b, &result);`を実行し，`printf("%.1f / %.1f: ok=%d result=%.1f\n", a, b, ok, result);`で表示する．
- `main`で，課題1-2の表示の後に`show_divide(6.0, 2.0);`，`show_divide(-6.0, 2.0);`，`show_divide(0.0, 2.0);`，`show_divide(6.0, 0.0);`の順に呼ぶ．

課題1を終えたときの`calc.h`は次のとおりです．

~~~c
#ifndef PL1_CALC_H
#define PL1_CALC_H
double add(double a, double b);
double multiply(double a, double b);
double subtract(double a, double b);
/* outは有効なdoubleを指す．bが0.0なら0を返し，*outを変更しない． */
int calc_divide(double a, double b, double *out);
#endif
~~~

表示は，課題1-2までの6行に続けて次の4行が出ます．

~~~text
6.0 / 2.0: ok=1 result=3.0
-6.0 / 2.0: ok=1 result=-3.0
0.0 / 2.0: ok=1 result=0.0
6.0 / 0.0: ok=0 result=99.0
~~~

??? tip "ヒント"

    0で割ってから調べるのではなく，計算前に`b`を検査します．失敗時に`out`へ書き込まなければ，呼び出し前の値を保てます．

最後の行の`99.0`は計算結果ではなく，呼び出し前の値が残ったものです．利用側は`ok`を見てから結果を使います．

課題1全体の表示は次の10行になります．

~~~text
a=1.5 b=2.0 add=3.5 multiply=3.0
a=0.0 b=3.0 add=3.0 multiply=0.0
a=-2.0 b=4.0 add=2.0 multiply=-8.0
5.0 - 2.0 = 3.0
0.0 - 0.0 = 0.0
2.0 - 5.0 = -3.0
6.0 / 2.0: ok=1 result=3.0
-6.0 / 2.0: ok=1 result=-3.0
0.0 / 2.0: ok=1 result=0.0
6.0 / 0.0: ok=0 result=99.0
~~~

## 課題2　ベクトルと行列のモジュール

`VectorCalc`プロジェクトに`vector_main.c`，`vector.c`，`matrix.c`，`vector.h`，`matrix.h`を作ります．他の課題の`main.c`は追加しません．この課題では，次の2つの小問を順に行います．

1. 課題2-1：講義のベクトルと行列のモジュールを使い，いくつかの行列と係数で計算する．
2. 課題2-2：内積と転置の関数をモジュールに追加する．

### 課題2-1　行列とベクトルの計算

講義の[ベクトルと行列のモジュール](lec12.md)を使い，`axpy`と`gemv`を複数の行列と係数で計算するプログラムを作成し，単位行列の場合と`alpha`が0の場合の結果と，呼び出し後も`x`と`y`が変わらないことを確認してください．

プログラムが満たすこと（仕様）は次のとおりです．

- `vector.h`，`vector.c`，`matrix.h`，`matrix.c`は，講義と同じ内容から始める．`matrix.h`は，宣言に使う`Vector`のために自分で`vector.h`をインクルードする．
- `vector_main.c`は，`stdio.h`，`matrix.h`，`vector.h`をこの順にインクルードする．`vector.h`は`matrix.h`経由と直接の2回取り込まれるので，インクルードガードが必要になる．
- `vector_main.c`に関数`void show_gemv(double alpha, Matrix a, Vector x, double beta, Vector y)`を定義する．`show_gemv`は，`print_matrix(a)`で行列を表示し，`printf("alpha=%.1f beta=%.1f gemv=", alpha, beta);`に続けて`gemv(alpha, a, x, beta, y)`の結果を`print_vector`で表示する．
- `main`では，`Vector x = {{1.0, 2.0}};`，`Vector y = {{3.0, 4.0}};`，`Matrix a = {{1.0, -1.0, -1.0, 1.0}};`，単位行列`Matrix identity = {{1.0, 0.0, 0.0, 1.0}};`を宣言し，次の順に処理する．
    1. `printf("axpy=");`に続けて`axpy(2.0, x, y)`の結果を`print_vector`で表示する．
    2. `show_gemv(2.0, a, x, 1.0, y);`
    3. `show_gemv(2.0, identity, x, 1.0, y);`
    4. `show_gemv(0.0, a, x, 1.0, y);`
    5. `printf("x=");`に続けて`x`を，`printf("y=");`に続けて`y`を`print_vector`で表示する．

表示は次のようになります．

~~~text
axpy=(5.0, 8.0)
[1.0 -1.0]
[-1.0 1.0]
alpha=2.0 beta=1.0 gemv=(1.0, 6.0)
[1.0 0.0]
[0.0 1.0]
alpha=2.0 beta=1.0 gemv=(5.0, 8.0)
[1.0 -1.0]
[-1.0 1.0]
alpha=0.0 beta=1.0 gemv=(3.0, 4.0)
x=(1.0, 2.0)
y=(3.0, 4.0)
~~~

単位行列では2Ax+yが2x+yと同じ(5.0, 8.0)になり，`alpha`が0で`beta`が1なら，`A`や`x`に関係なく`y`になります．`axpy`と`gemv`は値渡しされた構造体から新しい`Vector`を作って返すので，`x`と`y`は変わりません．

インクルードガードは，同じ翻訳単位（前処理後の1つのソース）の中で，ヘッダの本体を1回だけ有効にします．ガードがないと，`vector_main.c`の中に`Vector`の構造体の定義が2回現れてエラーになります．一方，`vector.c`と`matrix.c`は別の翻訳単位なので，それぞれが`vector.h`を読みます．また，`matrix.h`が自分で`vector.h`を取り込んでいるので，利用側はインクルードの順序を気にせずに済みます．「同じ内容を二度読まない工夫」（ガード）と「必要な型をヘッダ自身で用意する工夫」は別のものです．

### 課題2-2　内積と転置を追加する

ベクトルの内積を返す関数`dot`を`vector`モジュールに，行列の転置を返す関数`transpose`を`matrix`モジュールに追加して`vector_main.c`から呼び出すプログラムを作成し，内積の値と，転置の前後で`gemv`の結果が変わることを確認してください．

- `vector.h`に`double dot(Vector a, Vector b);`を宣言し，`vector.c`に定義する．`dot`は`a.v[0] * b.v[0] + a.v[1] * b.v[1]`を返す．
- `matrix.h`に`Matrix transpose(Matrix a);`を宣言し，`matrix.c`に定義する．`transpose`は，`a`の行と列を入れ替えた新しい`Matrix`を返す．`v[0]`，`v[1]`が第1行，`v[2]`，`v[3]`が第2行である．
- `main`で，課題2-1の表示の後に次の順に処理する．
    1. `Matrix b = {{1.0, 2.0, 3.0, 4.0}};`を宣言する．
    2. `printf("dot(x, y)=%.1f\n", dot(x, y));`と`printf("dot(x, x)=%.1f\n", dot(x, x));`を実行する．
    3. `show_gemv(1.0, b, x, 0.0, y);`と`show_gemv(1.0, transpose(b), x, 0.0, y);`を呼ぶ．

課題2を終えたときの`vector.h`と`matrix.h`は次のとおりです．

~~~c
#ifndef PL1_VECTOR_H
#define PL1_VECTOR_H

typedef struct {
    double v[2];
} Vector;

Vector axpy(double alpha, Vector a, Vector b);
void print_vector(Vector a);
double dot(Vector a, Vector b);

#endif
~~~

~~~c
#ifndef PL1_MATRIX_H
#define PL1_MATRIX_H

#include "vector.h"

typedef struct {
    double v[4];
} Matrix;

Vector gemv(double alpha, Matrix a, Vector x, double beta, Vector y);
void print_matrix(Matrix a);
Matrix transpose(Matrix a);

#endif
~~~

表示は，課題2-1の12行に続けて次の8行が出ます．

~~~text
dot(x, y)=11.0
dot(x, x)=5.0
[1.0 2.0]
[3.0 4.0]
alpha=1.0 beta=0.0 gemv=(5.0, 11.0)
[1.0 3.0]
[2.0 4.0]
alpha=1.0 beta=0.0 gemv=(7.0, 10.0)
~~~

`dot`の宣言は`vector.h`にあるので，`vector_main.c`からは直接インクルードした`vector.h`でも，`matrix.h`経由でも見えます．`transpose`の戻り値は`Matrix`の値なので，`show_gemv`の引数にそのまま渡せます．

課題2全体の表示は次のようになります．

~~~text
axpy=(5.0, 8.0)
[1.0 -1.0]
[-1.0 1.0]
alpha=2.0 beta=1.0 gemv=(1.0, 6.0)
[1.0 0.0]
[0.0 1.0]
alpha=2.0 beta=1.0 gemv=(5.0, 8.0)
[1.0 -1.0]
[-1.0 1.0]

dot(x, x)=5.0
~~~

## 課題3　内部の状態を隠すモジュール

数を足し込むカウンタの値を`counter.c`の中に隠し，公開した関数だけで操作するプログラムを作成し，加算とリセットの後の値を確認してください．

`Counter`プロジェクトに`counter_main.c`，`counter.c`，`counter.h`を作ります．プログラムが満たすこと（仕様）は次のとおりです．

- `counter.h`は次のとおりとする．変数の宣言は置かない．

    ~~~c
    #ifndef PL1_COUNTER_H
    #define PL1_COUNTER_H
    void counter_reset(void);
    void counter_add(int amount);
    int counter_value(void);
    #endif
    ~~~

- `counter.c`は`counter.h`をインクルードし，ファイルスコープに`static int count = 0;`を置く．`counter_reset`は`count`を0にし，`counter_add`は`count`に`amount`を加え，`counter_value`は`count`を返す．
- `counter_main.c`は`count`を直接使わず，ヘッダの3つの関数だけを使う．
- `counter_main.c`に関数`void add_and_show(int amount)`を定義する．`add_and_show`は`counter_add(amount)`を呼び，`printf("add %d -> %d\n", amount, counter_value());`で表示する．
- `main`では，次の順に処理する．
    1. `printf("start=%d\n", counter_value());`
    2. `add_and_show(3);`，`add_and_show(4);`，`add_and_show(-2);`
    3. `counter_reset();`の後に`printf("reset=%d\n", counter_value());`
    4. `add_and_show(5);`

表示は次のようになります．

~~~text
start=0
add 3 -> 3
add 4 -> 7
add -2 -> 5
reset=0
add 5 -> 5
~~~

ファイルスコープの`static`は，名前を他の翻訳単位から直接参照させない指定です．`count`を変更できるのは`counter.c`の関数だけになり，`counter_main.c`は公開された関数を通して値を扱います．ヘッダに`int count = 0;`のような定義を書くと，ヘッダを読む`.c`ごとに同じ変数が定義され，リンクで重複します．

## 発展1　並べ替えのモジュール

整数配列を昇順に並べ替える処理と，個数を表す文字列を検査して変換する処理を`intlib`モジュールに分けたプログラムを作成し，正しい個数と不正な文字列，`int`の両端の値を含む配列で結果を確認してください．

`SortModule`プロジェクトに`sort_main.c`，`intlib.c`，`intlib.h`を作ります．利用者は比較の方法を意識せず，`sort_ints`を呼び出すだけで並べ替えられるようにします．プログラムが満たすこと（仕様）は次のとおりです．

- `intlib.h`は次のとおりとする．`size_t`を使う宣言があるので，ヘッダ自身が`stddef.h`をインクルードする．

    ~~~c
    #ifndef PL1_INTLIB_H
    #define PL1_INTLIB_H

    #include <stddef.h>

    #define INTLIB_CAPACITY 8

    /* outは有効なintを指す．失敗時は変更しない． */
    int parse_count(const char *text, int *out);
    /* aは少なくともn個のintを持つ配列を指す． */
    void sort_ints(int a[], size_t n);

    #endif
    ~~~

- `parse_count`は，`text`を`strtol`で10進数として変換する．数字がない，末尾に余計な文字（空白を含む）がある，`long`の範囲を超える，0〜`INTLIB_CAPACITY`の範囲外，のどれかなら0を返して`*out`を変更しない．それ以外は値を`*out`へ保存して1を返す．先頭の空白や`+`符号は`strtol`の規則どおりに受け付ける．
- `sort_ints`は`qsort`で`a`の先頭`n`個を昇順に並べ替える．比較関数`compare_int`は`intlib.c`の中だけで使うので`static`にし，`intlib.h`には宣言しない．
- `compare_int`は引き算の結果を返さず，大小を比べて−1，0，1のどれかを返す．
- `sort_main.c`は`limits.h`，`stdio.h`，`intlib.h`をインクルードし，次の2つの関数を定義する．
    - `void print_ints(const int a[], int n)`：`a`の先頭`n`個を，それぞれ`printf(" %d", a[i]);`で表示し，最後に改行する．
    - `void sort_and_show(const char *text)`：`int data[INTLIB_CAPACITY] = {7, -2, 7, 0, 3, 9, -8, 1};`と`int n = -1;`を宣言し，`parse_count(text, &n)`を呼ぶ．失敗したら`printf("\"%s\" -> invalid n=%d\n", text, n);`で表示する．成功したら`data`の先頭`n`個を`sort_ints`で並べ替え，`printf("\"%s\" ->", text);`に続けて`print_ints(data, n)`で表示する．
- `main`では，次の12個の文字列の順に`sort_and_show`を呼ぶ．

| `text` | 内容 |
| --- | --- |
| `"5"`，`"0"`，`"1"`，`"8"` | 正しい個数 |
| `" +3"` | 先頭の空白と`+`符号 |
| `""`，`"abc"` | 数字がない |
| `"3x"`，`"3 "` | 末尾に余計な文字がある |
| `"-1"`，`"9"` | 0〜8の範囲外 |
| `"999999999999999999999999"` | `long`の範囲を超える |

- 続けて`int extreme[] = {INT_MAX, INT_MIN, 0, INT_MIN};`を宣言して`sort_ints(extreme, 4)`で並べ替え，`printf("extreme:");`に続けて`print_ints(extreme, 4)`で表示する．

表示は次のようになります．`int`が32ビットの環境（Visual Studioを含む）での表示です．

~~~text
"5" -> -2 0 3 7 7
"0" ->
"1" -> 7
"8" -> -8 -2 0 1 3 7 7 9
" +3" -> -2 7 7
"" -> invalid n=-1
"abc" -> invalid n=-1
"3x" -> invalid n=-1
"3 " -> invalid n=-1
"-1" -> invalid n=-1
"9" -> invalid n=-1
"999999999999999999999999" -> invalid n=-1
extreme: -2147483648 -2147483648 0 2147483647
~~~

??? tip "qsortの比較関数"

    比較関数に渡される`const void *`は要素へのポインタです．今回の要素型は`int`なので，`const int *`として読み出します．`qsort`には`compare_int`と関数名を渡します．`compare_int(...)`と書いてその場で呼び出した結果を渡すのではありません．関数を必要なときに呼んでもらう仕組みをコールバックと呼びます．

`"0"`では要素を表示せず，`->`の後で改行します．失敗したときに`n=-1`のままなのは，`parse_count`が保存先を変更しないからです．`INT_MAX`と`INT_MIN`の差は`int`の範囲に収まらないので，`a - b`を返す比較関数ではオーバーフローします．大小を比べて−1，0，1を返せば，両端の値も正しく並べ替えられます．

`compare_int`は並べ替えの内部の都合なので公開しません．`sort_ints`を入口にすれば，内部の方法を変えても呼び出し方を保てます．固定配列の容量（8）と有効な個数`n`（0〜8）は別のものです．

## 発展2　標準ライブラリの使用条件

数学関数，文字の判定，文字列とバイト列のコピー，`assert`，擬似乱数を使い，それぞれの結果を0または1などの決まった値で表示するプログラムを作成し，`strcpy`と`memcpy`のコピー範囲の違いと，同じ種から同じ乱数列が得られることを確認してください．

`LibraryCheck`プロジェクトに`library_check.c`を作ります．自作の`calc.c`などは入れません．プログラムが満たすこと（仕様）は次のとおりです．

- 先頭で`#define _CRT_SECURE_NO_WARNINGS`を定義し，使う関数に対応する標準ヘッダ（`assert.h`，`ctype.h`，`float.h`，`math.h`，`stdio.h`，`stdlib.h`，`string.h`）をインクルードする．
- `char src[5] = {'a', 'b', '\0', 'c', 'd'};`，`char text[10] = {0};`，`char bytes[10] = {0};`を宣言し，`strcpy`で`src`を`text`へ，`memcpy`で`src`の`sizeof src`バイトを`bytes`へコピーする．
- `printf("math=%.1f %.1f %.1f\n", ...)`で，`sqrt(9.0)`，`pow(3.0, 2.0)`，`fabs(-2.5)`を表示する．
- `printf("alpha=%d digit=%d min_positive=%d\n", ...)`で，`'A'`が英字か，`'7'`が数字か，`FLT_MIN`が正かを0または1で表示する．`isalpha`と`isdigit`には`unsigned char`へ変換した値を渡し，結果は`!= 0`で0または1にする．
- `printf("text=%s bytes=%c%c %c%c\n", ...)`で，`text`と，`bytes`の添字0，1，3，4の文字を表示する．
- `assert`で`text[2]`が`'\0'`であることと，`bytes[3]`が`'c'`であることを確かめる．`assert`の式には，コピーや`rand`の呼び出しなどの副作用を書かない．
- `srand(123U);`の後の`rand()`を`first`に，もう一度`srand(123U);`とした後の`rand()`を`again`に保存し，`printf("same_seed=%d\n", first == again);`で表示する．乱数の値そのものは表示しない．
- 続けて`double u = (double)rand() / RAND_MAX;`を求め，`printf("in_range=%d\n", 0.0 <= u && u <= 1.0);`で表示する．

表示は次のようになります．

~~~text
math=3.0 9.0 2.5
alpha=1 digit=1 min_positive=1
text=ab bytes=ab cd
same_seed=1
in_range=1
~~~

`FLT_MIN`は`float`の最も負の値ではなく，最小の正の正規化数です．`strcpy`は最初の`'\0'`まで（終端を含む）を，`memcpy`は指定した5バイトをコピーするので，`bytes`には`c`と`d`も入ります．同じ種で最初から生成し直したので`first`と`again`は一致しますが，その値自体は環境によって異なるので表示しません．

`_CRT_SECURE_NO_WARNINGS`は，容量が確認できる固定例で`strcpy`を学ぶための指定です．危険なコピーを安全にする機能ではありません．一般の入力では，終端までの長さとコピー先の容量を必ず調べます．`NDEBUG`を定義すると`assert`は無効になり，式そのものが評価されなくなるので，必要な処理を`assert`の式に入れてはいけません．

!!! note "静的ライブラリについて"

    課題1の`calc.c`と`calc.h`は，静的ライブラリ（`.lib`）にして別のアプリのプロジェクトから使うこともできます．ソースは課題1と同じで，変わるのはプロジェクトの設定だけなので，この演習の提出物にはしていません．試す場合は，元の`SplitCalc`を残し，別のソリューションで次のように設定します．

    1. 空のプロジェクト`CalcLib`を作り，「プロパティ → 構成プロパティ → 全般 → 構成の種類」を「スタティック ライブラリ（`.lib`）」にする．C17とCとしてコンパイルも設定し，`calc.c`と`calc.h`だけを入れる．
    2. 同じソリューションへ空のプロジェクト`CalcApp`を追加し，同じ設定で`main.c`だけを入れる．
    3. `CalcApp`の「参照 → 参照の追加」で`CalcLib`を選ぶ．
    4. `CalcApp`の「C/C++ → 全般 → 追加のインクルード ディレクトリ」に，`calc.h`のある`CalcLib`のフォルダを追加する．既存の設定値は残す．
    5. 両プロジェクトの構成とプラットフォーム（x64等）をそろえ，`CalcApp`をスタートアッププロジェクトにしてビルドする．

    ヘッダの検索先と，リンクするライブラリの参照は別の設定です．配布された`.lib`を使う場合は，講義の表の「追加のライブラリ ディレクトリ」と「追加の依存ファイル」も設定します．ライブラリを更新したら，アプリを再リンクしないと新しい内容は取り込まれません．`CalcLib`は静的ライブラリなので，`CalcLib.dll`は作られません．

## 確認問題

この節は自習用で，成績には含めません．

1. 「`calc.h`を追加したので`calc.c`を追加しなくてもよい」は正しいか．
2. インクルードガードで，同じ外部関数を2つの`.c`に定義した問題は解決するか．
3. `.lib`の検索先が正しくても，ヘッダが見つからないことはあるか．
4. 静的ライブラリを更新すれば，配布済みの`.exe`も自動的に新しくなるか．
5. 不完全型の`Vector *`を宣言できることと，`Vector`の実体を作れることは同じか．

## チェックリスト

- 各課題のプロジェクトに，表のファイルがすべて入り，警告なしでビルドできる．
- `main`を持つファイルが，各プロジェクトに1つだけある．
- 各ヘッダに，ヘッダごとに異なる名前のインクルードガードがある．
- ヘッダには宣言や型の定義だけを書き，関数の本体や変数の定義を書いていない．
- 各`.c`が，必要なヘッダだけをインクルードしている．定義を持つ`.c`は，自分のヘッダもインクルードしている．
- 内部だけで使う関数や変数に`static`を付け，ヘッダに宣言していない．
- 1回の実行で，課題に示したすべての場合の結果が表示される．
- 表示が，課題に示した出力と一致する．
- 関数の名前，引数，戻り値の型が課題の指定どおりである．
- 小問のある課題で，前の小問の関数や表示を残している．
