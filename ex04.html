    第4回　演習：制御構造¶

    解答・解説は授業で別途提示します．このページには問題とヒントを掲載しています．

    講義を読んでから取り組んでください．出力と処理の流れを予測しましょう．

    準備と進め方¶

    作業場所は PL1\week04 です．第1回と同じ設定（Cとしてコンパイル，C17，警告レベル4）で，課題ごとに別の空のプロジェクトを作ります．特に指定がなければ，mainを持つソースは1プロジェクトに1つです．保存後にCtrl+Shift+Bでビルドし，Ctrl+F5で実行します．

    各課題で，ソース，試した値，予測，実行結果，結果の説明を残してください．提出先や締切は，授業時に案内します．

    今回の課題¶

    課題 主な内容 確認すること
    1 if・else ifによる料金分類 条件の順序と境界
    2 forとwhileによる合計 初期化・条件・更新
    3 二重ループの掛け算表 内側の初期化と改行位置
    4 2の累乗とdo-while 回数ではなく値で継続を決める
    発展 break・continue・switch 移動先とフォールスルー

    基本課題1〜4を順に進め，発展は基本が終わってから取り組んでください．入力関数は使わず，ソース内の初期値を変えて確認します．各課題では「動いた」だけで終えず，どの条件が真になり，何回本体を実行したかを説明します．

    各プログラムに共通の手順¶

    1. プロジェクトを作り，.cファイルを1つ追加する．
    2. 入力に相当する固定値と，予想する表示を書く．
    3. 条件式と更新を紙上で追い，停止することを確認する．
    4. 保存・ビルド後に実行し，表示と予想を比較する．
    5. 指定の境界値へ1か所ずつ変更し，再度ビルド・実行する．
    6. 結果が違ったら，最初に予想とずれた条件や変数を探す．

    記録は「変更した値／予想／実行結果／そうなる理由」の4項目に分けると整理しやすくなります．実行が止まらなければ中断して確認してください．整数の範囲を超えるまでループを伸ばす実験は行いません．

    課題1　料金を分類する¶

    Fee プロジェクトでageを固定値として宣言し，0〜5歳は0，6〜17歳は500，18歳以上は1000を表示してください．負の年齢はinvalidと表示します．-1，0，5，6，17，18で確認してください．

    初期値はage = 17とします．表示するのは料金の数値だけで，最後に改行します．年齢の不正値を最初に除き，残った値を小さい区分から分類しましょう．次の表は「どれか1行だけ」に該当するように読みます．

    age 期待する表示 調べる境界
    −1 記入してください 許される範囲の手前
    0 記入してください 最小の有効値
    5 記入してください 無料の最後
    6 記入してください 500の最初
    17 記入してください 500の最後
    18 記入してください 1000の最初
    ヒント

    小さい区分からelse ifで調べます．

    条件の順序を確かめる¶

    age <= 17をage <= 5より前に置くと，ageが5のときどうなるでしょうか．変更前に予想し，実行後は正しい順序に戻してください．また，else ifを別々のifへ変えると，複数の表示が出る場合があります．条件が独立になることを図や言葉で説明してください．

    説明すること：負の年齢の検査を省くと，−1はどの区分に入るか．また，18歳以上を最後のelseだけで表せるのはなぜか．

    課題2　偶数の合計¶

    EvenSum プロジェクトで，1からnまでの偶数の合計をfor文で求めます．nは0〜100の固定値とし，n=10なら30を表示してください．0，1，2，100でも確認します．

    n=10のときは2＋4＋6＋8＋10＝30です．合計用のsumとカウンタのiは役割が異なります．sumはそれまでの結果を保存し，iは現在調べている数を表します．

    ヒント

    sumを0にし，ループ内でiが2で割り切れるときだけ加算します．

    0，1，2，100の期待値は順に0，0，2，2550です．同じ処理をwhileでも書き，結果を比較してください．

    値を追跡する¶

    n=4として，紙上で次の表を埋めてから実行してください．

    本体に入るときのi 偶数か 加算前のsum 加算後のsum
    1 いいえ 0 0
    2 はい 0 ?
    3 いいえ ? ?
    4 はい ? ?

    whileへ書き換える¶

    forの初期化をループの前へ，更新を本体の最後へ移します．以下で元のfor全体を置き換え，n=0，1，2，10，100で同じ結果になることを確認してください．sumの初期化と最後のprintfはそのまま残します．

    説明すること：n=0では条件判定と本体はそれぞれ何回行われるか．sum = 0を本体の中へ移してはいけないのはなぜか．

    余裕があれば，iを2から始めて2ずつ増やすforへ変更します．偶数だけを通るため，偶奇判定のifは不要です．出力は同じでも，本体の実行回数が違うことを確かめましょう．

    課題3　小さな掛け算表¶

    Table プロジェクトで1〜3の掛け算表を表示します．外側を行，内側を列にします．

    rowを1〜3，colを1〜3として，row * colを表示します．列の間には半角スペースを1つ入れ，各数値は%2dで表示します．行の最後に余分な区切りのスペースは付けず，改行を1回入れます．

     1  2  3
 2  4  6
 3  6  9
    ヒント

    %2dは最低2文字幅で整数を表示します．改行は内側のループが終わった後です．

    外側と内側の関係を確認する¶

    rowが1の間に，colは1，2，3を通ります．rowが2になったらcolは再び1から始まります．組(row, col)の順を9組書き出してください．rowを更新する前に，内側の条件が偽になるまで実行する点に注意します．

    次に，列の上限と列間の判定を3から4へ変更し，3行4列の表を作ります．行の上限は変更しません．本体の表示回数は何回になるでしょうか．

     1  2  3  4
 2  4  6  8
 3  6  9 12

    説明すること：改行を内側のループへ移したときと，外側のループより後へ移したとき，表の形はどう変わるか．予想してから1か所ずつ変更し，確認後は元へ戻してください．

    課題4　100未満の2の累乗¶

    Powers プロジェクトで，1から始めて値を2倍しながら，100未満の2の累乗を表示してください．for版とwhile版を順に作成します．数字の後ろにはコンマと半角スペースを入れ，最後に改行を1回だけ表示します．この課題では最後の64の後ろにも区切りを付けます．

    1, 2, 4, 8, 16, 32, 64,

    変数limitを100とします．本体の中で毎回改行せず，改行用のprintfはループの後に置きます．入力ではなく値の初期化だけで条件を変更できるようにしましょう．

    ヒント

    カウンタを1ずつ増やす必要はありません．初期値は1，継続条件はpower < limit，更新はpower *= 2です．powerが128になったら条件が偽になります．

    境界を確かめる¶

    limitを次の値へ変更し，両方の版で確認してください．この課題のlimitは1〜100に限定し，むやみに上限を大きくしてはいけません．条件を満たさなくなる直前の更新でも，計算結果が型の範囲に収まる必要があります．

    limit 表示する数 本体の回数
    1 なし（改行だけ） 記入してください
    2 1 記入してください
    64 1，2，4，8，16，32 記入してください
    65 1，2，4，8，16，32，64 記入してください
    100 1，2，4，8，16，32，64 記入してください

    説明すること：powerが64のとき，本体と更新の後にどの値で条件を調べるか．また，<を<=へ変更するとlimit=64の表示がどう変わるか．

    do-whileとの違いを確認する¶

    while版のwhile全体を次の部分に置き換えてください．その前にあるpowerの初期化と，その後の改行は残します．limit=1と100の結果を予測します．

    do {
    printf("%d, ", power);
    power *= 2;
} while (power < limit);

    発展　break・continue・switchを追跡する¶

    途中で飛ばす処理¶

    次の断片をmain内で実行する前に表示順を答えてください．

    for (int i = 0; i < 6; ++i) {
    if (i == 2) { continue; }
    if (i == 4) { break; }
    printf("%d\n", i);
}

    次に，i == 4の部分のbreakをcontinueへ変更します．表示は0，1，3，5になります．どちらの場合もi == 2のcontinueからはforの更新へ進むことを説明してください．

    switchとifを比較する¶

    YearGroup プロジェクトで，school_yearが1か2ならlower years，3か4ならupper years，それ以外ならinvalidと表示します．次の例を読み，school_yearを0〜5まで変えて実行してください．

    同じ処理をif・else if・elseで書き換え，結果を比較します．case 1とcase 2の間に処理がない理由と，printfの後にbreakがある理由を別々に説明してください．

    switch版で最初のbreakだけを外すと，school_year=2でlower yearsの後にupper yearsも表示されます．これはcase 3の条件に一致したからではなく，次の文へ実行が続いたためです．予想と照合したらbreakを戻してください．

    確認問題¶

    1. if (3)は真・偽のどちらの経路へ進むか．
    2. flagが−1の場合，if (flag)，if (!flag)，if (flag == 1)はそれぞれ真か偽か．
    3. for (int i = 0; i < 3; ++i)の本体と条件判定はそれぞれ何回か．
    4. whileとdo-whileの本体の実行回数が異なるのは，どのような開始条件か．
    5. forのcontinueはどこへ進むか．whileではどうか．
    6. 3行4列の二重ループで，内側が毎回1回目にbreakしたら，本体は合計何回か．
    7. switchのdefaultがなく，一致するcaseもないとき，どこへ進むか．
    8. 講義のgotoの例でgoto done;をbreak;に置き換えても同じ表示になるのはなぜか．

    チェックリスト¶

    • 正常な値だけでなく，課題に示された境界の値でも確認した．
    • 警告を確認し，原因を説明・修正した．
    • 自分の言葉で，処理の流れと使った型を説明できる．
    • 0回・1回・複数回の反復を区別して説明できる．
    • breakとcontinue，switchのcaseとifの条件を混同していない．
