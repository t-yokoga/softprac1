    第2回　演習¶

    解答・解説は授業で別途提示します．このページには問題とヒントを掲載しています．

    第2回の講義を読み，variables.cをビルド・実行できることを確認してから取り組んでください． 今回は，変数に値を保存し，計算・代入・表示を行います． ソースを書き換える前と実行する前に，どの変数の値が変わるかを予測しましょう．

    演習の進め方¶

    課題1〜4を順に進め，最後に確認問題に答えてください．課題5は発展課題です． キーボードからの数値入力，条件分岐，繰り返しは使いません． 値を変えて試す場合は，ソースを編集してから保存・ビルド・実行を行います．

    作業場所と記録

    講義で用意した PL1\week02 を作業場所にします． 課題ごとにソースと実行結果を保存し，memo.txtなどに予測・結果・理由を記録してください． 提出先や締切は，授業時に案内します．

    課題 内容 プロジェクト名 ソースファイル
    1 長方形の面積と再計算 Rectangle rectangle.c
    2 型と表示の対応 Profile profile.c
    3 値のコピーと交換 Exchange exchange.c
    4 値・サイズ・場所の観察 Observe observe.c
    5 発展：小数を使った計算 Temperature temperature.c

    各プログラムに共通の手順¶

    第1回の手順に従い，1課題につき1つの空のプロジェクトを作ります． 場所はweek02とし，ソリューションとプロジェクトを同じディレクトリに配置します．

    1. 表の名前の.cファイルを「ソース ファイル」に追加する．
    2. Cコードとしてコンパイル（/TC），C17，警告レベル4を設定する．
    3. コードを入力し，Ctrl+Sで保存する．
    4. Ctrl+Shift+Bでビルドし，警告・エラーを確認する．
    5. 成功したらCtrl+F5で実行し，予測した結果と比較する．

    別々のmainを同じプロジェクトに入れない

    各課題のプログラムは，それぞれmainを持つ独立したプログラムです． 講義のvariables.cを入れたまま別のプログラムを追加すると，mainが重複します．課題ごとにプロジェクトを分けてください．

    課題1　長方形の面積と再計算¶

    変数を変更した後に，面積を求め直す

    Rectangleプロジェクトにrectangle.cを作り，次の処理を行ってください．

    1. int型のheightを7，widthを4で初期化する．
    2. areaへ縦と横の積を保存し，表示する．
    3. widthへ6を代入する．
    4. 再計算する前のareaを表示する．
    5. areaを計算し直し，表示する．

    期待する表示は次の3行です．

    first=28
before recalculation=28
after recalculation=42
    ヒント

    宣言・初期化ではint area = height * width;と書きます． 同じareaへもう一度値を保存するときにはintを付けず，area = height * width;と書きます． widthへの代入だけではareaは変わりません．

    値を変えて確かめる¶

    途中の width = 6; の6を，0，1に変えて確認します．最初のwidth = 4は変更しません． 実行前に，3行すべての出力を予測してください．

    説明すること：areaに保存しているのは計算式そのものですか，その時点の計算結果ですか．

    課題2　型と表示の対応¶

    整数・小数・1文字を使い分ける

    Profileプロジェクトにprofile.cを作り，個数3をintのcount，単価125.5をdoubleのprice，区分Bをcharのgradeへ保存してください． countとpriceの積をdoubleのtotalに保存し，次のように表示します．

    count=3 price=125.50 grade=B
total=376.50

    計算済みの表示文字列を直接書かず，変数をprintfに渡してください．

    ヒント

    intは%d，doubleは%f，1文字は%cで表示します． 単価と合計は小数点以下2桁にするため%.2fを使います．区分の初期値は'B'です． 整数とdoubleの積はdoubleになります．型変換は第6回で詳しく扱います．

    表示方法を変えてみる¶

    1. priceを表示する%.2fだけを%fへ変更して実行する．
    2. 125.500000と表示されることを確認する．
    3. countを0へ変え，totalが0.00になることを確認する．
    4. 最後に最初の設定へ戻して保存する．

    説明すること：%.2fを%fへ変えると，priceに保存された値も変わりますか．

    型と違う書式で試さない

    priceに%d，countに%fを対応させて実験しないでください．書式と型の不一致は実行前に修正します．

    課題3　値のコピーと交換¶

    上書きで値を失わないようにする

    Exchangeプロジェクトにexchange.cを作ります．intのaを10，bを20で初期化し，最後にaが20，bが10になるように値を交換してください． 交換前と交換後を，次のように表示します．

    before: a=10 b=20
after: a=20 b=10

    次の2文だけでは正しく交換できません．まず，それぞれの文の実行後のaとbを紙に書いてください．

    a = b;
b = a;
    ヒント

    a = b;を実行した時点で，aにあった10は失われます． もう1つint型の変数tempを用意して，元のaの値を保存しておきます．

    別の値でも確認する¶

    初期値をa = -3，b = 8とした場合，a = 5，b = 5とした場合でも確認します．

    記録すること：一時変数を使わない2文の結果と，tempを使った結果の違いを書いてください．

    課題4　値・サイズ・場所の観察¶

    同じ変数を，3つの観点から観察する

    Observeプロジェクトにobserve.cを作り，intのvalueを10で初期化します．値・サイズ・アドレスを表示し，99を代入して再び表示してください．どの項目が変わるか予測します． 最後にchar，int，long，long long，doubleのサイズも表示します．

    ヒント

    valueの値には%d，sizeofの結果には%zu，アドレスには%pを使います． アドレスを渡す部分は(void *)&valueと書きます．その詳しい意味は第8回で学びます．

    観察表を作る¶

    項目 変更前 変更後 変化したか
    valueの値 10 記入してください 自分で記入
    sizeof value 自分の結果 記入してください 自分で記入
    &valueの表示 自分の結果 記入してください 自分で記入

    表を埋め，型ごとのサイズも記録します．起動し直した際のアドレスは前回と同じとは限りません．

    説明すること：1000を保存するとsizeof valueも変わりますか．また「64ビットPCならすべての変数が8バイト」は正しいでしょうか．

    課題5　発展：小数を使った計算¶

    摂氏から華氏へ変換する

    Temperatureプロジェクトにtemperature.cを作り，摂氏celsiusから華氏fahrenheitを求めてください． 変換式は fahrenheit = celsius * 9.0 / 5.0 + 32.0 です． 両方をdoubleで保存し，celsius = 25.0のとき次のように表示します．

    Celsius=25.0 Fahrenheit=77.0

    掛け算は*，割り算は/です．小数の計算に9.0や5.0を使います．

    ヒント

    表示は小数点以下1桁なので%.1fです．fahrenheitの値を77.0と直接書くのではなく，celsiusから計算します．

    値を変えて確かめる¶

    celsiusの初期値を0.0，100.0，-40.0に変更して，それぞれ32.0，212.0，-40.0になることを確認します． celsiusを計算後に変更した場合には再計算が必要です．

    確認問題¶

    次の問いに，コードや実行結果をもとに答えてください．

    1. int count = 3;とcount = 5;では，どちらが宣言と初期化を行うか．
    2. int a = 10; int b = a;の後にaを20へ変えると，bはどうなるか．
    3. heightを変更しただけで，前に計算したareaが自動で更新されるか．
    4. doubleの値を%dへ渡せば，整数に変換して表示されるか．
    5. char型の1文字の初期値に使うのは'A'と"A"のどちらか．
    6. sizeofで得られるのは，値・サイズ・アドレスのどれか．
    7. 未初期化の変数が一度0と表示されたら，いつでも0だと考えてよいか．
    8. 同じ実行中にint変数の値を変えると，サイズとアドレスも変わるか．

    チェックリスト¶

    • 課題1〜4のプロジェクトとソースを保存した．
    • 警告・エラーを確認し，型とprintfの書式を合わせた．
    • 課題1の再計算前と再計算後の違いを説明できる．
    • 課題2の書式を変えた結果と，変数の値そのものを区別できる．
    • 課題3で，なぜ元の値を一時変数へ保存するのか説明できる．
    • 課題4の観察表を埋め，値・サイズ・場所を区別できる．

    次回は演算子を学びます．今回使った足し算や掛け算に加え，比較・論理演算・ビット演算を扱います．
