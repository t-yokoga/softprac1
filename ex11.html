    第11回　演習：構造体¶

    解答・解説は授業で別途提示します．このページには問題とヒントを掲載しています．

    講義を読んでから取り組んでください．

    準備と進め方¶

    作業場所はPL1\week11です．第1回と同じ設定（Cとしてコンパイル，C17，警告レベル4）を使います．演習では，課題ごとに別の空のプロジェクトを作り，次のファイルを1つだけ追加します．

    課題・小問 プロジェクト名 ソースファイル
    課題1：値渡しとポインタ渡し PointMove point_move.c
    課題2-1〜2-3：学生の点数 Students students.c
    課題3：長方形の面積 RectArea rect_area.c
    課題4：配列メンバとポインタメンバ CopyMembers copy_members.c
    発展1：初期化と構造体を返す関数 PointInit point_init.c
    発展2：長方形の正規化と包含判定 RectContains rect_contains.c
    発展3：構造体の配置 StructLayout struct_layout.c

    各プロジェクトはPL1\week11の下へ保存します．1つのプロジェクトにmainを持つファイルを複数追加しないでください．

    同じソリューションへ複数のプロジェクトを追加した場合は，実行したいプロジェクトを右クリックして「スタートアッププロジェクトに設定」を選びます．

    保存後にCtrl+Shift+Bでビルドし，成功を確認してCtrl+F5で実行します．

    提出するのは，上の表の7つのソースファイルです．成績はソースファイルで評価します．提出先や締切は，授業時に案内します．

    ソースの書き方¶

    • 課題に示した場合は，すべてmainから呼び出して表示します．値を書き換えて実行し直すのではなく，1回の実行ですべての結果が表示されるようにします．
    • 小問のある課題は，同じファイルへ小問の順に書き足します．前の小問で作った関数や表示は消さずに残します．
    • 型の名前とメンバ，関数の名前，引数，戻り値の型は，課題の指定どおりにします．
    • 表示は，課題に示した出力と同じにします．

    今回のプログラムはどれも入力を待ちません．実行するとすぐに結果を表示して終了します．座標は有限な−1000〜1000の値，点数は0〜100です．

    構造体の定義はmainより前に1回だけ置きます．指定初期化子の書き方で診断が出た場合は，.cppではなく.cで，C17としてコンパイルしているかも確認します．初期化していない構造体のメンバ，寿命が終わった配列を指すポインタ，文字列リテラルへの書き込みは，ソースに書きません．

    課題1　値渡しとポインタ渡し¶

    Pointを値で受け取る関数とポインタで受け取る関数で点を移動するプログラムを作成し，呼び出し方と移動量によって，どの変数が変わるかを確認してください．

    PointMoveプロジェクトにpoint_move.cを作ります．プログラムが満たすこと（仕様）は次のとおりです．

    • 講義のPoint（doubleのメンバx，y）と，Point moved(Point p, double dx, double dy)，void move_in_place(Point *p, double dx, double dy)をmainの前に定義する．
    • 関数void show(const char *label, Point p)を作り，printf("%s=(%.1f, %.1f)\n", label, p.x, p.y);で表示する．
    • 関数void try_move(double dx, double dy)を作る．try_moveは次の処理を順に行う．
      1. Point a = {1.0, 2.0};とPoint b = moved(a, dx, dy);を宣言する．
      2. printf("move %.1f %.1f: a=(%.1f, %.1f) b=(%.1f, %.1f)", dx, dy, a.x, a.y, b.x, b.y);を実行する（改行なし）．
      3. move_in_place(&a, dx, dy);を呼び，printf(" -> a=(%.1f, %.1f)\n", a.x, a.y);を実行する．
    • mainでは，まず移動量（dx，dy）を（3.0，−1.0），（0.0，0.0），（−1.0，−2.0），（2.0，3.0）の順にtry_moveを呼ぶ．
    • 続けて，それぞれ{1.0, 2.0}で初期化した3つの変数ignored，assigned，in_placeで，次の3つの呼び出し方を試し，変数名をラベルにしてshowで表示する．
    変数 呼び出し方
    ignored moved(ignored, 3.0, -1.0);
    assigned assigned = moved(assigned, 3.0, -1.0);
    in_place move_in_place(&in_place, 3.0, -1.0);
    • 最後にPoint copy = in_place;を宣言してcopy.x = 100.0;とし，show("in_place", in_place);とshow("copy", copy);で表示する．

    表示は次のようになります．

    move 3.0 -1.0: a=(1.0, 2.0) b=(4.0, 1.0) -> a=(4.0, 1.0)
move 0.0 0.0: a=(1.0, 2.0) b=(1.0, 2.0) -> a=(1.0, 2.0)
move -1.0 -2.0: a=(1.0, 2.0) b=(0.0, 0.0) -> a=(0.0, 0.0)
move 2.0 3.0: a=(1.0, 2.0) b=(3.0, 5.0) -> a=(3.0, 5.0)
ignored=(1.0, 2.0)
assigned=(4.0, 1.0)
in_place=(4.0, 1.0)
in_place=(4.0, 1.0)
copy=(100.0, 1.0)

    movedのpはaのコピーなので，関数内でpを変更してもaは変わらず，戻り値を受け取ったbだけが移動します．move_in_placeのpもコピーですが，コピーされたのはポインタの値です．そのコピーがaを指しているので，p->xへの代入でaのメンバが変わります．

    値渡しの関数でも，assigned = moved(assigned, ...)のように戻り値を元の変数へ代入すれば，結果としてその変数を更新できます．戻り値を受け取らないignoredは変わりません．関数内での変更と，呼び出し側の代入を分けて考えます．

    copyはin_placeと同じ値を持ちますが，別の保存場所です．copy.xを変更してもin_placeは変わりません．構造体のコピーを，ポインタのコピーと混同しないようにします．

    課題2　学生の点数¶

    Studentsプロジェクトにstudents.cを作ります．この課題では，次の3つの小問を順に行い，同じファイルへ書き足します．

    1. 課題2-1：Student配列の平均点を求める．
    2. 課題2-2：配列の2つの要素を，構造体ごと交換する．
    3. 課題2-3：2人の学生が同じかを，名前と点数で判定する．

    3つの小問で，講義と同じ次の型を使います．

    typedef struct {
    char name[16];
    int score;
} Student;

    課題2-1　平均点を求める¶

    Student配列の点数の平均を求めるプログラムを作成し，人数と点数を変えた6通りで平均を確認してください．

    プログラムが満たすこと（仕様）は次のとおりです．

    • 関数double average(const Student a[], int n)を作り，a[0]〜a[n-1]のscoreの平均を返す．nは1以上で，aには少なくともn人分のデータがあるものとする．
    • 関数void show_average(const Student a[], int n)を作り，printf("n=%d average=%.1f\n", n, average(a, n));で表示する．
    • mainでは，次の4つの配列を宣言し，表の順にshow_averageを呼ぶ．
    Student a[] = {{"Aki", 80}, {"Ren", 70}, {"Mio", 90}};
Student zeros[] = {{"Aki", 0}, {"Ren", 0}, {"Mio", 0}};
Student fulls[] = {{"Aki", 100}, {"Ren", 100}, {"Mio", 100}};
Student changed[] = {{"Aki", 80}, {"Ren", 70}, {"Mio", 91}};
    配列 n
    a 3
    a 1
    a 2
    zeros 3
    fulls 3
    changed 3

    表示は次のようになります．

    n=3 average=80.0
n=1 average=80.0
n=2 average=75.0
n=3 average=0.0
n=3 average=100.0
n=3 average=80.3
    ヒント

    配列の各要素から.scoreを取り出して合計します．合計はintで求め，割る前にdoubleへ変換します．

    a[1]は2人目のStudent，a[1].scoreはその点数70，a[1].nameは名前を保存した配列で，a[1].name[0]は'R'です．仮引数aはStudent配列の先頭へのポインタで，3人分の構造体が自動でコピーされているわけではありません．変更しないことを示すためにconstを付けています．

    n=4なら存在しない要素へ進み，n=0なら0で割るので，どちらもaverageには渡しません．

    課題2-2　構造体ごと交換する¶

    配列のa[0]とa[2]を構造体ごと交換するプログラムを作成し，交換後の名前と点数の対応と平均を確認してください．

    • 関数void print_students(const Student a[], int n)を作り，各要素をprintf("%s %d\n", a[i].name, a[i].score);で1行ずつ表示する．
    • mainで，課題2-1の表示の後に，Student型の変数tempを使ってa[0]とa[2]を交換する．
    • 交換後にprint_students(a, 3);とshow_average(a, 3);を呼ぶ．

    課題2-1の6行に続けて，次の4行が表示されます．

    Mio 90
Ren 70
Aki 80
n=3 average=80.0

    構造体の代入では，nameの配列もscoreも一緒にコピーされます．scoreだけを交換すると，名前と点数の対応が壊れます．構造体へまとめたことで，「1人分」という単位で操作できます．

    課題2-3　同じ学生か判定する¶

    名前と点数がどちらも一致するときに同じ学生とみなす関数を加えたプログラムを作成し，3通りの組合せで判定結果を確認してください．

    • string.hをインクルードし，関数int same_student(Student left, Student right)を作る．名前の内容がstrcmpで等しく，かつ点数が等しければ1，そうでなければ0を返す．
    • mainで，課題2-2の表示の後にStudent mio = {"Mio", 90};とStudent low = {"Mio", 0};を宣言する．
    • printf("same=%d %d %d\n", same_student(a[0], mio), same_student(a[2], mio), same_student(low, mio));で表示する．aは課題2-2で交換した後の配列である．

    課題2-2の表示に続けて，次の1行が表示されます．

    same=1 0 0

    left == rightという比較はCの構造体には使えません．また，nameのアドレスの一致ではなく，文字列の内容を比較します．同名の学生を区別する必要があるなら，学生番号など別のメンバを設計します．

    課題2全体の表示は次のようになります．

    n=3 average=80.0
n=1 average=80.0
n=2 average=75.0
n=3 average=0.0
n=3 average=100.0
n=3 average=80.3
Mio 90
Ren 70
Aki 80
n=3 average=80.0
same=1 0 0

    課題3　長方形の面積¶

    Pointを2つと名前を持つRectの面積を求めるプログラムを作成し，4通りの長方形の面積と，同じメンバを表す4つの書き方の値を確認してください．

    RectAreaプロジェクトにrect_area.cを作ります．プログラムが満たすこと（仕様）は次のとおりです．

    • 講義と同じPointと，enum { MAX_NAME = 20 };を使ったRect（メンバPoint lower，Point upper，char name[MAX_NAME + 1]）を定義する．
    • 関数double area(const Rect *r)を作り，(upper.x − lower.x) × (upper.y − lower.y)を返す．upperの各座標はlower以上であるものとする．
    • 関数void show_area(const Rect *r)を作り，printf("%s lower=(%.1f, %.1f) upper=(%.1f, %.1f) area=%.1f\n", r->name, r->lower.x, r->lower.y, r->upper.x, r->upper.y, area(r));で表示する．
    • mainでは，次の4つの長方形を指定初期化子で作り，表の順にshow_areaを呼ぶ．
    name lower upper
    "sample" (1, 2) (5, 5)
    "zero_width" (1, 2) (1, 5)
    "zero_height" (1, 2) (5, 2)
    "negative" (−2, −1) (1, 3)
    • 続けて，"sample"の長方形をRect rにコピーし，Rect *q = &r;を宣言して，printf("%.1f %.1f %.1f %.1f\n", r.lower.x, (r.lower).x, q->lower.x, (q->lower).x);で表示する．

    表示は次のようになります．

    sample lower=(1.0, 2.0) upper=(5.0, 5.0) area=12.0
zero_width lower=(1.0, 2.0) upper=(1.0, 5.0) area=0.0
zero_height lower=(1.0, 2.0) upper=(5.0, 2.0) area=0.0
negative lower=(-2.0, -1.0) upper=(1.0, 3.0) area=12.0
1.0 1.0 1.0 1.0
    ヒント

    rがRectへのポインタなら，r->lowerはPoint本体です．そのxはr->lower.xと書きます．

    mainのr.lower.xのrはRect本体，areaのr->lower.xのrはRectへのポインタです．lowerはPointへのポインタではないので，q->lower->xとは書けません．*q.lower.xという書き方も，必要な間接参照の順序になりません．

    このareaは，upperの各座標がlower以上であることを前提にしています．両方の差が負なら積が正になってしまうので，面積が正だっただけでは前提を守った証拠になりません．座標の順序をそろえる処理は発展2で扱います．

    nameは21要素なので，ASCIIなら20文字と終端を保存できます．宣言後にr.name = "other";とは書けません．構造体全体の代入ができることと，配列メンバ単独への代入ができることは別です．

    課題4　配列メンバとポインタメンバ¶

    文字列を配列メンバに持つ構造体と，ポインタメンバで指す構造体をそれぞれコピーするプログラムを作成し，一方を変更したときに他方から変更が見えるかを確認してください．

    CopyMembersプロジェクトにcopy_members.cを作ります．プログラムが満たすこと（仕様）は次のとおりです．

    • 講義のTextArray（メンバchar text[7]）とTextPointer（メンバchar *text）を定義する．
    • 関数void replace_with_fuga(char *dst)を作る．const char replacement[] = "fuga";の終端を含む全要素（sizeof replacement個）を，添字を使ってdstへコピーする．dstは5要素以上の書き換え可能な配列を指すものとする．
    • mainでは，次の処理を順に行う．
      1. TextArray a1 = {.text = "hoge"};，TextArray a2 = a1;とし，a1.text[0] = 'H';の後にprintf("array=%s %s\n", a1.text, a2.text);を実行する．
      2. char buffer[] = "hoge";，TextPointer p1 = {.text = buffer};，TextPointer p2 = p1;とし，p1.text[0] = 'H';の後にprintf("pointer=%s %s same=%d\n", p1.text, p2.text, p1.text == p2.text);を実行する．
      3. char other[] = "fuga";とし，p1.text = other;の後にprintf("redirect=%s %s same=%d\n", p1.text, p2.text, p1.text == p2.text);を実行する．
      4. replace_with_fuga(a1.text);の後に，1.と同じprintfを実行する．
      5. char shared[] = "hoge";，TextPointer p3 = {.text = shared};，TextPointer p4 = p3;とし，replace_with_fuga(p3.text);の後にprintf("shared=%s %s same=%d\n", p3.text, p4.text, p3.text == p4.text);を実行する．

    表示は次のようになります．

    array=Hoge hoge
pointer=Hoge Hoge same=1
redirect=fuga Hoge same=0
array=fuga hoge
shared=fuga fuga same=1
    処理 直接変更するもの 他方にも見えるか
    a1.text[0] = 'H'; a1の内部配列 a2には見えない
    p1.text[0] = 'H'; 共有しているbuffer p2からも見える
    p1.text = other; p1に入っているアドレス p2のアドレスは変わらない

    ポインタをコピーした直後は同じ場所を指すため，==で1になります．sameはアドレスの比較で，文字列の内容を比較するstrcmpとは目的が違います．構造体をコピーしても，ポインタメンバが指す文字列本体は複製されません．

    replace_with_fugaは，十分な容量があると分かっている固定の文字列だけをコピーします．任意の長さの文字列を受け付けるなら，第8回の容量検査を行う関数が必要です．

    書かない例

    次の3つは，コンパイルできても実行時に正しく動く保証がないので，ソースに書きません．

    • ポインタメンバへ文字列リテラル"hoge"を入れ，その先へ書き込む．文字列リテラルは変更できません．読み取り用途ならconst char *を使います．
    • 関数内のchar buffer[8]を指す構造体を返し，関数終了後に表示する．構造体のコピーではbufferの寿命は延びません．
    • 未初期化のTextPointerへ，いきなりtext[0]を書き込む．構造体の宣言は，ポインタの先の文字配列を作りません．

    発展1　初期化と構造体を返す関数¶

    指定初期化子，省略したメンバ，複合リテラル，構造体を返す関数，タグ付きのtypedefを使うプログラムを作成し，各メンバに入る値を確認してください．

    PointInitプロジェクトにpoint_init.cを作ります．プログラムが満たすこと（仕様）は次のとおりです．

    • Pointを，タグ付きのtypedef struct point { double x; double y; } Point;の形で定義する．
    • 関数Point add_point(Point a, Point b)を作り，xどうし，yどうしを足したPointを返す．
    • mainでは，次の処理を順に行う．
      1. Point a = {.y = 2.0, .x = 10.0};，Point b = {.x = 3.0, .y = 5.0};，Point result = add_point(a, b);とし，printf("a=%.1f %.1f result=%.1f %.1f\n", a.x, a.y, result.x, result.y);を実行する．
      2. Point ordered = {2.0, 10.0};とし，printf("ordered=%.1f %.1f\n", ordered.x, ordered.y);を実行する．
      3. Point partial = {.x = 3.0};，Point zero = {0};とし，printf("partial=%.1f %.1f zero=%.1f %.1f\n", partial.x, partial.y, zero.x, zero.y);を実行する．
      4. 複合リテラルでa = (Point){.x = -1.0, .y = 4.0};と代入し，printf("assigned=%.1f %.1f\n", a.x, a.y);を実行する．
      5. struct point tagged = add_point(b, (Point){.x = 1.0, .y = 1.0});とし，printf("tagged=%.1f %.1f\n", tagged.x, tagged.y);を実行する．

    表示は次のようになります．

    a=10.0 2.0 result=13.0 7.0
ordered=2.0 10.0
partial=3.0 0.0 zero=0.0 0.0
assigned=-1.0 4.0
tagged=4.0 6.0

    aは.yを先に書いていますが，yへ2.0，xへ10.0が入ります．名前を指定しないorderedは宣言順に対応するので，x=2.0，y=10.0となり，aとは同じ意味になりません．

    partial.yとzeroの両メンバは0.0です．これは初期化リストで省略したメンバが0に相当する値で初期化されるためで，「初期化しなくても構造体は0になる」という意味ではありません．Point partial;とだけ宣言したローカル変数のメンバは読みません．

    (Point)を省略したa = {.x = -1.0, .y = 4.0};は正しい代入式ではありません．複合リテラルはPoint型の値として扱えるので，構造体全体の代入や関数の引数に使えます．

    struct pointとPointは同じ型を表すので，struct pointの変数へadd_pointの戻り値を代入できます．typedefは型に別名を付けるだけで，typedefの定義だけで座標データが1個作られるわけではありません．typedef int JPY;とJPY price = 100;も，前者は別名を付け，後者は変数を作ります．

    発展2　長方形の正規化と包含判定¶

    2点の順序をそろえた長方形を作る関数と，点が長方形の範囲内かを判定する関数を使うプログラムを作成し，4通りの2点の並びと8通りの点で結果を確認してください．

    RectContainsプロジェクトにrect_contains.cを作ります．プログラムが満たすこと（仕様）は次のとおりです．

    • 課題3と同じPointとRectを定義する．
    • 講義のRect normalized(Rect r)とint contains(Point p, Rect r)をmainの前に定義する．範囲は下限を含み，上限を含まない．
    • 関数void show_normalized(Rect r)を作る．show_normalizedはRect standard = normalized(r);とし，printf("%s lower=(%.1f, %.1f) upper=(%.1f, %.1f) original=(%.1f, %.1f) (%.1f, %.1f)\n", standard.name, standard.lower.x, standard.lower.y, standard.upper.x, standard.upper.y, r.lower.x, r.lower.y, r.upper.x, r.upper.y);で表示する．
    • 関数void show_contains(Point p, Rect r)を作り，printf("%s (%.1f, %.1f) inside=%d\n", r.name, p.x, p.y, contains(p, r));で表示する．
    • mainでは，次の4つの長方形について，表の順にshow_normalizedを呼ぶ．
    name lower upper
    "same" (1, 1) (3, 4)
    "reversed" (3, 4) (1, 1)
    "cross_a" (1, 4) (3, 1)
    "cross_b" (3, 1) (1, 4)
    • 続けて，Rect r = {.lower = {1.0, 4.0}, .upper = {3.0, 1.0}, .name = "sample"};とRect standard = normalized(r);を宣言し，次の7つの点について，表の順にshow_contains(点, standard)を呼ぶ．
    点 意味
    (2, 2) 内側
    (1, 1) 下限
    (1, 3) xが下限，yが範囲内
    (3, 2) xの上限
    (2, 4) yの上限
    (0, 2) xが下限より小さい
    (2, 5) yが上限より大きい
    • 最後に，幅0の長方形Rect line = {.lower = {1.0, 1.0}, .upper = {1.0, 4.0}, .name = "line"};と点(1, 2)でshow_containsを呼ぶ．

    表示は次のようになります．

    same lower=(1.0, 1.0) upper=(3.0, 4.0) original=(1.0, 1.0) (3.0, 4.0)
reversed lower=(1.0, 1.0) upper=(3.0, 4.0) original=(3.0, 4.0) (1.0, 1.0)
cross_a lower=(1.0, 1.0) upper=(3.0, 4.0) original=(1.0, 4.0) (3.0, 1.0)
cross_b lower=(1.0, 1.0) upper=(3.0, 4.0) original=(3.0, 1.0) (1.0, 4.0)
sample (2.0, 2.0) inside=1
sample (1.0, 1.0) inside=1
sample (1.0, 3.0) inside=1
sample (3.0, 2.0) inside=0
sample (2.0, 4.0) inside=0
sample (0.0, 2.0) inside=0
sample (2.0, 5.0) inside=0
line (1.0, 2.0) inside=0
    ヒント

    表の長方形は，(Rect){.lower = {1.0, 1.0}, .upper = {3.0, 4.0}, .name = "same"}のような複合リテラルでshow_normalizedへ直接渡せます．

    2点を丸ごと交換するだけでは，cross_aやcross_bのような交差した組合せを正規化できません．xとyを独立にそろえます．

    normalizedの最初のRect result = r;は，座標だけでなく名前もコピーします．そのため，正規化後のnameも元の名前のままです．normalizedはrのコピーから結果を作るので，originalに表示した呼び出し元の座標は入力の順序のままです．元の変数も正規化したい場合はr = normalized(r);と代入します．

    上限の点が0になるのは，上限を含まない仕様だからです．幅0や高さ0の長方形では，この条件を満たす点はありません．閉じた図形なら境界も含めるという直感だけで，<を<=へ変えないでください．まず仕様を決めます．

    発展3　構造体の配置¶

    講義のRecordの全体のサイズと各メンバの位置を表示するプログラムを作成し，全体のサイズとメンバのサイズの合計の違いを確認してください．

    StructLayoutプロジェクトにstruct_layout.cを作ります．プログラムが満たすこと（仕様）は次のとおりです．

    • stdio.hとstddef.hをインクルードし，講義のRecord（メンバchar tag，int count，char flagをこの順に持つ）を定義する．
    • mainでは，printf("size=%zu tag=%zu count=%zu flag=%zu\n", sizeof(Record), offsetof(Record, tag), offsetof(Record, count), offsetof(Record, flag));を実行する．
    • 続けて，3つのメンバのサイズの合計をprintf("members=%zu\n", sizeof(char) + sizeof(int) + sizeof(char));で表示する．

    表示は次のようになります．

    size=12 tag=0 count=4 flag=8
members=6

    1行目の値は環境によって異なります．上の値は，Visual Studioの既定設定（x64，intが4バイト）での値です．tagが0であることと，tag，count，flagの順に位置が大きくなることは，どの環境でも同じです．

    sizeがmembersより大きいのは，countを4の倍数の位置に置くための隙間（tagの後の3バイト）と，配列にしたときに次のRecordのcountもそろうようにする末尾の隙間（flagの後の3バイト）があるためです．この課題では隙間の中身は表示しません．パディングの値は一定とは限らないので，memcmpで構造体全体を比較して同じデータか判定する用途にも使いません．

    構造体全体をfwriteすると，メンバの表現だけでなく，処理系依存の配置や隙間も保存されます．ポインタメンバのアドレスを保存しても，次の実行で同じ文字列を指せるとは限りません．保存形式は，第10回のようにメンバごとに意味を決めて設計します．

    確認問題¶

    この節は自習用で，成績には含めません．

    1. struct pointの定義とPoint p;は何が違うか．
    2. 指定初期化子で.yを先に書くと，値の対応は変わるか．
    3. 構造体内の配列もコピーされるのに，通常の配列代入ができないのは矛盾か．
    4. Pointを値で渡す場合とPoint配列を渡す場合は同じか．
    5. q->lower.xでは，なぜ->とドットが両方必要か．
    6. ポインタメンバのコピーは，指す先の寿命を延ばすか．
    7. 長方形を正規化するとき，2点を交換するだけで十分か．
    8. containsで上限の点が0になるのはバグか．

    チェックリスト¶

    • 各課題のソースが1つのファイルにまとまり，警告なしでビルドできる．
    • 1回の実行で，課題に示したすべての場合の結果が表示される．
    • 表示が，課題に示した出力と一致する．
    • 型の名前とメンバ，関数の名前，引数，戻り値の型が課題の指定どおりである．
    • 小問のある課題で，前の小問の関数や表示を残している．
    • 初期化していないメンバ，寿命が終わった配列を指すポインタ，文字列リテラルへの書き込みを書いていない．
