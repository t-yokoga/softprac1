    第9回　演習：ポインタ2¶

    解答・解説は授業で別途提示します．このページには問題とヒントを掲載しています．

    講義を読んでから取り組んでください．

    準備と進め方¶

    作業場所はPL1\week09です．第1回と同じ設定（Cとしてコンパイル，C17，警告レベル4）を使います．演習では，課題ごとに別の空のプロジェクトを作り，次のファイルを1つだけ追加します．

    課題・小問 プロジェクト名 ソースファイル
    課題1-1〜1-3：最大要素の場所 FindMax find_max.c
    課題2-1〜2-2：ポインタ配列の文字列 Names names.c
    課題3-1〜3-2：行ごとの平均 MatrixMean matrix_mean.c
    課題4：二次元配列の行の交換 SwapRows swap_rows.c
    発展1：長さが異なる行 RaggedRows ragged_rows.c
    発展2：配列とポインタの型 ArrayTypes array_types.c

    各プロジェクトはPL1\week09の下へ保存します．1つのプロジェクトにmainを持つファイルを複数追加しないでください．

    同じソリューションへ複数のプロジェクトを追加した場合は，実行したいプロジェクトを右クリックして「スタートアッププロジェクトに設定」を選びます．

    保存後にCtrl+Shift+Bでビルドし，成功を確認してCtrl+F5で実行します．

    提出するのは，上の表の6つのソースファイルです．成績はソースファイルで評価します．提出先や締切は，授業時に案内します．

    今回の課題¶

    課題 内容 確認すること
    1 二重ポインタと最大要素の検索 値の出力と場所の出力，失敗時の扱い
    2 文字列の表示順の交換 ポインタの交換と，文字の書き換え
    3 二次元配列の平均 列数の固定，行数の受け渡し，配列へのポインタ
    4 二次元配列の行交換 固定幅の要素の交換
    発展 長さの違う行と型の整理 int **とint (*)[3]

    ソースの書き方¶

    • 課題に示した場合は，すべてmainから呼び出して表示します．値を書き換えて実行し直すのではなく，1回の実行ですべての結果が表示されるようにします．
    • 小問のある課題は，同じファイルへ小問の順に書き足します．前の小問で作った関数や表示は消さずに残します．
    • 関数の名前，引数，戻り値の型は，課題の指定どおりにします．
    • 表示は，課題に示した出力と同じにします．

    今回のプログラムはどれも入力を待ちません．実行するとすぐに結果を表示して終了します．アドレスの数値は実行ごとに変わるので表示せず，p == &xのような比較の結果を表示します．

    未初期化ポインタ，NULLの間接参照，配列の範囲外アクセス，文字列リテラルへの書き込みは，ソースに書きません．型を合わせるためだけのキャスト（二次元配列をint **へ変換するなど）も書きません．

    課題1　最大要素の場所を返す¶

    FindMaxプロジェクトにfind_max.cを作ります．この課題では，次の3つの小問を順に行い，同じファイルへ書き足します．

    1. 課題1-1：二重ポインタを通して，整数とポインタを書き換える．
    2. 課題1-2：講義のfind_maxで，最大要素の場所を出力引数に受け取る．
    3. 課題1-3：最大値を値で返す関数と，場所で返す関数を比べる．

    課題1-1　二重ポインタの代入を追う¶

    二重ポインタを通して整数とポインタ変数を書き換えるプログラムを作成し，各代入の後で変わった変数と，pが指している変数を確認してください．

    プログラムが満たすこと（仕様）は次のとおりです．

    • 講義のvoid redirect(int **destination, int *target)をmainの前に定義する．
    • 関数void trace(void)を作る．traceでは，int x = 10;，int y = 30;，int *p = &x;，int **pp = &p;と宣言する．
    • traceでは，次の5つの代入・呼び出しを順に行い，それぞれの直後にprintf("x=%d y=%d p_is_x=%d p_is_y=%d\n", x, y, p == &x, p == &y);を実行する．
      1. **pp = 20;
      2. *pp = &y;
      3. **pp = 40;
      4. redirect(&p, &x);
      5. *p = 50;
    • mainではtrace();を呼ぶ．

    表示は次のようになります．

    x=20 y=30 p_is_x=1 p_is_y=0
x=20 y=30 p_is_x=0 p_is_y=1
x=20 y=40 p_is_x=0 p_is_y=1
x=20 y=40 p_is_x=1 p_is_y=0
x=50 y=40 p_is_x=1 p_is_y=0

    **ppへの代入は2段先の整数を変え，*ppへの代入は1段先のポインタ変数pを変えます．2行目でxとyがどちらも変わらないのは，整数ではなくpに保存されたアドレスを変えたからです．pp自身は最初から最後までpを指しています．

    redirectのdestinationは値渡しで作られたコピーですが，&pのコピーなので同じpを指します．そのため*destination = target;で呼び出し元のpが変わります．

    課題1-2　見つからない場合と同点の場合¶

    講義のfind_maxで最大要素の場所を受け取るプログラムを作成し，検索範囲が異なる場合，検索に失敗する場合，最大値が2つある場合の結果を確認してください．

    プログラムが満たすこと（仕様）は次のとおりです．

    • 講義のint find_max(int a[], int n, int **out)をmainの前に定義する．
    • 関数void try_find(int x0, int x1, int x2, int n)を作る．try_findは次の処理を行う．
      • int a[] = {x0, x1, x2};と，int *answer = &a[1];を宣言する．answerに前の結果が残っている状態を表すため，わざとNULL以外で初期化している．
      • int ok = find_max(a, n, &answer);を実行し，printf("n=%d ok=%d null=%d\n", n, ok, answer == NULL);で表示する．
      • okが1のときだけ，printf("max=%d index=%td\n", *answer, answer - a);で表示し，*answer = 99;を実行する．
      • 最後にprintf("a=%d %d %d\n", a[0], a[1], a[2]);で配列を表示する．
    • nは3以下とする．
    • mainでは，課題1-1のtrace();に続けて，次の表の順にtry_findを呼ぶ．
    x0，x1，x2 n
    7，12，4 3
    7，12，4 1
    7，12，4 0
    7，12，4 −1
    12，12，4 3

    課題1-1の5行に続けて，次の13行が表示されます．

    n=3 ok=1 null=0
max=12 index=1
a=7 99 4
n=1 ok=1 null=0
max=7 index=0
a=99 12 4
n=0 ok=0 null=1
a=7 12 4
n=-1 ok=0 null=1
a=7 12 4
n=3 ok=1 null=0
max=12 index=0
a=99 12 4
    ヒント

    *answerを読むのは，戻り値が1のときだけです．answer - aはポインタの差なので%tdで表示します．

    n=1では先頭の要素だけが検索に使われるので，a[1]の12は候補になりません．nが0以下なら要素を読まずに失敗します．find_maxは最初に*out = NULL;を実行するので，失敗したときにanswerへ前のアドレスが残りません．失敗した関数が出力先をどう扱うかは関数ごとの仕様で，この関数ではNULLにすると決めています．

    最大値が2つあるときは，a[i] > *bestという比較なので最初の要素（添字0）が選ばれます．>=にすると最後の要素が選ばれます．

    find_maxは，nが実際の要素数以下かどうかを判定できません．負のnを失敗として扱えることと，大きすぎるnが安全であることは別です．nに4以上を渡す呼び出しは書きません．また，outには有効なポインタ変数のアドレスを渡します．出力結果としてNULLを受け取ることと，out自体へNULLを渡すことは違います．

    課題1-3　値を返す版と場所を返す版¶

    最大値を値で返す関数と場所で返す関数を使うプログラムを作成し，返された場所を通して配列を書き換えたときに，保存した値と配列がどう変わるかを確認してください．

    プログラムが満たすこと（仕様）は次のとおりです．

    • 講義のint max_value(const int a[], int n)とint *max_pointer(int a[], int n)をmainの前に定義する．max_valueはnが1以上のときだけ使い，max_pointerはnが0以下ならNULLを返す．
    • 関数void try_return(int x0, int x1, int x2)を作る．try_returnは次の処理を行う．
      • int a[] = {x0, x1, x2};を宣言し，int saved = max_value(a, 3);とint *found = max_pointer(a, 3);を実行する．
      • foundがNULLでなければ，printf("before=%d %d\n", saved, *found);，*found = 99;，printf("after=%d %d\n", saved, *found);を順に実行する．
      • 最後にprintf("a=%d %d %d\n", a[0], a[1], a[2]);で配列を表示する．
    • mainでは，課題1-2の呼び出しに続けてtry_return(7, 12, 4);とtry_return(-7, -12, -4);を呼ぶ．
    • 続けてmainでint a[] = {7, 12, 4};を宣言し，printf("empty=%d\n", max_pointer(a, 0) == NULL);を実行する．

    課題1-2の表示に続けて，次の7行が表示されます．

    before=12 12
after=12 99
a=7 99 4
before=-4 -4
after=-4 99
a=-7 -12 99
empty=1

    savedは最大値を求めた時点の整数のコピーなので，*found = 99;の後も12のままです．一方，foundは元の配列の要素を指しているので，*foundへの代入はaへ反映されます．max_pointerが返すのは関数内の変数best自身のアドレスではなく，bestに保存されていた，呼び出し元の配列の要素のアドレスです．

    全部が負の配列でも正しく求まるのは，最大候補を0ではなく先頭の要素から始めているからです．空の入力に対して，max_valueには意味のある戻り値がないのでn=0を渡しません．max_pointerはNULLで失敗を表せます．

    課題1全体の表示は次のようになります．

    x=20 y=30 p_is_x=1 p_is_y=0
x=20 y=30 p_is_x=0 p_is_y=1
x=20 y=40 p_is_x=0 p_is_y=1
x=20 y=40 p_is_x=1 p_is_y=0
x=50 y=40 p_is_x=1 p_is_y=0
n=3 ok=1 null=0
max=12 index=1
a=7 99 4
n=1 ok=1 null=0
max=7 index=0
a=99 12 4
n=0 ok=0 null=1
a=7 12 4
n=-1 ok=0 null=1
a=7 12 4
n=3 ok=1 null=0
max=12 index=0
a=99 12 4
before=12 12
after=12 99
a=7 99 4
before=-4 -4
after=-4 99
a=-7 -12 99
empty=1

    課題2　表示順を変更する¶

    Namesプロジェクトにnames.cを作ります．この課題では，次の2つの小問を順に行い，同じファイルへ書き足します．

    1. 課題2-1：ポインタ配列の要素を交換して，文字列の表示順を変える．
    2. 課題2-2：変更可能な文字配列をポインタ配列から書き換える．

    課題2-1　ポインタを交換する¶

    ポインタ配列の2つの要素を交換して文字列の表示順を変えるプログラムを作成し，3通りの交換と，表示に文字を付け足しても文字列本体が変わらないことを確認してください．

    プログラムが満たすこと（仕様）は次のとおりです．

    • 講義のvoid swap_names(const char *names[], int i, int j)とvoid print_each(const char *prefectures[], int n)をmainの前に定義する．iとjは有効な添字とする．
    • 関数void try_swap(int i, int j, int times)を作る．try_swapは次の処理を行う．
      • const char *names[] = {"Tokyo", "Osaka", "Nagoya"};を宣言する．
      • swap_names(names, i, j);をtimes回くり返す．
      • printf("swap(%d, %d) x%d:", i, j, times);の後，3つの文字列をそれぞれprintf(" %s", names[k]);で表示し，最後に改行する．
    • mainでは，try_swap(0, 2, 1);，try_swap(1, 1, 1);，try_swap(0, 2, 2);の順に呼ぶ．
    • 続けてmainでconst char *names[] = {"Tokyo", "Osaka", "Nagoya"};を宣言し，print_each(names, 3);を呼んでから，printf("%s length=%zu\n", names[2], strlen(names[2]));を実行する．

    表示は次のようになります．

    swap(0, 2) x1: Nagoya Osaka Tokyo
swap(1, 1) x1: Tokyo Osaka Nagoya
swap(0, 2) x2: Tokyo Osaka Nagoya
Tokyo-ken
Osaka-ken
Nagoya-ken
Nagoya length=6

    try_swapは呼ばれるたびにnamesを初期値から作るので，3つの場合はそれぞれ初期状態から試したことになります．同じ添字の交換では何も変わらず，同じ交換を2回行うと元の順に戻ります．

    各文字列の長さが違っても交換できるのは，文字を移動せず，大きさが一定のポインタ値を交換しているからです．print_eachは表示のときに-kenを付けるだけで，文字列の末尾へ書き足していません．そのためstrlen(names[2])は6のままです．

    課題2-2　指す先の文字を書き換える¶

    ポインタ配列を通して，変更可能な文字配列の先頭の文字を大文字に書き換えるプログラムを作成し，元の配列の内容が変わることを確認してください．

    プログラムが満たすこと（仕様）は次のとおりです．

    • 関数void capitalize(char *words[], int n)を作る．words[0]〜words[n - 1]が指す文字列の先頭の文字を，toupperで大文字に書き換える．toupperの戻り値はintなので，charへキャストして代入する．
    • mainでは，課題2-1の表示に続けて，char city0[] = "tokyo";，char city1[] = "osaka";，char *editable[] = {city0, city1};を宣言し，capitalize(editable, 2);を呼ぶ．
    • 続けて，printf("%s %s\n", city0, city1);とprintf("same=%d\n", editable[0] == city0);を実行する．

    課題2-1の7行に続けて，次の2行が表示されます．

    Tokyo Osaka
same=1
    ヒント

    toupperを使うにはctype.hをインクルードします．引数は(unsigned char)words[i][0]のように変換して渡します．

    capitalizeはeditableのポインタ値を変えていません．各ポインタが指しているcity0やcity1の文字を変えています．そのため，city0とcity1を直接表示しても先頭が大文字になっています．

    namesの要素は文字列リテラルを指すconst char *なので，names[0][0]のように文字を書き換えることはできません．constを外したりキャストしたりして書き換えることもしません．文字を変えたいときは，この課題のように変更可能な配列を用意します．なお，char *の配列editableを，そのままconst char **の引数（swap_namesなど）へ渡すことはできません．関数と配列の要素型をそろえます．

    課題2全体の表示は次のようになります．

    swap(0, 2) x1: Nagoya Osaka Tokyo
swap(1, 1) x1: Tokyo Osaka Nagoya
swap(0, 2) x2: Tokyo Osaka Nagoya
Tokyo-ken
Osaka-ken
Nagoya-ken
Nagoya length=6
Tokyo Osaka
same=1

    課題3　行ごとの平均¶

    MatrixMeanプロジェクトにmatrix_mean.cを作ります．この課題では，次の2つの小問を順に行い，同じファイルへ書き足します．

    1. 課題3-1：2行3列の配列の行ごとの平均を表示する．
    2. 課題3-2：配列へのポインタで受け取り，全体の平均を求める．

    列数はenum { COLS = 3 };で定めます．要素の値は0〜100とします．

    課題3-1　行ごとの平均を表示する¶

    二次元配列の行ごとの平均を表示するプログラムを作成し，3通りの配列と，行数を変えた場合の結果を確認してください．

    プログラムが満たすこと（仕様）は次のとおりです．

    • 関数void print_means(int a[][COLS], int rows)を作る．先頭からrows行について，各行の合計をintで求め，(double)total / COLSをprintf(" %.1f", ...)で表示する．改行はしない．
    • 関数void show(int a[][COLS], int rows)を作る．showはprintf("rows=%d:", rows);で表示し，print_means(a, rows);を呼んでから改行する．
    • rowsは0〜2とする．

    • mainでは，次の3つの配列を宣言する．

      int a[2][COLS] = {{1, 2, 3}, {4, 5, 6}};
int b[2][COLS] = {{0, 0, 0}, {100, 100, 100}};
int c[2][COLS] = {{1, 1, 2}, {2, 2, 3}};

    • mainでは，show(a, 2);，show(a, 1);，show(a, 0);，show(b, 2);，show(c, 2);の順に呼ぶ．

    表示は次のようになります．

    rows=2: 2.0 5.0
rows=1: 2.0
rows=0:
rows=2: 0.0 100.0
rows=2: 1.3 2.3

    rows=0では行を1つも処理しないので，平均は表示されません．rowsに3を渡すと存在しない3行目へ進むので，そのような呼び出しは書きません．

    (double)totalの変換をせずにtotal / COLSとすると整数除算になり，小数部分が失われます．表示桁数を増やしても，除算で失った情報は戻りません．

    課題3-2　配列へのポインタで受け取る¶

    配列へのポインタで二次元配列を受け取り，行ごとの平均と全体の平均を求めるプログラムを作成し，課題3-1と同じ平均が求まることと，全体の平均が求められない場合の戻り値を確認してください．

    プログラムが満たすこと（仕様）は次のとおりです．

    • 関数void print_means_pointer(int (*a)[COLS], int rows)を作る．処理と表示はprint_meansと同じで，仮引数の書き方だけが違う．
    • 関数int overall_mean(int (*a)[COLS], int rows, double *mean)を作る．rowsが0以下なら*meanを変更せずに0を返す．そうでなければ，全要素の合計を要素数(double)rows * COLSで割った値を*meanへ書き込み，1を返す．
    • 関数void show_overall(int (*a)[COLS], int rows)を作る．show_overallはdouble mean = 0.0;を宣言してint ok = overall_mean(a, rows, &mean);を実行し，printf("rows=%d: ok=%d overall=%.2f\n", rows, ok, mean);で表示する．
    • mainでは，課題3-1の表示に続けて，printf("pointer:");，print_means_pointer(a, 2);，改行の表示を順に行う．
    • 続けて，show_overall(a, 2);，show_overall(a, 1);，show_overall(a, 0);，show_overall(c, 2);の順に呼ぶ．

    課題3-1の5行に続けて，次の5行が表示されます．

    pointer: 2.0 5.0
rows=2: ok=1 overall=3.50
rows=1: ok=1 overall=2.00
rows=0: ok=0 overall=0.00
rows=2: ok=1 overall=1.83

    仮引数のint a[][COLS]はint (*a)[COLS]と同じ型なので，結果は変わりません．括弧を落としてint *a[COLS]と書くと，仮引数はint **になり，別の型です．列数は，次の行までの大きさを決めるために必要です．行数は型に残らないのでrowsとして別に渡します．

    rows=0では要素の個数が0なので，割り算をせずに失敗を返します．ok=0の行のoverall=0.00は，show_overallが初期化した値がそのまま表示されたもので，平均ではありません．行平均を表示する関数がrows=0で何も表示しないことと，平均値を返す関数が空の入力を失敗として扱うことは，別の仕様です．

    aの全体の平均3.5は，行平均2.0と5.0の平均と一致します．これはどの行も要素数が同じだからです．行の長さが異なる場合は，発展1で確かめます．

    課題3全体の表示は次のようになります．

    rows=2: 2.0 5.0
rows=1: 2.0
rows=0:
rows=2: 0.0 100.0
rows=2: 1.3 2.3
pointer: 2.0 5.0
rows=2: ok=1 overall=3.50
rows=1: ok=1 overall=2.00
rows=0: ok=0 overall=0.00
rows=2: ok=1 overall=1.83

    課題4　二次元配列の行を交換する¶

    3行9列の文字配列の2つの行を，終端を含む9個のcharずつ交換するプログラムを作成し，交換の前後で各行の9要素がどう変わるかを確認してください．

    SwapRowsプロジェクトにswap_rows.cを作ります．プログラムが満たすこと（仕様）は次のとおりです．

    • 列数をenum { WIDTH = 9 };で定める．
    • 関数void swap_rows(char names[][WIDTH], int i, int j)を作る．i行とj行のWIDTH個の要素を，1個ずつ一時変数を使って交換する．iとjは有効な添字とする．
    • 関数void show(const char *label, char names[][WIDTH], int n)を作る．showはprintf("%s:", label);で表示した後，n行それぞれについて空白を1つ表示し，その行のWIDTH個の要素を順に表示する．値が0の要素は.，それ以外は%cで表示する．最後に改行する．
    • mainではchar names[][WIDTH] = {"toyama", "ishikawa", "fukui"};を宣言し，次の順に処理する．
      1. show("start", names, 3);
      2. swap_rows(names, 1, 2);の後にshow("swap 1 2", names, 3);を呼び，さらにprintf("%s %s %s\n", names[0], names[1], names[2]);を実行する．
      3. swap_rows(names, 1, 2);の後にshow("swap 1 2", names, 3);
      4. swap_rows(names, 1, 1);の後にshow("swap 1 1", names, 3);
    • 続けてmainでchar empty[][WIDTH] = {"toyama", "ishikawa", ""};を宣言し，swap_rows(empty, 1, 2);の後にshow("empty", empty, 3);を呼ぶ．

    表示は次のようになります．

    start: toyama... ishikawa. fukui....
swap 1 2: toyama... fukui.... ishikawa.
toyama fukui ishikawa
swap 1 2: toyama... ishikawa. fukui....
swap 1 1: toyama... ishikawa. fukui....
empty: toyama... ......... ishikawa.
    ヒント

    行は配列なので，names[i] = names[j];とは書けません．列cを0〜WIDTH−1まで進め，各文字を一時変数で交換します．終端や初期化で0になった残りの要素も含めて交換します．

    WIDTHは，最長のishikawaの8文字と終端の1個を合わせた9です．短い行も9個分が確保され，初期化で余った要素は0になります．.の位置が，その0の要素です．

    交換の後も，各行の開始位置は変わっていません．その位置に保存されている内容が変わっています．課題2では文字列本体を動かさず，配列中のポインタを変えました．ポインタの交換は文字列の長さに関係なく一定回数の代入で済みますが，行の交換はWIDTH回の反復が必要です．一方，二次元配列は本体を連続した固定幅の領域として確保できます．

    短いfukuiの5文字だけをishikawaの先頭へ上書きすると，終端を書かない限りfukuiawaのように余分な文字が残ります．固定幅全体を交換すれば，長さが違う場合や空文字列の場合も正しく入れ替わります．

    発展1　長さが異なる行を扱う¶

    長さが異なる2つの行をポインタ配列と長さの配列で管理し，行と長さを組にして交換するプログラムを作成し，交換の前後の各行の合計と平均，全要素の平均，交換後に書き換わる元の配列を確認してください．

    RaggedRowsプロジェクトにragged_rows.cを作ります．プログラムが満たすこと（仕様）は次のとおりです．

    • 関数int row_sum(const int *row, int length)を作る．rowからlength個の要素の合計を返す．
    • 関数void print_rows(int **rows, const int lengths[], int n)を作る．各行rについて，合計sumをrow_sumで求め，printf("row%d sum=%d mean=%.2f\n", r, sum, (double)sum / lengths[r]);で表示する．
    • 関数double total_mean(int **rows, const int lengths[], int n)を作る．全行の合計を，全行の要素数の合計で割った値を返す．
    • 関数void swap_ragged(int *rows[], int lengths[], int i, int j)を作る．rows[i]とrows[j]を交換し，lengths[i]とlengths[j]も交換する．

    • mainでは，講義と同じ次の宣言をする．

      int row0[] = {1, 2, 3};
int row1[] = {4, 5};
int *rows[] = {row0, row1};
int lengths[] = {3, 2};
int **p = rows;

    • mainでは，次の順に処理する．

      1. print_rows(p, lengths, 2);
      2. printf("total mean=%.2f\n", total_mean(p, lengths, 2));
      3. swap_ragged(rows, lengths, 0, 1);の後にprint_rows(p, lengths, 2);
      4. p[1][0] = 10;の後にprintf("row0[0]=%d row1[0]=%d\n", row0[0], row1[0]);

    表示は次のようになります．

    row0 sum=6 mean=2.00
row1 sum=9 mean=4.50
total mean=3.00
row0 sum=9 mean=4.50
row1 sum=6 mean=2.00
row0[0]=10 row1[0]=4

    全要素の平均は15 / 5 = 3.0です．行平均2.0と4.5を単純に平均した3.25とは一致しません．要素数が異なる場合は，各行の合計と個数を集計してから割ります．

    ポインタ配列rowsはint **で指せます．p[1]の場所には実際にint *が保存されているからです．ポインタ配列を用意してもrow0やrow1の内容はコピーされません．交換後のp[1]はrow0を指しているので，p[1][0] = 10;で変わるのは変数row0の先頭です．表示のrow0，row1は「現在の0行目，1行目」であり，変数名のrow0，row1とは別です．

    ポインタだけを交換して長さを交換しないと，2要素の行を長さ3として読み，範囲外にアクセスします．行のポインタと有効な要素数は，必ず組で扱います．

    発展2　配列とポインタの型を確かめる¶

    二次元配列，ポインタ配列，配列へのポインタ，一次元配列について，要素の個数と，ポインタを1つ進めたときの単位を表示するプログラムを作成し，それぞれの型が何を数えるかを確認してください．

    ArrayTypesプロジェクトにarray_types.cを作ります．プログラムが満たすこと（仕様）は次のとおりです．

    • 列数をenum { COLS = 3 };で定める．
    • 関数int flat_at(const int flat[], int r, int c)を作る．幅COLSの行列として，行r・列cの要素flat[r * COLS + c]を返す．

    • mainでは，次の宣言をする．

      int a[2][COLS] = {{1, 2, 3}, {4, 5, 6}};
int *rows[2] = {a[0], a[1]};
int (*q)[COLS] = a;
int flat[] = {1, 2, 3, 4, 5, 6};

    • mainでは，次の7つのprintfを順に実行する．

      printf("ints_a=%zu ints_row=%zu pointers_rows=%zu\n",
       sizeof a / sizeof(int), sizeof a[0] / sizeof(int), sizeof rows / sizeof(int *));
printf("row_count=%zu col_count=%zu\n", sizeof a / sizeof a[0], sizeof a[0] / sizeof a[0][0]);
printf("step_row=%td step_int=%td\n", (a + 1) - a, (a[0] + 1) - a[0]);
printf("q=%d same_row=%d\n", q[1][2], q + 1 == &a[1]);
printf("rows=%d same_row=%d\n", rows[1][2], rows[1] == a[1]);
printf("same_place=%d\n", (void *)&a == (void *)&a[0][0]);
printf("flat=%d a=%d\n", flat_at(flat, 1, 2), a[1][2]);

    表示は次のようになります．

    ints_a=6 ints_row=3 pointers_rows=2
row_count=2 col_count=3
step_row=1 step_int=1
q=6 same_row=1
rows=6 same_row=1
same_place=1
flat=6 a=6

    sizeof aは6 * sizeof(int)，sizeof a[0]は3 * sizeof(int)，sizeof rowsは2 * sizeof(int *)です．バイト数そのものは環境によって異なるので，ここではsizeof(int)やsizeof(int *)で割って個数として表示しています．rowsにはポインタしか含まれず，指す先のintの大きさはsizeof rowsに入りません．sizeof a / sizeof a[0]で行数を求められるのは，mainで宣言した配列そのものに対してだけです．関数の仮引数はポインタなので，この式では行数を求められません．

    a + 0の型はint (*)[3]で，1つ進むと次の行（int3個分）へ進みます．a[0] + 0の型はint *で，1つ進むと次のintへ進みます．どちらも差は1です．ポインタの差は，バイト数ではなく，指す型の要素数で表されます．

    &a（型はint (*)[2][3]），&a[0]（int (*)[3]），&a[0][0]（int *）は，どれも格納領域の先頭に対応します．same_place=1はそれをvoid *に変換して比べた結果です．しかし型は違うので，関数の引数として自由に取り替えられるわけではありません．特に，aも&aもint **ではありません．なお，int (*q)[3]に対する&qの型はint (**)[3]で，qというポインタ変数自身を指します．

    int *p = &a[0][0];としてp[0]〜p[5]を走査する書き方は使いません．最初の行の範囲を越えるためです．二次元配列はa[r][c]で走査します．一次元として扱いたいなら，flatのように最初から一次元配列を用意し，r * COLS + cで添字を計算します．
