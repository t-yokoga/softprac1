    第3回　演習¶

    解答・解説は授業で別途提示します．このページには問題とヒントを掲載しています．

    第3回の講義を読み，operators.cをビルド・実行できることを確認してから取り組んでください． 今回は，計算結果を予測してから実行し，値の更新や条件式の意味を説明します． 答えの数値が合うだけでなく，どの型で，どの演算を行った結果かを確認しましょう．

    演習の進め方¶

    課題1〜4を順に進め，最後に確認問題に答えてください．課題5はビット演算を使う発展課題です． 入力はソースコードに直接書きます．if文・繰り返し・キーボードからの入力は使いません． 条件式の結果は，%dで0または1として表示します．

    作業場所と記録

    講義で用意した PL1\week03 を作業場所とし，ソースと実行結果を保存してください． memo.txtなどに「変更した値・予測・実行結果・理由」を記録します．提出先や締切は，授業時に案内します．

    課題 内容 プロジェクト名 ソースファイル
    1 秒を分と秒へ分解する TimeParts time_parts.c
    2 前置・後置と複合代入 Update update.c
    3 範囲の判定と短絡評価 Conditions conditions.c
    4 うるう年の条件式 Leap leap.c
    5 発展：権限フラグ Flags flags.c

    各プログラムに共通の手順¶

    第1回の手順と同じく，課題ごとに別の空のC++／Windowsプロジェクトを作ります．

    1. 保存場所をweek03にし，ソリューションとプロジェクトを同じディレクトリに配置する．
    2. 表の名前の.cファイルを追加する．
    3. Cコードとしてコンパイル（/TC），C17，警告レベル4を設定する．
    4. 編集後にCtrl+Sで保存し，Ctrl+Shift+Bでビルドする．
    5. 警告・エラーを確認し，成功したらCtrl+F5で実行する．

    mainの重複と，危険な実験を避ける

    独立したmainを持つファイルを同じプロジェクトへまとめて追加しないでください． また，0による整数除算・範囲外のシフト・同じ変数を順序不明のまま複数回更新する式は，実行して結果を試す対象ではありません．

    課題1　秒を分と秒へ分解する¶

    整数の商と余りを使う

    TimePartsプロジェクトにtime_parts.cを作り，int型のsecondsを3671で初期化します． 整数の除算と剰余を使い，分をminutes，残りの秒をrestへ保存してください． さらに，secondsを60.0で割った値をdoubleのdecimal_minutesへ保存して表示します．

    61 min 11 sec
decimal minutes=61.18

    入力は0〜10000秒の整数とし，小数の分は小数点以下2桁で表示します．

    ヒント

    minutesはseconds / 60，restはseconds % 60です． doubleへ保存する場合も，右辺が整数同士の除算なら小数部分は失われます．小数の分には60.0を使ってください．

    境界の値を試す¶

    secondsの初期値を0，59，60，61へ変更してください． 特に60秒の前後で，分と秒の値がどう変わるか予測します．

    説明すること：seconds = 61のとき，decimal_minutesの右辺をseconds / 60へ変更すると，なぜ1.00になるのでしょうか． 除算とdoubleへの保存の順序を説明し，確認後は60.0へ戻してください．

    課題2　前置・後置と複合代入¶

    値が変わる順番を追う

    Updateプロジェクトにupdate.cを作り，次の処理を順に行います．

    1. intのxを5で初期化する．
    2. x++の式の値を，intのbeforeへ保存する．
    3. ++xの式の値を，intのafterへ保存する．
    4. before，after，xを表示する．
    5. xへ3を加算して保存し，さらに2倍して保存する．
    6. 最終的なxを表示する．

    実行前に，各段階のx，before，afterの値を表に書いてください．

    ヒント

    x++は増加前の値を式の値にし，++xは増加後の値を式の値にします． どちらも次の文へ進む前にはxを1増やしています．後半では+=と*=を使います．

    書き方を変えて比較する¶

    後半のx += 3;とx *= 2;を，それぞれ通常の代入の形へ書き換え，同じ結果になることを確認してください． 次に，最初のxを0と-2へ変更して試します．

    説明すること：x *= 2;とx += 3;の順番を逆にすると，最終値は同じでしょうか． 初期値5の場合，前置・後置の処理後のxは7です．そこから2倍して3を足すと17になり，元の20とは異なります．

    短くまとめない

    beforeへの代入，afterへの代入，printfは別々の文のままにします． printfの複数の引数にx++や++xをまとめて渡すと，順序が保証されず，未定義動作の原因になります．

    課題3　範囲の判定と短絡評価¶

    条件の結果を0か1で表示する

    Conditionsプロジェクトにconditions.cを作ります．scoreはintで，最初の値は75です． 次の2つの条件を別々の変数へ保存します．

    • valid：scoreが0以上100以下なら1，それ以外なら0．
    • invalid：scoreが0未満または100より大きければ1，それ以外なら0．

    さらにintのnを12，dを0とし，「dが0でなく，整数除算n / dが2より大きい」という条件をlargeへ保存します． dが0のときには，除算を行わない書き方にしてください．

    ヒント

    範囲内は2つの比較を&&で，範囲外は2つの比較を||でつなぎます． 除算を含む条件は，d != 0を&&の左側へ置きます．

    条件の境界を試す¶

    scoreを-1，0，100，101に変えてください．次にscoreを75へ戻し，dを3，6に変えます． 変更は1項目ずつ行い，どの表示に影響するかも確認します．

    説明すること：0 <= score <= 100 が正しい範囲判定にならない理由を，最初の比較の結果を使って説明してください． また，dが0のまま&&を&に置き換えると，短絡評価がなくなるため危険です．この変更は実行しません．

    課題4　うるう年の条件式¶

    日本語の条件を式へ分解する

    Leapプロジェクトにleap.cを作り，グレゴリオ暦のうるう年の規則を条件式で表してください． この課題では年を正の整数として与え，次の規則だけを扱います．

    • 4で割り切れ，かつ100では割り切れない年は，うるう年である．
    • それとは別に，400で割り切れる年も，うるう年である．

    yearを2000で初期化し，うるう年なら1，そうでなければ0をleapに保存して表示します． まず「4で割り切れる」などの3つの条件を，個別に書き出してください．

    ヒント

    割り切れるとは，%で求めた余りが0であることです． 2つ目の規則は，1つ目の規則と「または」で結びます．最後は1つの条件式にできます．

    例外を含む年で確認する¶

    1900，2000，2024，2025で実行します．単に4で割り切れるかどうかだけを調べる式と，結果が違う年はどれでしょうか．

    説明すること：式のどの部分が「かつ」，どの部分が「または」に対応するか説明してください． この式は分岐ではなく，条件の真偽を求めて変数へ保存していることも確認します．

    課題5　発展：権限フラグ¶

    対象のビットだけ変更する

    Flagsプロジェクトにflags.cを作ります．unsigned intのflagsの下位3ビットを，次の意味で使います．

    ビット位置 意味 マスク
    0 読む権限 1u << 0
    1 書く権限 1u << 1
    2 実行する権限 1u << 2

    初期値は1u（読む権限だけ）です．書く権限を追加し，読む権限を外し，実行する権限を反転します． 各段階のflagsを十進数で表示し，最後に実行する権限の有無を0か1で表示してください．

    ヒント

    セットはOR，クリアは反転したマスクとのAND，反転はXORです． 権限を調べる式では(flags & mask)全体を括弧で囲み，0と比較します．

    ビット列で確かめる¶

    下位3ビットを書き出すと，001 → 011 → 010 → 110です． 最初のflagsを0uと7uに変え，同じ処理を順に実行してください．

    説明すること：同じ権限を2回セットしても，ORならほかのビットへ影響しません． 加算を代わりに使うとどうなるか，1u + 1uと1u | 1uを比較して説明してください．

    確認問題¶

    次の問いに，実行結果や値の追跡表をもとに答えてください．

    1. 式と式文の違いは何か．複合文には何を使うか．
    2. 7 / 2と7 / 2.0の結果は，なぜ異なるか．
    3. double x = 7 / 2;で，失われた小数部分は代入時に戻るか．
    4. x++と++xは，式の値として何を使うか．
    5. =と==は，それぞれ何を行うか．
    6. &&の左側が偽のとき，右側は評価されるか．
    7. 4u & 2uと4u && 2uの結果は同じか．
    8. flagsの対象ビットを0にするとき，なぜ反転したマスクを使うか．

    チェックリスト¶

    • 課題1〜4のソースと実行結果を保存した．
    • 整数除算と小数の除算を，計算時の型から説明できる．
    • 前置・後置の式の値と，変数の更新後の値を区別できる．
    • 範囲の境界と，うるう年の例外にあたる値を試した．
    • 短絡評価が0による除算を防ぐ理由を説明できる．
    • ビット演算ではunsigned intを使い，0と1の列で結果を確認できる．

    次回は制御構造を学びます．今回の条件式を使って，実行する処理を選んだり，同じ処理を繰り返したりします．
