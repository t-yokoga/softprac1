    第4回　制御構造¶

    到達目標¶

    • 条件に応じて実行する文を選べる．
    • for・while・do-whileの実行順を説明できる．
    • 境界値と停止条件を用いて処理を検証できる．

    1　順次・分岐・反復¶

    文を上から実行する順次，条件で経路を選ぶ分岐，同じ処理を繰り返す反復を組み合わせてアルゴリズムを記述します．入力を固定した短いプログラムで流れを確かめ，入力操作は第7回で学びます．

    前回とのつながり¶

    第3回ではscore >= 60という式から0または1を求めました．今回はその結果を使い，実際に実行する処理を切り替えます．また，sum += iのような更新を繰り返し，1回の計算では求められない合計や表を作ります．条件式を書くことと，条件に従って処理を進めることを結び付ける回です．

    構造 考え方 例
    順次 上から順番に進む 値を設定し，計算し，表示する
    分岐 条件で進む経路を選ぶ 点数で合格・再挑戦を表示する
    反復 条件が成立する間，同じ処理を行う 1から10まで加算する

    作業の準備¶

    作業場所はPL1の下のweek04です．第1回の手順で空のプロジェクトを作り，拡張子.cのソースを追加します．Cとしてコンパイル，C17，警告レベル4を確認してください．この回もVisual Studio内で編集・ビルド・実行し，端末へのコマンド入力は行いません．

    短いコード片はmainの中に置き，printfを使うファイルにはstdio.hをインクルードします．1つのプロジェクトに複数のmainを入れないでください．まず出力を予測し，保存→Ctrl+Shift+Bでビルド→Ctrl+F5で実行の順に確認します．

    ブロックで処理をまとめる¶

    複数の文を{と}でまとめると，制御文の本体として1つのまとまりにできます．ブロック内で宣言した変数は，そのブロックの外では使えません．例えばifの中でだけ必要な一時変数は，その中に宣言できます．一方，分岐後にも使う結果は分岐前に宣言します．変数のスコープは第5回で詳しく扱います．

    2　ifとelse¶

    条件に応じて片方だけを実行する¶

    if (score >= 60) {
    printf("pass\n");
} else {
    printf("retry\n");
}

    条件が真なら最初のブロック，偽ならelseのブロックを実行します．elseは省略できます．複数の区分には else if を使い，上から最初に真になった1つを実行します．

    実行の流れは「条件判定→選ばれたブロック→分岐の後の文」です．elseがなければ，偽のときは本体を飛ばして先へ進みます．どちらの経路を通っても，その後の文には進みます．

    int n = 10;
if (n % 2 == 0) {
    printf("even\n");
} else {
    printf("odd\n");
}
printf("done\n");

    nが10ならevenとdone，11ならoddとdoneを表示します．%による余りの判定と，実行される経路を対応させましょう．

    真は1だけではない¶

    Cの条件では0が偽，0以外が真です．if (3)やif (-1)も真の経路へ進みます．比較演算の結果は0か1ですが，条件に置ける値が0と1に限定されるわけではありません．

    書き方 同じ意味の条件 読み方
    if (flag) if (flag != 0) フラグが立っている
    if (!flag) if (flag == 0) フラグが立っていない

    flagが2でもif (flag)は真ですが，if (flag == 1)は偽です．短く書くことより，どの値を真とするかを明確にしましょう．また，if (flag = 1)は比較ではなく代入で，flagを書き換えてしまいます．

    複数の条件を上から調べる¶

    例えば90点以上をA，60点以上をBにするときは，先に90点以上を調べます．先に60点以上を調べると，95点もそこで該当してしまいます．範囲外の値があり得るときは，0〜100かどうかも先に検査します．

    if (score < 0 || score > 100) {
    printf("invalid\n");
} else if (score >= 90) {
    printf("A\n");
} else if (score >= 60) {
    printf("B\n");
} else {
    printf("C\n");
}

    scoreが75なら範囲外ではなく，90以上でもなく，60以上なのでBです．最後のelseは，それまでの条件がすべて偽だった場合です．別々のifを並べると各条件を独立に調べるため，複数の本体が実行されることがあります．「どれか1つ」を選ぶelse ifと区別してください．

    ifを入れ子にする¶

    ブロック内にさらにifを書くこともできます．次は，flagが0ならresultを−1にし，そうでなければ2つの値の小さい方を選ぶ例です．

    int flag = 1;
int val1 = 10;
int val2 = 2;
int result;
if (flag == 0) {
    result = -1;
} else {
    if (val1 < val2) {
        result = val1;
    } else {
        result = val2;
    }
}
printf("result=%d\n", result);

    表示はresult=2です．resultはどの経路でも代入されてから使われます．flagが0の経路でも，プログラム自体が終了するのではなく，最後のprintfへ進みます．

    文法上，本体が1文なら波括弧を省略でき，同じ行に書くこともできます．ただし，その後に文を追加したときの間違いを防ぐため，この講義では常に波括弧を付けます．波括弧がない場合，elseは対応の決まっていない最も近いifに結び付きます．字下げだけでは対応を変えられません．開き波括弧を次の行に置くスタイルもありますが，ファイル内で統一してください．

    末尾のセミコロンに注意

    if (条件); のセミコロンは何もしない文です．その後のブロックは条件と無関係になります．本体が1文でも波括弧を付け，インデントを整えましょう．

    3　for：回数を管理する¶

    初期化・条件・更新の役割¶

    forはfor (初期化; 継続条件; 更新)という形です．3つの部分の区切りはコンマではなくセミコロンです．条件は「終了する条件」ではなく，続ける条件であることに注意しましょう．

    int sum = 0;
for (int i = 1; i <= 3; ++i) {
    sum += i;
}

    実行順は 初期化 → 条件判定 → 本体 → 更新 → 条件判定… です．条件が偽になると抜けます．

    本体を実行するときのi 実行前のsum 実行後のsum
    1 0 1
    2 1 3
    3 3 6

    更新後にiは4になり，条件が偽になります．i < 3 と i <= 3 では回数が1回違います．累積用のsumはループの前で初期化します．

    初期化は最初に1回だけ行います．更新は本体の後です．最初の条件が偽なら，本体も更新も実行しません．sumを本体内で毎回0に戻すと，それまでの合計が消えるため，累積になりません．

    N回の反復とカウンタの範囲¶

    for (int i = 0; i < 5; ++i) {
    printf("%d\n", i);
}

    これは0，1，2，3，4の5回です．0から始めてi < Nとする形を基本にすると，第5回の配列にもつながります．forの初期化部分で宣言したiは，そのforの外では使えません．この書き方はC99以降で使え，授業のC17でも利用できます．forの前でint i;と宣言する書き方もありますが，必要な範囲を狭くするのが基本です．

    初期化 継続条件 更新 本体で表示する式 表示される値
    int i = 0 i < 5 ++i i 0，1，2，3，4
    int i = 0 i <= 4 ++i i 0，1，2，3，4
    int i = 1 i < 6 ++i i - 1 0，1，2，3，4
    int i = 5 i > 0 --i 5 - i 0，1，2，3，4

    同じ表示でもカウンタの値は異なります．まずは基本形で書き，必要に応じて減らす反復などへ変更しましょう．更新部分で結果の値を使わず，intのiを1増やすだけなら，++iとi++はどちらも同じ反復になります．第3回の「式の値も使う場合」と区別します．

    4　whileとdo-while¶

    条件を先に調べるwhile¶

    int i = 0;
while (i < 5) {
    printf("%d\n", i);
    ++i;
}

    forの基本例と同じく0〜4を表示します．whileでは，初期化を手前に，更新を本体に自分で書きます．回数があらかじめ分かる処理にはfor，状態がある条件を満たす間の処理にはwhileが読みやすいことが多くあります．

    continueを含まない基本的なforは，「初期化; while (継続条件) { 本体; 更新; }」と読み替えられます．ただし，変数の有効範囲やcontinueの移動先まで自動的に同じになるわけではありません．書き換えた後も更新が行われるか確認します．

    条件を後で調べるdo-while¶

    while (条件) { 本体 } は先に条件を調べるため，0回で終わる場合があります．do { 本体 } while (条件); はあとで判定するため，必ず1回は実行します．do-whileの末尾のセミコロンは必要です．

    int n = 3;
do {
    printf("%d\n", n);
    --n;
} while (n > 0);

    nを0にすると，このdo-whileは0を1回表示します．同じ本体のwhileなら実行しません．ループでは「何が変化し，いつ条件が偽になるか」を説明できるようにします．

    開始時のn while (n > 0)の表示 do-whileの表示
    3 3，2，1 3，2，1
    1 1 1
    0 表示なし 0

    whileの条件の直後に余分なセミコロンを書くと，本体が空の反復になります．一方，do-whileの末尾にはセミコロンが必要です．位置と意味をセットで確認しましょう．

    無限ループと停止条件¶

    while (1)は条件が常に真，for (;;)は継続条件を省略した形で，どちらも途中で抜けなければ繰り返し続けます．入力待ちなどで意図的に使う場合もありますが，更新忘れによって意図せず無限ループになることもあります．

    int count = 0;
for (;;) {
    printf("%d\n", count);
    ++count;
    if (count == 3) {
        break;
    }
}

    この例は次節のbreakによって0，1，2を表示して終了します．for (;;)をwhile (1)に変えても同じです．無限に動くプログラムを試す必要はありません．止まらないときは，Visual Studioでデバッグ実行中なら「デバッグの停止」，デバッグなしの実行なら実行中のコンソールウィンドウを閉じて中断し，条件と更新を確認してください．

    待機のため一定時間処理を休止する機能もありますが，sleepのような関数はC17の標準ライブラリの機能ではなく，OSにより使い方が異なります．この回では待機用の関数を使わず，有限回の例で制御を学びます．

    5　break・continue・switch¶

    反復を終えるbreakと，残りを飛ばすcontinue¶

    break; は最も内側のループまたはswitchを抜けます．continue; は現在のループの残りを飛ばし，次の反復へ進みます．forでは更新式へ，whileでは条件判定へ進みます．whileで更新を飛ばすと無限ループになる場合があります．

    for (int n = 0; n < 5; ++n) {
    if (n == 3) {
        break;
    }
    printf("%d\n", n);
}

    breakなら0，1，2を表示し，3でforの外へ進みます．breakをcontinueに変えると0，1，2，4を表示します．3のときはprintfだけを飛ばし，++nを行って次の条件判定へ進むからです．do-whileのcontinueも末尾の条件判定へ進みます．

    continueは「次の反復を丸ごと飛ばす」のではなく，現在の反復の残りを飛ばす命令です．whileで更新がcontinueの後にあると，その更新が実行されず同じ値のまま条件へ戻ることがあります．

    整数の値で分けるswitch¶

    整数の値で場合分けするときはswitchも使えます．

    switch (menu) {
case 1:
    printf("start\n");
    break;
case 2:
    printf("help\n");
    break;
default:
    printf("unknown\n");
    break;
}

    caseは定数で指定します．breakがないと次のcase側の文も実行されます（フォールスルー）．範囲を比べる処理にはifが自然です．

    switchは式の値に一致するcaseへ移り，そこから文を順に実行します．caseを通過するたびに条件を再判定するわけではありません．defaultはどのcaseにも一致しない場合の移動先で，省略すると一致しない場合は何もせずswitchの後へ進みます．caseの値は重複できません．小数や文字列ではなく，整数型の値（charを含む）で場合分けします．

    複数の値に同じ処理を割り当てる場合は，caseを続けて書けます．

    switch (school_year) {
case 1:
case 2:
    printf("lower years\n");
    break;
case 3:
case 4:
    printf("upper years\n");
    break;
default:
    printf("invalid\n");
    break;
}

    この例は「school_year == 1 || school_year == 2ならlower years，そうでなく3か4ならupper years，それ以外ならinvalid」というif・else if・elseでも書けます．caseの共有は意図的ですが，処理の後のbreakの付け忘れとは区別してください．ループ内のswitchにあるbreakはswitchだけを抜け，外側のループは続きます．

    補足：ラベルへ移動するgoto¶

    gotoは同じ関数内のラベルへ移動する文です．次は読み方を知るための例です．

    for (int n = 0; n < 5; ++n) {
    if (n == 3) {
        goto done;
    }
    printf("%d\n", n);
}
done:
printf("done\n");

    表示は0，1，2，doneです．done:が移動先のラベルで，goto done;がジャンプです．この例ならbreakで同じ目的を達成できます．gotoは読み手が処理を追いにくくなるため，この回の課題では使用せず，順次・分岐・反復で書きます．Cには後処理をまとめる用途などもあるため，言語機能そのものが常に誤りというわけではありません．

    例題の3つの処理を分けて読む¶

    部分 開始時の状態 終了までの流れ
    合否の分岐 scoreは75 範囲外ではなく，60以上なのでpassだけを表示
    合計のfor sumは0，iは1から 1〜10を加算し，iが11になると条件が偽．sumは55
    累乗のwhile powerは1 表示後に2倍．64の次は128となり，100未満ではないので終了

    この3つは順次実行されます．ifの条件が偽になった場合でも，その後にあるforやwhileが丸ごと省略されるわけではありません．どの文がどの波括弧に囲まれているかを確認してください．

    最初はscoreだけを59へ変え，retryになることを確かめます．次に60でpass，−1と101でinvalidになることを確認します．その間，sumと累乗の表示は変わりません．別の部分へ影響しないことも大切な確認です．

    続いて，合計の条件i <= 10をi < 10へ変える前に，何が加算されなくなるか予想してください．10を加えないので合計は45です．条件式の1文字の違いが，最後に実行する本体を変えます．確認したら元の条件へ戻しましょう．

    7　二重ループとテスト¶

    ループの中にループを書くと，行と列の処理を表せます．外側が1回進むたびに，内側が最初から最後まで動きます．3行4列なら本体は12回です．

    for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 4; ++j) {
        printf("i: %d, j: %d\n", i, j);
    }
}

    表示される(i, j)は(0, 0)，(0, 1)，(0, 2)，(0, 3)，次に(1, 0)〜(1, 3)，最後に(2, 0)〜(2, 3)です．外側が進むたびに，内側の初期化でjが0へ戻ります．内側のループのbreakは内側だけを抜けます．continueも最も内側のループの次の反復へ進みます．

    表を表示するとき，値の表示は内側，行末の改行は内側のループが終わった後に置きます．改行を内側へ入れると1要素ずつ別の行になります．逆に両方のループの外へ置くと，全要素が1行に並びます．

    条件分岐は境界の直前・境界・直後を試します．繰り返しは0回・1回・複数回になる値を試します．Visual Studioで止まらなくなったら，デバッグ実行中は「デバッグの停止」で中断し，更新と条件を見直してください．

    症状 主な原因 確認する点
    どの値でも同じ側へ進む =と==の取り違え，if直後の; 条件式と警告
    端の値だけ結果が違う <と<=の取り違え 境界の前後と境界そのもの
    1回多く表示される 0始まりなのに<=を使用 最初と最後のカウンタ値
    合計が最後の値になる sumを本体内で0に戻している 累積変数の初期化位置
    終了しない 更新忘れ，continueで更新を飛ばした 条件へ戻るまでの全経路
    switchで余分な表示が出る breakの付け忘れ caseから実行される文の順序

    Visual Studioで処理を追う場合は，調べたい実行文の行にブレークポイントを置き，デバッグ実行で停止させます．ステップオーバーで1文ずつ進み，ローカル変数の値と次に進む経路を確認できます．出力だけが合うことと，処理の流れを説明できることの両方を目指しましょう．

    2. whileとdo-whileで実行回数が違うのはどんな場合か．
