    第5回　演習：配列と関数¶

    解答・解説は授業で別途提示します．このページには問題とヒントを掲載しています．

    講義を読んでから取り組んでください．出力と処理の流れを予測しましょう．

    準備と進め方¶

    作業場所は PL1\week05 です．第1回と同じ設定（Cとしてコンパイル，C17，警告レベル4）で，課題ごとに別の空のプロジェクトを作ります．特に指定がなければ，mainを持つソースは1プロジェクトに1つです．保存後にCtrl+Shift+Bでビルドし，Ctrl+F5で実行します．

    各課題で，ソース，試した値，予測，実行結果，結果の説明を残してください．提出先や締切は，授業時に案内します．

    今回の進め方¶

    課題 主な内容 注目する点
    1 配列から最大値を返す 添字，初期値，長さの引数
    2 二次元配列の列合計 行・列とループの順序
    3 値渡しとスコープ 呼び出し元と仮引数の違い
    4 平均と累乗の関数 複数引数，プロトタイプ，戻り値
    発展 合計と平均の役割分担 関数の契約と検証

    各課題では，実行前に「配列の要素数」「使える添字」「関数へ渡す値」「返される値」を書き出します．境界の確認でも配列の外を読み書きしてはいけません．要素数を変更したら，ループと関数へ渡す長さも一緒に見直します．

    保存→ビルド→実行の順を守り，古い実行ファイルの結果と混同しないようにしてください．mainを複製するのではなく，初期値を変えて再ビルドします．関数はmainの外側に定義します．mainより後へ置く場合は，呼び出し前のプロトタイプ宣言を忘れないでください．

    ウォームアップ：初期化を読む¶

    次の配列の全要素を紙上で書き出し，forで表示して確かめます．これはmain内に置くコード片です．表示にはstdio.hが必要です．

    int a[5] = {1, 1};
int b[5] = {0};
for (int i = 0; i < 5; ++i) {
    printf("%d %d\n", a[i], b[i]);
}

    課題1　最大の点数¶

    Maximum プロジェクトで，配列{72, 85, 60, 93, 80}の最大値を求める関数max_scoreを作ってください．要素数nは1以上，点数は0〜100とします．

    ヒント

    最大値の候補を最初の要素で初期化し，2番目以降と比べます．

    実行前に結果を予測し，実行後に結果とその理由を記録してください．

    最大値の候補を追跡する¶

    関数へ入った時点でbestはa[0]の72です．その後は次のようになります．

    i a[i] 比較前のbest 更新後のbest
    1 85 記入してください 記入してください
    2 60 記入してください 記入してください
    3 93 記入してください 記入してください
    4 80 記入してください 記入してください

    bestは「これまでに調べた要素の最大値」を保持します．最後の要素まで調べたら配列全体の最大値になる，という仕組みです．各比較の途中でreturnしてしまうと，残りの要素を調べられません．

    異なる配列で確かめる¶

    配列 渡すn 最大値 注目点
    {0} 1 記入してください 本体を0回で終了する
    {60, 60, 60} 3 記入してください 等しい値で候補が変わらない
    {100, 20, 30} 3 記入してください 最初が最大
    {20, 30, 100} 3 記入してください 最後が最大

    配列の後ろへ要素を増やすだけでは，呼び出しのmax_score(a, 5)の5は自動では変わりません．今回は表に合わせて手で変更してください．講義のsizeofによる要素数の計算は，配列を宣言したmainでは可能ですが，max_scoreの中では同じ方法を使えません．

    説明すること：iを1から始める理由，戻り値を返す位置，constを付ける意図を説明してください．

    課題2　列ごとの合計¶

    講義のarrays.cを別の ColumnSum プロジェクトへ入れ，二次元配列の各列の合計を5，7，9の順に表示するよう変更してください．

    ヒント

    外側を列，内側を行にします．sumの初期化は列ごとに必要です．

    すべての要素を0にした場合も確認します．table[row][col]の添字は，ループの外側・内側の順と必ず一致しなければならないのでしょうか．

    訪問順と合計を確認する¶

    点数の合計を表示する部分はそのままなので，変更後のプログラム全体の表示は次のようになります．

    total=390 mean=78.0
col 0: 5
col 1: 7
col 2: 9
    外側のcol 内側で読む要素 計算
    0 table[0][0]，table[1][0] 記入してください
    1 table[0][1]，table[1][1] 記入してください
    2 table[0][2]，table[1][2] 記入してください

    colが変わるたびにsumを0にする必要があります．sumの初期化を二重ループ全体の前へ移すと，5，12，21の累積になってしまいます．表示だけでなく，どの要素を足したかを確認してください．

    次にtableを{{1, 1, 1}, {2, 2, 2}}へ変更し，各列が3になることを確認します．さらに{{0}}へ変更すると，全要素が0になり，各列も0です．どの場合も点数配列scoresは変更していないので，最初のtotalの表示は変わりません．

    説明すること：table[col][row]へ入れ替えてはいけない理由を，それぞれの添字の範囲から説明してください．この課題ではcolが2になるため，行数2の配列の第1添字にcolを使うと範囲外になります．危険な変更は実行せず，紙上で判断します．

    補足：三次元配列の添字¶

    int data[2][3][4] = {0};の総要素数と，最後の要素を表す式を答えてください．最後の要素へ7を代入し，その要素を表示します．各次元の添字の範囲も説明してください．

    課題3　値渡しを確認する¶

    ValueCopy プロジェクトで，次の結果を予測してから実行してください．

    #include <stdio.h>
int increment(int x)
{
    x = x + 1;
    return x;
}
int main(void)
{
    int x = 10;
    int y = increment(x);
    printf("%d %d\n", x, y);
    return 0;
}

    3つの呼び出し方を比べる¶

    mainの中だけをそれぞれの形に変更してください．以下は独立した実験なので，毎回xを10から始めます．

    呼び出し方 呼び出し後のmainのx 戻り値の扱い
    increment(x); 記入してください 記入してください
    int y = increment(x); 記入してください 記入してください
    x = increment(x); 記入してください 記入してください

    元の完全なプログラムの初期値を0，−1へ変更した場合の表示を予測してください．この課題では初期値は−100〜100に限定します．上限付近の整数に1を加える実験は行いません．

    呼び出しごとに別の局所変数になる¶

    元のmainへ，最初の呼び出しの後にint z = increment(x);を追加してください．x，y，zの値を予測し，仮引数と呼び出し元の変数を区別して説明してください．

    一方，x = increment(x);を2回続ける場合はどうなるでしょうか．更新が関数の内側の変数だけに起きたのか，呼び出し元への代入でも起きたのかを分けて説明しましょう．

    スコープの読解¶

    次の2つのブロックをmain内に書いた場合，表示を予想してください．それぞれのaは別の変数です．

    {
    int a = 123;
    printf("%d\n", a);
}
{
    int a = 345;
    printf("%d\n", a);
}

    この直後にprintfでaを表示できるか，2つの宣言を同じブロックへ移せるかも考えてください．関数の仮引数xとmainのxが共存できる理由も，範囲から説明してください．

    課題4　平均と累乗を関数にする¶

    Functions プロジェクトで，次の2つの関数を作成します．引数と戻り値の型，計算してよい値の範囲を先に確認してください．

    関数 引数 戻り値 この課題での範囲
    average floatのaとb 記入してください 各値−100〜100
    power intのbaseとexponent 記入してください baseは1〜5，exponentは0〜5

    関数をmainより後ろへ定義し，mainより前へプロトタイプ宣言を書きます．関数内で表示はせず，mainで戻り値を表示してください．最初の表示はaverage=3.0，power=32の2行にします．

    ヒント

    averageは(a + b) / 2.0fを返します．powerは結果を1で初期化し，baseをexponent回掛けます．^は累乗ではなく，第3回のビットXORなので使いません．

    境界の値で確認する¶

    呼び出し 期待する戻り値 理由
    average(0.0f, 0.0f) 記入してください 同じ値の平均
    average(-4.0f, 2.0f) 記入してください 負の値を含む平均
    average(1.0f, 2.0f) 記入してください 小数部を失わない
    power(2, 0) 記入してください 本体は0回で初期値を返す
    power(5, 1) 記入してください 1回だけ掛ける
    power(5, 5) 記入してください 課題で許す最大の結果

    引数は表の範囲を呼び出し側が守る設計です．このpowerは負の指数を扱う関数ではありません．整数の範囲を超えるほど繰り返すことも認めません．関数名だけで万能な計算ができると考えず，受け付ける値の範囲を約束します．

    説明すること：resultを0で初期化してはいけない理由，returnをforの外へ置く理由，プロトタイプ宣言の末尾にセミコロンが必要な理由を説明してください．

    戻り値と表示を分ける¶

    averageの中でprintfだけを実行しても，平均を呼び出し元の計算に使えるわけではありません．float result = average(2.0f, 4.0f);と一度変数に保存してから表示する形へ変更し，同じ表示になることを確認してください．表示を担当するmainと，計算を担当する関数の分担が分かりやすくなります．

    発展　役割を分ける¶

    合計を返すsum_arrayと，平均を計算して表示するmainに分けてください．要素数は1〜5，値は0〜100とします．平均では (double)total / n とし，整数除算を避けます．この型変換は次回説明します．

    初期値でtotal=390 mean=78.0になります．{0}とn=1ではtotal=0 mean=0.0，{100, 100, 100}とn=3ではtotal=300 mean=100.0になることを確認します．合計関数単独ではn=0を受け付けても，平均は0で割れないので，このmainのnは1以上です．

    確認問題¶

    1. int a[5] = {1, 1};の最後の要素の添字と値は何か．
    2. int table[2][3];に対してtable[0][3]を読んではいけないのはなぜか．
    3. intが4バイトなら，int a[3]の全体のサイズと隣接要素の間隔は何バイトか．
    4. 配列を渡された関数の中でsizeof aから元の要素数を求められないのはなぜか．
    5. int b = 10;としてplus_one(b);だけを実行した後，bは何になるか．
    6. グローバル変数countと同名の局所変数を関数内へ宣言すると，その関数内の++countはどちらを変えるか．
    7. void関数のreturn;とint関数のreturn 0;は何が違うか．
    8. 関数をmainより後ろに定義しても呼び出せるようにするには何が必要か．

    チェックリスト¶

    • 正常な値だけでなく，課題に示された境界の値でも確認した．
    • 警告を確認し，原因を説明・修正した．
    • 自分の言葉で，処理の流れと使った型を説明できる．
    • 添字の範囲と，関数に渡す要素数が一致している．
    • 値を返すこと，変数へ代入すること，画面へ表示することを区別できる．
